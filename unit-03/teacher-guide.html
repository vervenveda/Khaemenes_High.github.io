Prerequisites

  • Whole-number factors, multiples, and GCF
  • Integer sign reasoning
  • Basic fraction and decimal familiarity
  • Order of operations
  • Place value and measurement units

Common misconceptions

  • Adding denominators when adding fractions
  • Comparing only numerators or only denominators
  • Dropping a negative sign when converting forms
  • Believing multiplication always makes values larger
  • Using invert-and-multiply without a division meaning
  • Misaligning decimal digits instead of decimal points
  • Treating rounded decimals as exact

Foundation supports

  • Fraction strips, grids, number lines, and place-value charts
  • Color-coded numerator and denominator roles
  • Benchmark cards for 0, 1/2, and 1
  • One representation change per step
  • Calculator use after estimation, not instead of reasoning
  • Vocabulary preview in a bridge language

Extended opportunities

  • Prove cross-product comparison
  • Characterize terminating denominators
  • Convert simple repeating decimals to fractions
  • Quantify absolute and relative rounding error
  • Simplify nested complex fractions
  • Compare exact and approximate solution strategies

Assessment use

The mastery check reports domains rather than a single label. A score of 80% marks the current unit threshold, but instruction should also consider misconceptions, explanations, project evidence, and independence.

Permit reassessment after specific review. Preserve prior records when growth documentation is useful.

Discussion prompts

  • How can two different-looking numbers be exactly equal?
  • Which representation makes this calculation easiest?
  • What should the answer be near before we calculate?
  • When is a rounded decimal responsible—and when is it misleading?
  • What unit does the denominator name?
