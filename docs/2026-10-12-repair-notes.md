# High School repair release · October 12, 2026

Course records now follow the selected Academy learner on direct math routes, shared games, and English 10–12 pages. Already scoped keys cannot be read for another learner or acquire a second learner suffix. Switching the Academy learner pauses writes from a stale page until it is reloaded.

Existing records are retained. Unassigned device work appears in a recovery notice: export it, select only records belonging to the active learner, and copy them. Historical records containing several local students require selection of the individual saved student. Originals remain untouched, and an existing learner record is not silently replaced.

English 10–12 dashboards derive completed weeks from saved daily lessons and quiz mastery of at least 80%. Manual planning marks are separate. Real zero scores count in averages and exports; incomplete weighted grades are labeled provisional. Imports require a valid course/version/record shape and preserve the preceding record before replacement. Storage failures and stale-tab writes show recovery guidance with an export option.

All 230 local reference failures from the audit have been repaired. Course service workers have distinct cache names and prefixes and read their current release caches. Updated releases cache identity and record helpers. Every shared game has a canonical return-to-lesson helper; test coverage accommodates round-based and individual-challenge interfaces.

Public title typography is 55 px for eyebrows, 33 px for H1, and 24 px for H2/subtitles. Public footer credits use Jennifer Kay Pearl. Original layout rules and course content remain in place. No STOS file was changed or activated.

Verification includes repository validators, sitewide HTML references, learner-switch and historical-record recovery reproductions, zero-score and malformed-import checks, stale-tab/storage-failure checks, cache coexistence, shared-game rounds and challenge rendering, syntax, JSON parsing, component seals, and typography coverage.

Visual browser testing and live third-party resource availability remain unverified. Browser-delivered scores retain their existing learning-evidence status; this release does not issue protected credentials or activate backend services.
