# English 9–12 · authentic reading and vertical assessment audit v1

This is a **quality gate for ongoing migration**, not an assertion that texts have been licensed, cached or taught in every weekly HTML engine.

## Reading source verification before student release
For each 36-week English 9–12 map record: (1) exact title and author, (2) passage or chapter, (3) authenticated public-domain/permission provenance and jurisdictional restrictions, (4) a local first-party or legally cleared offline reading path, (5) text actually reachable from weekly lesson, (6) original writing prompt requiring a passage-specific claim, (7) citations and accommodations. **Unspecified 'literary passage' is a gap**, not a verified reading.

## Grade progression — rubric dimensions, 0–4 each
- **Grade 9:** accurate summary; cited textual detail; literal-to-inferential reading; organized analytical paragraph; correct attribution
- **Grade 10:** comparative interpretation; nuanced theme and characterization; rhetorical decisions; multi-paragraph reasoning; source credibility
- **Grade 11:** historical/cultural context; competing readings; synthesis across genres; counterargument; method-aware research
- **Grade 12:** independent scholarly thesis; primary and critical sources; justified interpretive lens; sustained argument and rebuttal; reproducible citation and ethical disclosure

For every dimension, 0 = absent, 1 = emerging, 2 = partial, 3 = proficient, 4 = advanced. Publish grade-specific anchors before automatic rubric scoring; preserve human teacher judgment where needed. This rubric is formative guidance, not a replacement for the established 80% mastery engine.

## Release regression
A fictional learner must be able to open the actual assigned text, study offline, submit an original passage-specific response, save/print Academic Evidence, receive a transparent rubric with teacher-review boundary, and resume without changing another learner's draft. A bare JSON curriculum description does not certify this journey.
