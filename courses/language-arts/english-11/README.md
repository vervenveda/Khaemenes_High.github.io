# Khaemenes High — English 11 / English III

A complete advanced, globally inclusive, 36-week Grade 11 language arts course for the Khaemenes High GitHub architecture.

## Included

- 12 three-week units
- 36 weekly portals
- 180 Monday–Friday lessons
- 36 repeatable weekly quizzes
- 12 unit assessments and major projects
- Diagnostic, cumulative midterm, and cumulative final
- Global reading guide, teacher guide, portfolio, rubrics, gradebook, attendance and reading records, calendar, certificate, backup and CSV export
- Light/dark themes, responsive print styles, local progress, and course-scoped offline support

## Repository path

`courses/language-arts/english-11/`

## Portability statement

There is no single federal national ELA curriculum. This course is cross-aligned to Common Core 11–12, Florida B.E.S.T. Grade 11, SAT/ACT readiness domains, AP Language and AP Literature skill frameworks, and international language-and-literature reference points. Local approval and transcript requirements must still be verified.
