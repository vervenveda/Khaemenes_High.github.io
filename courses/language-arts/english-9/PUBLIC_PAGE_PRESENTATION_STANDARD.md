# Public Page Presentation Standard

Every public English 9 index, worksheet, assessment, source guide, key, record, and printable document must pass this gate.

| Feature | Required result |
|---|---|
| Weight | Body and supporting text use 333; headings, labels, controls, and emphasis use 444. |
| Centering | Title, purpose, and primary actions form one centered opening hierarchy. |
| Measure | Long reading text remains near 65–75 characters per line. |
| Spacing | Sections, fields, prompts, and choices have visible breathing room. |
| Controls | Minimum 42px target, visible keyboard focus, and text labels. |
| Navigation | Every public page provides clear Eiren and Beta routes. |
| Responsive layout | No page-level horizontal scroll at 320px; wide tables receive a labeled wrapper. |
| Print | Navigation and controls disappear; answer space and source records remain usable. |
| Accessibility | Semantic landmarks, one primary `h1`, ordered headings, labels, and live feedback where needed. |
| Language | Accurate `lang` and, where needed, `dir`; machine translation is visibly draft-labeled. |
| Privacy | No private route, credential, topology, hidden service, or learner information is exposed. |
| Evidence | Sources, editions, rubric, submission components, and mastery rule are easy to find. |
| Portability | Learner work can be printed or exported in a durable, human-readable form. |

## Shared classes

- `.document-page` — reports, guides, keys, and formal documents.
- `.worksheet-page` — student worksheets and assessment records.
- `.response-space` — printable handwritten responses.
- `.source-record` — citation and provenance fields.
- `.page-actions` — screen-only print/export controls.

The shared stylesheet supplies centered layout, readable measure, responsive spacing, and formal print treatment. Public pages should not replace it with cramped inline styling.
