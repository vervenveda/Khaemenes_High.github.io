# Diagnostic Routing — English 9

## Diagnostic domains
1. Close reading
2. Evidence and inference
3. Vocabulary/context
4. Language/conventions
5. Analytical writing
6. Argumentation
7. Research literacy
8. Speaking/listening
9. Media literacy

## Instructional routing
| Result | Route |
|---|---|
| 85%+ across domains | Advanced Readiness |
| 80–84% | Ready |
| 70–79% | Ready + Optional Review |
| 55–69% | Targeted Refresh |
| <55% | Foundational Path Recommended |

These are instructional routes, not grades.

## Required behavior
Diagnostic results should produce:
- strengths
- priority skills
- recommended refresh lessons
- recommended challenge lessons
- a learner growth goal

The diagnostic should never permanently label a learner.
