Research Questions & Search Strategy

What makes a research question focused, significant, and answerable?

Reading: Background sources, reference entries, indexes, catalogs, databases, archives, and search-result sets.
Research & Writing: Move from curiosity to a researchable question, build a search vocabulary, test multiple search paths, and preserve a transparent search log.

Weekly Targets

By the end of this week, the student can…

  • Distinguish a broad topic, factual lookup question, argumentative prompt, and genuinely researchable inquiry.
  • Refine scope by population/subject, place, period, concept, relationship, or evidence availability without narrowing mechanically.
  • Build keyword families using synonyms, broader/narrower terms, names, dates, variant spellings, and discipline-specific vocabulary discovered during research.
  • Select source types according to the question rather than assuming one source type is always best.
  • Explain the difference between primary and secondary sources as a relationship to the research question, not a simple good/bad hierarchy.
  • Test and revise search strings after inspecting results rather than repeatedly submitting the same unsuccessful query.
  • Preserve a search log including query, tool/location searched, useful results, dead ends, vocabulary discoveries, and next move.
  • Use precise nouns and clear question formation.
  • Use accurately: inquiry, scope, keyword, primary source, secondary source, database.
  • Complete the research proposal, search strategy, and defined scored checks at 80% or higher.

Five-Day Inquiry Laboratory

Curiosity → question → vocabulary → search paths → proposal.

Day 1 · Question Ladder

A Topic Is Not Yet a Research Question

Begin with a broad area of curiosity and generate multiple kinds of questions. Evaluate which ones can sustain investigation with evidence.

  • Write one broad topic and at least five questions about it.
  • Classify questions as lookup, descriptive, comparative, causal, interpretive, evaluative, or another defensible type.
  • Reject or revise questions that already assume their conclusion.
  • Identify what evidence would be needed to answer the strongest question.
  • Write why the question matters beyond “I am interested in it.”
Day 2 · Scope Laboratory

Focused Enough to Investigate, Large Enough to Matter

Test the question against time, evidence, complexity, available source types, and course constraints.

  • Create broader, current, and narrower versions of the question.
  • Identify boundaries that are intellectually meaningful rather than arbitrary.
  • Run a small background scan to see whether useful vocabulary and sources exist.
  • Revise if the question is impossibly broad, trivially narrow, inaccessible, or built on a false premise.
Day 3 · Search Vocabulary & Language Lab

Search With Concepts, Not Whole Sentences

Break the question into concepts and build keyword families. Search vocabulary should grow as the researcher learns.

  • Extract the essential nouns/concepts from the question.
  • Generate synonyms, related terms, names, dates, alternate spellings, broader/narrower terms, and specialist vocabulary.
  • Revise vague nouns into precise research language where appropriate.
  • Use all six weekly vocabulary terms accurately.
  • Complete the scored inquiry/language check at 80% or higher; review and retry below 80%.
Day 4 · Search Strategy Studio

Search Is Iterative, Not a Single Box

Test multiple combinations and source environments. Record both useful paths and dead ends so the research process remains inspectable.

  • Run several distinct queries derived from the keyword map.
  • Compare what changes when a term is added, removed, broadened, narrowed, or replaced.
  • Seek different source types appropriate to the question: primary documents, scholarly/contextual sources, data, reference works, archives, or current reporting as relevant.
  • Use discovered terminology to create the next query rather than assuming the first vocabulary was sufficient.
  • Preserve provenance for promising sources immediately.
Day 5 · Research Proposal Defense

Can the Inquiry Survive Inspection?

Submit and defend the research question, significance statement, scope, keyword map, source-type plan, and search log.

  • Explain why the question is researchable rather than merely answerable by one source.
  • Show how at least one search changed after inspecting results.
  • Identify one source type still missing and why it matters.
  • Use peer, teacher, or Eiren challenge to revise one hidden assumption or scope problem.
  • Preserve the proposal, search log, vocabulary map, challenge notes, and reflection.

Sovereign Search Game

The Query Forge

This game requires no external application. The goal is not to guess a magic phrase; it is to learn how search language changes the evidence landscape.

Forge 1 · Concept Split

Write the research question on paper. Circle its essential concepts and generate at least three alternative terms for each. Remove filler words that do not help retrieval.

Forge 2 · Search Mutation

Create three substantially different search strings from the concept bank. Predict what each query is likely to retrieve, then compare that prediction with actual results when a search tool is available.

Forge 3 · Vocabulary Harvest

Harvest useful names, dates, technical terms, organizations, events, or phrases from credible background material. Feed those discoveries back into the next search cycle and record the lineage in the search log.

Eiren · Language Arts Mentor

Eiren interrogates the question before helping with the answer.

Bring a topic, candidate questions, keyword map, search log, or proposal first. Eiren can expose hidden assumptions, ambiguous nouns, false premises, scope problems, and missing search vocabulary.

Open Eiren
Try: “Ask what evidence would be needed to answer this question.” · “Find the noun in my question that is too vague.” · “Challenge the assumption built into my wording.” · “Do not give me sources yet; help me generate better search concepts.” Eiren cannot invent sources, fabricate search results, write the assessed proposal, assign verified scores, or override mastery.
