# Accessibility Contract

Every learner-facing page/activity should satisfy:

## Structure
- semantic headings
- landmarks
- meaningful link text
- keyboard navigation
- visible focus
- no keyboard traps

## Visual
- scalable text
- sufficient contrast
- no color-only meaning
- reduced-motion alternative
- readable print layout

## Response modes
Where the academic target permits:
- typed
- paper
- oral
- audio
- printable

Alternate response modes must preserve the competency being measured.

## Content
- captions/transcripts where applicable
- descriptive labels
- concise instructions
- vocabulary support
- language-support options where locally appropriate
