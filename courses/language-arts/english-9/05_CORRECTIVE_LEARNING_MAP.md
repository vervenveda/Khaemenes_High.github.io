# Corrective Learning Map

| Signal | Skill Need | Correction | Reassessment |
|---|---|---|---|
| EVIDENCE | Selects weak/irrelevant evidence | Evidence-sort + model paragraph | Canonical item |
| INFERENCE | Confuses detail and inference | Think-aloud + annotated passage | Canonical item |
| VOCAB_CONTEXT | Misreads context clues | Context-clue routine + morphology | Canonical item |
| CONVENTIONS | Sentence/usage errors | Contextual mini-lesson + revision | Writing evidence |
| CLAIM | Weak or unfocused claim | Claim sort + thesis workshop | Canonical writing |
| RESEARCH | Weak source verification | Source audit + lateral reading | Research checkpoint |
| COUNTERCLAIM | Does not address opposition | Concession/rebuttal model | Argument evidence |
| SPEAKING | Weak organization/delivery | Rehearsal + self-review | Human rubric |
| MEDIA | Accepts claims without verification | Verification protocol | Source-analysis task |

## Rule
Correction is targeted to the skill signal. Do not make a student repeat an entire unit when only one skill is weak.
