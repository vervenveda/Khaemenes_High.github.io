# Teacher Dashboard Specification

## Class view
- mastery by skill
- students needing correction
- students ready for reassessment
- advanced-ready students
- missing human reviews
- portfolio evidence gaps

## Student view
- diagnostic profile
- current mastery
- attempt history
- best score
- recent skill signals
- correction history
- teacher feedback
- portfolio evidence

## Privacy
Only authorized instructional staff should see class/student analytics.
