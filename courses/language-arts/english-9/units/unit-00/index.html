Unit 0 · Foundations & Readiness

Unit 0 is assigned only when the NAIB readiness profile shows that foundational reinforcement would improve success in English I. Strong strands may use confirmation challenges; weaker strands receive full reteaching and practice. All learners who exit Unit 0 enter the exact same official Unit 1.

Adaptive Rule

Repair only what needs repair.

Each lesson follows the academy pattern: diagnostic connection → teach/reteach → guided practice → independent practice → application → mastery evidence. Strong strands can confirm readiness quickly; weak strands receive full instruction. Completion alone does not create readiness.

Exit Contract

80% + reasoning corrections → Official Unit 1.

The Unit 0 exit assessment uses fresh material and stable question IDs. Answers are not disclosed before submission. Attempts preserve version, timestamp, score, strand scores, and correction status. Below mastery, NAIB assigns targeted correction and fresh reassessment rather than automatic six-week repetition.
