    Manual learner-journey checklist

    1. Open Grade 9 Week 1 and begin the randomized 20-question assessment.
    2. Answer several questions, reload the page, and confirm both the question order and selected answers are retained.
    3. Submit 15/20 correct (75%): it must not unlock Week 2.
    4. Retry and submit 16/20 correct (80%): the weekly knowledge threshold should be met; practice evidence and reflection are also required for the local next-week rule.
    5. Export a journal. In a separate browser profile or device, open the portal, select Grade 9, and import that file. Confirm the saved attempt and daily entries return without altering teacher-verification status.
    6. Confirm midterm readiness requires all first 18 validated weekly records, and final readiness requires all 36 plus the approved midterm state.
    7. Repeat navigation with keyboard only and at a narrow/mobile viewport. Confirm locked and review-only states are understandable.

    Browser-local data is provisional and can be edited by a device owner. The runner never grants teacher verification or academic credit.

    No account data is sent to a server by this test page. Temporary test keys are cleaned up when the run completes.
