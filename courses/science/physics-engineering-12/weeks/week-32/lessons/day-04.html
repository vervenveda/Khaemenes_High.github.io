Optics & Communication Investigation

Use simulation or supplied data to compare signal transmission, reflection/refraction, or digital error behavior.

Weekly EvidencePhysics CourseScience Hall

Safety boundary

Use simulations, printed optics, and eye-safe light only. Do not direct lasers or intense light at people.

Explicit physics instruction

This investigation preserves raw transmitted/received values before decoding or fitting a model.

Students may compare angle data, attenuation, or bit-error patterns depending on the supplied simulation.

The conclusion should distinguish measured signal change from inferred communication performance.

Vocabulary: transmission; attenuation; error rate; calibration; uncertainty.

Worked example

A 1000-bit message contains 12 incorrect bits after transmission, so bit error rate is 12/1000=1.2%.

Guided question

Which raw data must be preserved before calculating an error rate?

Independent work

  1. Preserve transmitted and received records.
  2. Calculate one quantitative comparison.
  3. Graph or tabulate a signal relationship.
  4. State uncertainty and one revision.

Investigation / Data Lab

Preserve raw transmission/optics data, calculations, processed metrics, uncertainty, and one revision.

Misconception check

A processed error percentage should not replace the original transmitted/received evidence.

Formative check

What supports a communication-performance claim?

Reveal response

Traceable raw data plus a defined metric such as error rate.

Mentor evidence conference

Ask Archaemenes to audit wave variables, encoding assumptions, metrics, and model limits.

Teacher guidance

Foundation: Use supplied data tables.

Core: Calculate and interpret performance metrics.

Extended: Compare two encoding/transmission strategies.

Investigation-depth extension

Preserve raw transmitted and received records before calculating attenuation or bit error rate. A processed percentage is only meaningful if the underlying message length and error count are traceable.

For optics, preserve source angle, transmitted/reflected angle, or intensity readings before fitting a model. Compare repeated trials and state whether uncertainty could change the performance conclusion.

Evidence revision / CER

Write a CER comparing two communication or optics strategies using a defined metric and one uncertainty. Revise any claim that confuses signal amplitude loss with information failure automatically.

Spiral retrieval

Connect Week 05 evidence provenance with communication-performance metrics.

Performance-residual transfer

Compare two transmission strategies using the same message length and defined metric. If Strategy A has 1.2% error and Strategy B 0.4%, the lower rate is better only if power, bandwidth, and latency constraints are also acceptable.

For optics, compare predicted and measured angles or attenuation values with uncertainty rather than treating one processed percentage as complete evidence.

Evidence-quality transfer check

Compare two systems using the same message length, power, and bandwidth before ranking their error rates. If those conditions differ, the performance comparison must include the tradeoff rather than relying on one percentage alone.

Metric-quality check

Compare two systems with the same bit-error rate but different latency and bandwidth. State why one error metric cannot determine overall communication quality when engineering requirements differ.

Final evidence check

Use repeated transmission trials to report an average error rate and spread rather than relying on one message. Explain why repeatability matters for a communication-performance claim.

Communication-performance transfer

Compare two channels over five repeated 1000-bit trials. Channel A produces error counts 8, 10, 9, 11, and 7; Channel B produces 2, 18, 1, 20, and 3. Even if the average error rates are similar enough to tempt a simple ranking, the variability differs dramatically.

Report both central performance and spread. A channel with occasional severe failures may be unacceptable for some applications even if its mean error rate looks competitive. This is why repeatability and distribution of errors matter in addition to one summary percentage.

Then identify one additional metric—latency, bandwidth, power, or packet loss—that could change the design decision.
