Model Prediction Before Prototyping

Use a physics model to predict performance before testing a design.

Weekly EvidencePhysics CourseScience Hall

Explicit engineering instruction

Engineering is stronger when prototypes test a prediction rather than merely being built first and explained afterward.

A predictive model can be an equation, graph, simulation, or data-driven relationship tied to the relevant physics.

The prediction should include assumptions and an uncertainty/range so later testing can evaluate model quality.

Vocabulary: predictive model; prototype; assumption; uncertainty; validation.

Worked example

A circuit design predicts 0.50 A using V=IR. The prototype test can then compare measured current with that prediction and quantify residual error.

Guided question

Choose one course equation that could predict performance for a supplied design problem.

Independent work

  1. Write one predictive equation/model.
  2. State assumptions.
  3. Give an expected result range.
  4. Define how the prototype will test it.

Misconception check

A prototype without a prior prediction cannot fully test model accuracy.

Formative check

What converts a build into a model test?

Reveal response

A prior quantitative prediction and a defined comparison metric.

Mentor evidence conference

Ask Archaemenes to challenge criteria, weights, assumptions, and whether the evidence justifies the revision.

Teacher guidance

Foundation: Use a prediction template.

Core: Link physics to measurable performance.

Extended: Include uncertainty and model-limit analysis.
