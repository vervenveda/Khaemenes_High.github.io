Model Prediction Before Prototyping

Use a physics model to predict performance before testing a design.

Weekly EvidencePhysics CourseScience Hall

Explicit engineering instruction

Engineering is stronger when prototypes test a prediction rather than merely being built first and explained afterward.

A predictive model can be an equation, graph, simulation, or data-driven relationship tied to the relevant physics.

The prediction should include assumptions and an uncertainty/range so later testing can evaluate model quality.

Vocabulary: predictive model; prototype; assumption; uncertainty; validation.

Worked example

A circuit design predicts 0.50 A using V=IR. The prototype test can then compare measured current with that prediction and quantify residual error.

Guided question

Choose one course equation that could predict performance for a supplied design problem.

Independent work

  1. Write one predictive equation/model.
  2. State assumptions.
  3. Give an expected result range.
  4. Define how the prototype will test it.

Misconception check

A prototype without a prior prediction cannot fully test model accuracy.

Formative check

What converts a build into a model test?

Reveal response

A prior quantitative prediction and a defined comparison metric.

Mentor evidence conference

Ask Archaemenes to challenge criteria, weights, assumptions, and whether the evidence justifies the revision.

Teacher guidance

Foundation: Use a prediction template.

Core: Link physics to measurable performance.

Extended: Include uncertainty and model-limit analysis.

Predictive-model depth

A useful engineering prediction names the system boundary, governing relation, parameter values, assumptions, and expected uncertainty before testing. Dimensional analysis should be performed before numerical substitution. If units do not reduce to the intended output unit, the model or calculation is incomplete.

Example: a resistor network supplied at 6.0 V with an equivalent resistance of 12 Ω predicts a current of 0.50 A. If resistor tolerance and meter resolution suggest an expected range of roughly 0.47–0.53 A, a measured value of 0.51 A supports the model more strongly than simply saying “the circuit worked.”

Residual and model-limit reasoning

Define residual as measured minus predicted. A single small residual does not prove the model is universally correct; repeated residuals, their direction, and their spread help diagnose bias, random variation, or a missing mechanism. State which assumption is most likely to fail first under real conditions.

Evidence revision / CER

Write a prediction claim before testing, then compare the measured result with the predicted range. Revise either the design or the model when the discrepancy is larger than expected uncertainty, and identify which evidence triggered the revision.

Spiral retrieval

Select a model from mechanics, energy, fluids, thermal physics, circuits, magnetism, or waves. State one variable that should be controlled, one measurable output, and one condition under which the model should no longer be trusted.
