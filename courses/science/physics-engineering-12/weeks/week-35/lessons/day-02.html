Predictive Model & Uncertainty

Build at least one quantitative prediction with explicit assumptions and uncertainty.

Weekly EvidencePhysics CourseScience Hall

Explicit capstone instruction

The model should produce a number, curve, range, or threshold that can be tested.

Assumptions belong beside the model; hidden assumptions make later mismatch difficult to interpret.

Uncertainty can come from measurement resolution, parameter estimates, idealizations, and trial variation.

Vocabulary: prediction; parameter; assumption; uncertainty; testable model.

Worked example

A model predicts 3.2 s ±0.3 s. A measured result of 3.4 s is consistent with the prediction range; 5.1 s would demand explanation or revision.

Guided question

Choose one equation/model and identify which inputs dominate its uncertainty.

Independent work

  1. Write the predictive relation.
  2. Estimate parameter values.
  3. State an expected range.
  4. Identify two uncertainty sources.

Misconception check

A precise-looking prediction is not automatically accurate if its assumptions are weak.

Formative check

What makes a model genuinely testable?

Reveal response

It produces a measurable prediction before the test is run.

Mentor evidence conference

Ask Archaemenes to challenge system boundaries, predictions, uncertainty, and whether revisions follow the evidence.

Teacher guidance

Foundation: Use a prediction-range frame.

Core: Quantify assumptions and uncertainty.

Extended: Perform sensitivity analysis on key parameters.

Predictive-model depth

A capstone model should produce a quantity that can later be compared with evidence. Write the governing relation symbolically, audit units, substitute parameter values, and state the expected range before any test is run. If multiple equations are chained together, preserve intermediate quantities so the calculation remains traceable.

Suppose a cooling model predicts a 3.2 s response time with an estimated ±0.3 s uncertainty. A measured 3.4 s result is consistent with the prediction range; 5.1 s is not. The second result should trigger investigation of model assumptions, parameter estimates, or the physical build rather than simple acceptance or rejection.

Sensitivity analysis

Vary the most uncertain parameter across a defensible range and record how much the prediction changes. A parameter that causes a large output change deserves better measurement or tighter control. A parameter that barely changes the result may not deserve additional complexity.

Evidence revision / CER

State the prediction as a claim with assumptions and uncertainty. After testing, use the residual and expected uncertainty to decide whether the model is adequate for the design decision. Revise only the assumption or parameter that the evidence actually challenges.

Model-limit check

Identify at least one condition where the chosen relation should fail or require modification. A model can be useful within its operating range without being universally valid.

Spiral retrieval

Use dimensional analysis and uncertainty reasoning from earlier physics investigations to audit the capstone prediction before it becomes the basis for design decisions.
