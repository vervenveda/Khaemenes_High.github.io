Capstone Problem & System Definition

Define a real physics/engineering problem with a clear system boundary, measurable goal, criteria, and constraints.

Weekly EvidencePhysics CourseScience Hall

Explicit capstone instruction

A strong capstone begins with a system, not a gadget. Define what is inside the system boundary, what crosses it, and which outcome matters.

The problem statement should identify a measurable performance target and the constraints that limit acceptable solutions.

Select a physics domain—mechanics, energy, waves, fluids, circuits, sensing, or a combination—that can support a predictive model.

Vocabulary: system boundary; capstone; criterion; constraint; performance metric.

Worked example

A cooling design might define the system as device+heat sink, constrain mass below 200 g, and target maximum temperature below a stated threshold.

Guided question

Rewrite a broad problem into one measurable goal, two constraints, and two criteria.

Independent work

  1. Write the system boundary.
  2. Define one quantitative target.
  3. List criteria and constraints.
  4. Choose the physics model family that should predict performance.

Misconception check

Capstone definition depth

Translate the problem into an auditable engineering brief before choosing a solution. Identify the system boundary, inputs, outputs, users or stakeholders, environment, and failure modes. Every criterion should have a measurable metric and every hard constraint should have a pass/fail threshold.

For example, a thermal-control capstone may require device temperature to remain below 60 °C, total mass below 200 g, and power draw below 5 W while maximizing cooling rate. These quantities connect directly to thermal and electrical models and can be tested without hiding the tradeoffs.

Physics-model alignment

Choose only models that directly control performance. A mechanics capstone might require force, energy, momentum, or rotation; a thermal system may require q=mcΔT or power; an electrical system may require V=IR and P=VI. State why each chosen model belongs inside the system boundary.

Evidence revision / CER

Write a claim about the most important performance criterion, support it with problem-context evidence, and explain how the chosen metric tests success. Revise the criterion if it cannot be measured or if it conflicts with a hard constraint.

Uncertainty and assumptions

Separate known constraints from assumed operating conditions. Record which assumptions would most strongly change the model prediction if wrong, and identify one measurement that could reduce that uncertainty before prototyping.

Spiral retrieval

Retrieve one mechanics model and one non-mechanics model from earlier in Physics 12. Explain which would be relevant to the capstone and which would be unnecessary complexity.
