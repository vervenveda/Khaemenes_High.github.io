Capstone Problem & System Definition

Define a real physics/engineering problem with a clear system boundary, measurable goal, criteria, and constraints.

Weekly EvidencePhysics CourseScience Hall

Explicit capstone instruction

A strong capstone begins with a system, not a gadget. Define what is inside the system boundary, what crosses it, and which outcome matters.

The problem statement should identify a measurable performance target and the constraints that limit acceptable solutions.

Select a physics domain—mechanics, energy, waves, fluids, circuits, sensing, or a combination—that can support a predictive model.

Vocabulary: system boundary; capstone; criterion; constraint; performance metric.

Worked example

A cooling design might define the system as device+heat sink, constrain mass below 200 g, and target maximum temperature below a stated threshold.

Guided question

Rewrite a broad problem into one measurable goal, two constraints, and two criteria.

Independent work

  1. Write the system boundary.
  2. Define one quantitative target.
  3. List criteria and constraints.
  4. Choose the physics model family that should predict performance.

Misconception check

A capstone is not stronger merely because it uses many physics topics; relevance matters.

Formative check

What should be fixed before selecting a prototype?

Reveal response

The problem, system boundary, criteria, and constraints.

Mentor evidence conference

Ask Archaemenes to challenge system boundaries, predictions, uncertainty, and whether revisions follow the evidence.

Teacher guidance

Foundation: Use a capstone brief template.

Core: Define measurable goals and model choice.

Extended: Analyze stakeholder assumptions and competing objectives.
