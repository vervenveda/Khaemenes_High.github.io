The Curved-Graph Mystery

Learning objective: Distinguish a linear motion model from a quadratic one using shape and rate changes.

45–60 minutes · Offline-capable · Public practice, not a supervised examination

MondayTuesdayWednesdayThursdayFriday

Read and reason

One dataset, competing explanations

A cart's measured position can be plotted against time. If its velocity is approximately constant, x(t)=x0+vt is a plausible linear model. If its acceleration is approximately constant and nonzero, x(t)=x0+v0t+(a/2)t² is a quadratic model. A few noisy observations may make either appear visually plausible, so mathematics and careful measurement matter more than which line looks elegant.

Slope tells a mechanistic story

In a linear position model, the slope of x versus t is the constant velocity. In a quadratic model, velocity varies with time: v(t)=v0+at. This does not mean every curved dataset is caused by constant acceleration. Other models or systematic measurement problems can also cause curvature. An equation is an assumption to be tested against both data and physical constraints.

Why noisy data are useful

A real instrument never provides infinitely precise readings. Values might be rounded to 0.1 m, and timing may have uncertainty. The classroom dataset for this week is synthetic and deliberately perturbed to mimic measurement variation, not collected from a real moving cart. You can still practice how to compare model predictions, residuals and error patterns while accurately labeling the source.

Define the independent variable

Plot time horizontally in seconds and position vertically in meters. A data point at (2 s, 4.1 m) represents a position measurement at an elapsed time. Neither an x-axis label nor a derived curve substitutes for the recorded measurement method. Before choosing the model, check sampling frequency, origin, units and whether observations are drawn from a single motion regime.

Safety: Only use synthetic data and offline simulations for the core work. No real projectile launching, motor vehicles, improvised ramps, unsafe falling objects or video recording of others is needed.

Vocabulary in context

model
A mathematical representation used to explain or predict selected observations.
linear model
An equation x(t)=b+mt with constant slope/velocity.
quadratic model
An equation x(t)=b+mt+ct² whose slope generally varies with time.
trend
A systematic pattern in a sequence of observations.
prediction
A model-generated value for an unobserved or test time.

Use every term in a short original sentence or model explanation.

Worked example

Linear x(t)=1+2t gives x(3)=7 m. Quadratic x(t)=1+2t+0.5t² gives x(3)=11.5 m. Their initial position and initial slope match, but quadratic motion changes speed over time.
