Angular-Momentum Investigation

Why can rotational speed change when mass distribution changes?

Weekly EvidencePhysics CourseScience Hall

Explicit physics instruction

This investigation tests angular-momentum conservation using supplied or simulated data.

Use a simulation/video dataset that changes mass distribution without unsafe spinning. Compare I, ω, and L before/after.

Preserve raw angular-speed and geometry/mass-distribution evidence before calculating L.

Core relation: L=Iω and ΔL=τ_extΔt.

Worked example

If L_before=7.8 and L_after=8.1 kg·m²/s, compare the 0.3 residual with measurement uncertainty before judging conservation.

Guided question

Which measurements are required to test Iω conservation?

Independent work

  1. Solve three angular-momentum or torque-time problems.
  2. Declare the system and external-torque assumption.
  3. Record one unit/assumption check.

Investigation / Data Lab

Use a simulation/video dataset that changes mass distribution without unsafe spinning. Compare I, ω, and L before/after.

Preserve raw data, calculated I/ω/L values, residuals, uncertainty, and one revision.

Misconception check

Conserved angular momentum does not mean angular speed is constant; I can change.

Formative check

If I is halved with L conserved, what happens to ω?

Reveal response

It doubles.

Mentor evidence conference

Ask Archaemenes to audit the system boundary, moment-of-inertia reasoning, and external-torque claim.

Teacher guidance
