Buoyancy & Archimedes’ Principle

Why can a heavy ship float while a small dense object sinks?

Weekly EvidencePhysics CourseScience Hall

Explicit physics instruction

Buoyant force arises from pressure differences over an immersed object.

The fluid pushes more strongly on deeper surfaces than shallower ones, producing a net upward force.

For a fully immersed object, displaced-fluid volume equals immersed object volume.

Core relations: ρ=m/V; F_b=weight of displaced fluid.

Worked example

A 2.0 kg object displaces 2.5 kg of water. The displaced-fluid weight is about 24.5 N using g=9.8 m/s², so buoyant force is about 24.5 N.

Guided question

Why does an immersed object experience a larger pressure force on its bottom surface?

Vocabulary and Archimedes extension

Vocabulary: buoyant force; displaced fluid; Archimedes' principle; immersed volume; pressure difference.

Buoyant force results from unequal pressure forces over an immersed body. In the Archimedes model, F_b=ρ_fluid g V_displaced. For a fully immersed object, displaced volume equals object volume; for a floating object, only the submerged portion contributes.

If 0.0025 m³ of water is displaced, F_b≈1000×9.8×0.0025=24.5 N. Compare this with object weight to predict upward acceleration, downward acceleration, or equilibrium.

Buoyancy transfer calculation

A fully immersed object of volume 0.0030 m³ in water experiences F_b≈29.4 N. If its mass is 2.0 kg, weight is 19.6 N, so the initial net force is upward in the simple model. If its mass is 4.0 kg, weight is 39.2 N and the net force is downward.

The buoyant force did not change because the displaced water volume stayed the same. This is why object mass and buoyant force must be treated separately in the force diagram.

If displaced volume is uncertain, state how that uncertainty changes the buoyant-force prediction and whether it could reverse the expected motion.

Force-balance transfer check

For an immersed object with F_b=24.5 N and weight 19.6 N, net force is 4.9 N upward. If drag is ignored, Newton's second law predicts upward acceleration. Floating equilibrium is reached only when the displaced volume adjusts so buoyant force equals weight.

Explain why buoyancy alone does not guarantee equilibrium.

Partial-immersion note

For a floating body, displaced volume adjusts until buoyant force equals weight. Explain why only the submerged portion contributes to displaced-fluid volume and how this differs from the fully immersed case.

Buoyancy transfer note

State how buoyant force changes if the same immersed volume is placed in a denser fluid.
