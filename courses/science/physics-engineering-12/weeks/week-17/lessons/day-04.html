Explicit physics instruction

This investigation uses a combined motion/force/collision dataset. Students identify where the model should change, calculate predicted quantities, and compare with observed values.

Preserve raw observations before derived speed, energy, or momentum values. Each transformation should remain traceable.

A mismatch can indicate measurement uncertainty, unmodeled work, external impulse, or a poor system boundary.

Vocabulary: multi-stage data; residual; model transition; system boundary; uncertainty.

Worked example with reasoning

A cart’s predicted pre-collision speed is 2.5 m/s but measured is 2.3 m/s. The difference should be evaluated before the collision model uses 2.3 m/s as input.

Residual-propagation extension

In a staged investigation, assign each residual to the model and interval that produced it. A pre-collision speed mismatch belongs to the motion/energy stage; a momentum residual belongs to the collision stage. Blaming the entire experiment hides which model needs revision.

Preserve raw data and propagate uncertainty forward. If the measured pre-collision speed is 2.30±0.05 m/s, the collision momentum calculation should reflect that uncertainty rather than treat 2.30 as exact. A downstream mismatch may simply inherit an upstream uncertainty.

Compare residual size with uncertainty and expected unmodeled effects. A systematic residual pattern may indicate friction, calibration bias, or a poor stage boundary; random scatter may indicate measurement noise.

Evidence revision / CER

Defend one stage-specific model using raw evidence, residuals, and uncertainty. Revise the stage model rather than the entire analysis when the evidence points to a localized mismatch.

Uncertainty-propagation example

If a pre-collision speed is 2.30±0.05 m/s for a 2.0 kg cart, its momentum is about 4.60 kg·m/s with a velocity-related uncertainty of about ±0.10 kg·m/s before considering mass uncertainty. If the measured post-collision system momentum differs by only 0.06 kg·m/s, that mismatch may be fully consistent with upstream measurement limits.

Contrast this with a 0.40 kg·m/s residual under the same uncertainty scale. That larger discrepancy deserves a model revision, external-impulse estimate, or calibration check. Quantitative residual size should therefore be interpreted relative to uncertainty, not by whether the numbers merely look close.

Residual-transfer check

Trace one downstream disagreement back through every upstream quantity used to produce it. Mark which values were measured, which were calculated, and which assumptions connected the stages. This audit prevents a later collision residual from being blamed on the collision model when the actual source was an earlier speed estimate or calibration choice.
