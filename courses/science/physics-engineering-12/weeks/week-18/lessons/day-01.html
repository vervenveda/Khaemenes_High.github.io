Explicit physics instruction

The midterm covers mechanics and experimental reasoning from Weeks 01–17. Review should be organized by model families: motion graphs/vectors, forces, energy, momentum, and system reasoning.

A useful readiness map links each model to the evidence it uses, equations it supports, assumptions, and common errors.

This page is formative review only. The official midterm remains separately supervised and does not draw protected questions from this page.

Vocabulary: readiness map; representation; model family; assumption; supervised assessment.

Worked example with reasoning

A force problem may need a free-body diagram and F=ma; a collision problem may need signed momentum; a ramp problem may be simpler with energy. The readiness map helps select rather than memorize.

Guided question

Build a map that links one motion, force, energy, and momentum representation to the kind of question each answers best.

Independent work

  1. Create a four-column readiness map.
  2. List two common errors per model family.
  3. Mark one area that needs correction before the supervised exam.

Misconception check

Review is not strongest when it is only equation memorization; model selection and evidence interpretation matter.

Formative understanding check

What should a readiness map connect besides equations?

Reveal response

Representations, assumptions, evidence types, and common errors.

Mentor evidence conference
