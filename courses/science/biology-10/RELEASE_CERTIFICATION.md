## Source certification

The repository release is considered source-valid when the Biology 10 Course Integrity workflow confirms:

1. 36 weeks and exactly 180 daily lesson pages are materialized.
2. Every weekly classroom loads learner-scoping and every daily lesson loads the shared high-school learning context.
3. The public bank contains 180 unique assessable items with five items tagged to every week.
4. Weekly progression is assessment-derived; no learner-editable numeric mastery field controls unlocking.
5. Failed weekly mastery work keeps the same form and option order for correction.
6. The main portal uses external course-data/runtime modules.
7. The canonical Biology shell and 16px readable-type floor are present.
8. The public secure-assessment blueprint and planning standards crosswalk are present.
9. The five second-half quantitative studios are materialized and linked.
10. Public practice remains explicitly non-authoritative.

## Certification boundary

Automated source validation cannot prove real-browser layout, keyboard behavior, print fidelity, actual offline cache behavior, assistive-technology behavior, or protected Academy credential issuance. Those remain separate gates.

A passing source workflow therefore does **not** upgrade the course beyond SOURCE-VALIDATED / CONDITIONAL until the human/browser checklist is completed on the exact release SHA.
