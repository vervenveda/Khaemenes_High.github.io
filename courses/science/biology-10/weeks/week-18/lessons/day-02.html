Purpose and instruction

Quantitative biology this semester included percent change, rates, ratios, surface-area-to-volume reasoning, graph interpretation, energy-transfer patterns, feedback deviation, mitotic index, and sampling uncertainty. The key skill is deciding what calculation or graph fits the evidence—not merely recalling a formula.

Use the public Practice Midterm in the Biology course portal only as open-book formative rehearsal. Its result is not the supervised midterm score.

Student task

  1. Solve one example each involving percent change, rate, ratio, and a biological index.
  2. Interpret one time-series graph and one relationship/scatter-style graph.
  3. For every result, write units and one limitation.
  4. Complete the public Practice Midterm if useful, then classify each miss as concept, calculation, graph, vocabulary, or reasoning.

Mastery and correction check

A correct number without units, setup, interpretation, or limits is incomplete scientific reasoning. A practice score below 80% triggers review and correction; it does not create an official grade.
