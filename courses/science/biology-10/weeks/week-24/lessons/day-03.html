Translation & the Genetic Code

Translate mRNA codons into amino-acid sequences while keeping codon, anticodon and reading frame distinct.

Weekly Classroom & EvidenceBiology CourseScience HallArchaemenesPrevious DayNext Day

Safety, privacy and evidence boundary

Use fictional DNA/RNA/protein sequences and standard codon tables. Do not use personal genomic data or infer disease from sequence examples. Sequence exercises are educational models, not clinical interpretation.

Explicit science instruction

Ribosomes read mRNA in nonoverlapping three-base codons. Transfer RNAs carry amino acids and use anticodons to pair with codons. Translation usually begins at a start codon in the selected reading frame and ends at a stop codon.

The standard code is degenerate: multiple codons can specify the same amino acid. It is nearly universal but has known biological exceptions.

Worked example with reasoning

mRNA 5′-AUG GCU UUU UGA-3′ translates Met-Ala-Phe-Stop using the standard code. The codon is on mRNA; the tRNA anticodon is complementary and antiparallel.

Guided question

Why can shifting the reading frame change every downstream codon?

Independent work

  1. Translate three fictional mRNAs.
  2. Identify start and stop.
  3. Write one tRNA anticodon correctly oriented.
  4. Explain code degeneracy.

Misconception check

A codon is not an amino acid itself; it is an RNA sequence interpreted by the translation machinery.

Formative understanding check

What amino acid does AUG specify in the standard table?

Worked response

Methionine and commonly the start signal.

Week 24 information-flow checkpoint

Phenomenon: Translation reads mRNA codons in a defined frame. tRNA anticodons pair with codons, and the ribosome links amino acids into a polypeptide until a stop codon is reached.

Worked example: mRNA 5′-AUG GCU UAA-3′ translates as Met-Ala-stop using the standard genetic code. Reading from a different starting point changes every downstream codon, which is why frame matters.

Retrieval: Retrieve one DNA-replication idea from Week 23 and explain how transcription is similar and how it is different.

Evidence revision: Revise your explanation so strand direction, RNA processing, reading frame, codon logic, and sequence-change consequences are explicit where relevant.

Transfer: Predict how the outcome changes if strand choice, splice pattern, reading frame, or mutation position changes.

Advanced translation depth

Vocabulary in context: codon, anticodon, ribosome, tRNA, reading frame, start codon, stop codon, polypeptide.

Mechanism check: Translation depends on reading frame and direction. A codon table maps mRNA codons to amino acids; it does not read DNA directly and it does not identify where translation begins without a start context.

Evidence-quality task: Compare a raw DNA sequence, a predicted open reading frame, and a validated protein sequence. Rank the evidence for protein identity and explain why a computational prediction is not equivalent to experimental confirmation.

Quantitative transfer: For a 303-nucleotide coding region including one stop codon, determine the maximum number of amino acids encoded and explain whether the stop codon contributes an amino acid.
