Translation & the Genetic Code

Translate mRNA codons into amino-acid sequences while keeping codon, anticodon and reading frame distinct.

Weekly Classroom & EvidenceBiology CourseScience HallArchaemenesPrevious DayNext Day

Safety, privacy and evidence boundary

Use fictional DNA/RNA/protein sequences and standard codon tables. Do not use personal genomic data or infer disease from sequence examples. Sequence exercises are educational models, not clinical interpretation.

Explicit science instruction

Ribosomes read mRNA in nonoverlapping three-base codons. Transfer RNAs carry amino acids and use anticodons to pair with codons. Translation usually begins at a start codon in the selected reading frame and ends at a stop codon.

The standard code is degenerate: multiple codons can specify the same amino acid. It is nearly universal but has known biological exceptions.

Worked example with reasoning

mRNA 5′-AUG GCU UUU UGA-3′ translates Met-Ala-Phe-Stop using the standard code. The codon is on mRNA; the tRNA anticodon is complementary and antiparallel.

Guided question

Why can shifting the reading frame change every downstream codon?

Independent work

  1. Translate three fictional mRNAs.
  2. Identify start and stop.
  3. Write one tRNA anticodon correctly oriented.
  4. Explain code degeneracy.

Misconception check

A codon is not an amino acid itself; it is an RNA sequence interpreted by the translation machinery.

Formative understanding check

What amino acid does AUG specify in the standard table?

Worked response

Methionine and commonly the start signal.
