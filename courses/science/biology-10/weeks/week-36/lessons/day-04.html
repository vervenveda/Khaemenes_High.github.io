Purpose and instruction

A final correction is a learning artifact: identify the error class, explain why the original reasoning failed, state the corrected principle, and transfer the principle to a fresh public-safe example. Correction should preserve the original record rather than overwrite history.

Protected final questions stay inside the supervised correction process. Public notes should summarize the biological concept without reproducing confidential item wording.

Student task

  1. Classify each assigned correction.
  2. Write the corrected principle.
  3. Redo the reasoning as permitted by the supervisor.
  4. Create a parallel example with different numbers/context.
  5. Explain how the correction changes your course concept map.

Mastery check

A copied answer is not correction evidence. Mastery is demonstrated when the principle transfers to a new context.

Week 36 correction-and-transfer checkpoint

Phenomenon: A wrong final answer can come from a correct concept paired with a bad assumption, a calculation error, or an overextended interpretation. Correction should diagnose which layer failed.

Vocabulary in context: misconception, revision, evidence, assumption, transfer, reassessment.

Worked correction: Replace “the model was wrong” with a precise diagnosis such as “I treated correlation as causation” or “I used genotype probability as though it were observed population frequency.”

Evidence-quality task: For each correction, cite the evidence or rule that invalidates the original reasoning and show the revised reasoning path.

Transfer: Apply the corrected principle to a new biological context so the revision demonstrates learning rather than answer memorization.

Correction retrieval bridge

Retrieval: Revisit one corrected misconception from genetics, one from evolution, and one from ecology. For each, state the original error, the evidence that corrected it, and how the corrected principle applies in a new context.
