Unit 06 · Day 9

Electron Configurations for Elements 1–20

Represent electrons in simplified shells and connect configurations to atomic number.

45–60 minutesEvidence and modelsPortfolio evidence

Learning objectives

  • Write shell configurations for elements 1–20
  • Check that electron totals equal atomic number for neutral atoms
  • Recognize the limits of the simplified shell model

Materials

  • Notebook or digital record
  • Periodic table or supplied dataset
  • Calculator where required
Chemistry and radiation safety

Do not handle reactive alkali metals, concentrated halogens, unknown salts, open flames, radioactive minerals, smoke-detector sources, or unknown electrical equipment. Use published data, safe simulations, or a qualified laboratory protocol.

Evidence and source standard

Use NIST, CIAAW, IUPAC, official curriculum sources, or a documented laboratory record. Distinguish a measured spectrum or isotope abundance from an instructional model.

Simplified distribution

For the first 20 elements in this course, use shell totals such as 2,8,3. This is a curriculum model for pattern recognition.

Neutrality check

A neutral atom’s electron total equals its proton number.

Beyond the model

Actual electronic structure uses orbitals and quantum states. The shell model is useful but incomplete.

Portfolio evidence

Write and verify configurations for all first-20 elements; mark period and valence count.

Model boundary

Atom and shell diagrams are not literal scale drawings or photographs. They simplify size, distance, probability, and electron behavior.

Essential question and conceptual model

Essential question: How does a simplified shell configuration connect atomic number to periodic patterns for the first 20 elements?

For the first 20 elements, this course uses a simplified shell-count model to make recurring outer-electron patterns visible. A neutral atom has as many electrons as protons. The first shell is represented with up to 2 electrons, and the next shells are simplified for introductory pattern work so configurations such as 2,8,1 or 2,8,8,2 can be used. This representation is intentionally limited: real electronic structure is described with orbitals, subshells, and quantum states.

Worked reasoning example

Sodium has atomic number 11, so a neutral sodium atom has 11 electrons. In the course model: 2 in the first shell, 8 in the second, 1 in the outer shell → 2,8,1. Calcium has atomic number 20 → 2,8,8,2. Check every configuration by adding the shell totals and confirming that the sum equals atomic number for a neutral atom.

Vocabulary and misconception checks

Vocabulary: electron configuration · shell · valence electron · neutral atom · outer shell

Misconception check: The simplified '2,8,8...' pattern is not a universal rule for all elements. It is a deliberately limited first-20 model for recognizing introductory periodic patterns.

Retrieval and explanation practice

Answer from memory first. Then reopen the lesson, check each response, and write a correction wherever your explanation is incomplete or overstates the evidence.

  1. Write shell configurations for atomic numbers 8, 11, 17, and 20.
  2. Use electron total to check whether a neutral-atom configuration is internally consistent.
  3. Identify the valence-electron count from a first-20 shell configuration.
  4. State one limitation of the shell-count model.

Mentor evidence conference

Use the Science Mentor to test your reasoning, not to obtain scored answers. Bring a written model, calculation, graph, or evidence statement and be ready to revise it.

  • How does your configuration connect to atomic number rather than to atomic mass?
  • Which periodic prediction can you make from the outer-electron count?
  • Where would this simplified model stop being adequate?
