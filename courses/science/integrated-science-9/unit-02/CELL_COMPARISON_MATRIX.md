# Cell Comparison Matrix
| Feature | Typical bacterium | Typical animal cell | Photosynthetic plant cell | Fungal cell |
|---|---|---|---|---|
| Plasma membrane | Yes | Yes | Yes | Yes |
| Cytoplasm | Yes | Yes | Yes | Yes |
| Ribosomes | Yes | Yes | Yes | Yes |
| DNA | Yes | Yes | Yes | Yes |
| Membrane-bound nucleus | No | Yes | Yes | Yes |
| Mitochondria | No | Yes | Yes | Yes |
| Cell wall | Common; not cellulose | No | Cellulose | Chitin-rich |
| Chloroplasts | No | No | In photosynthetic cells | No |
| Large central vacuole | No | No | Common | Vacuoles may be present |

These are common patterns, not universal claims about every species or cell type.
