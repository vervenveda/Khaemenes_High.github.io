Virtual Gas-Law Investigation

Use a simulated dataset to test pressure–volume and temperature–volume models.

Weekly EvidenceChemistry CourseScience Hall

Explicit science instruction

A good gas-law investigation varies one target variable while controlling the others. This makes the selected proportional model testable.

Preserve raw pressure, volume, temperature, and amount values before transforming the data. Then graph a relationship that should linearize under the model.

Residuals and uncertainty matter: a near-linear trend supports a model within the tested range but does not prove ideal behavior under all conditions.

Vocabulary: controlled variable; transformed graph; linearization; residual; uncertainty.

Worked example with reasoning

Synthetic Boyle data: (1.0 atm, 4.0 L), (2.0, 2.0), (4.0, 1.0). PV is 4.0 L·atm for each point, and P versus 1/V is linear.

Guided question

Which variables must remain controlled to test Boyle’s law rather than a mixture of several gas-law effects?

Independent work

  1. Preserve the raw simulated dataset.
  2. Calculate PV or V/T for each trial as appropriate.
  3. Create one transformed graph.
  4. Identify one residual or uncertainty and revise the model claim if needed.

Investigation / Data Lab

Preserve raw P–V–T–n values, transformed calculations, graph, residuals, model assumptions, and one revision.

Misconception check

A clean graph is not evidence of causation if several variables changed at once.

Formative understanding check

What is the purpose of linearizing a gas-law dataset?

Reveal response

It makes a predicted proportional relationship easier to evaluate quantitatively.

Mentor evidence conference

Ask Archaemenes to check the model assumptions, unit logic, and physical direction of the result.

Teacher guidance

Foundation: Use a supplied data table and graph template.

Core: Test one gas-law model with transformed data.

Extended: Compare two candidate models using residual patterns and justify the stronger one.
