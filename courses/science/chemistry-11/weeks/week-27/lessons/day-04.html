Week 27 chemistry depth checkpoint

Phenomenon: A perturbation simulation can separate immediate composition changes from the later net reaction that restores equilibrium.

Retrieval: Use Days 1–3 to predict concentration, pressure/volume, and temperature disturbances before running the model.

Quantitative transfer: Record pre-disturbance values, the instantaneous post-disturbance state, and the new equilibrium state; compare Q with K at the middle step.

Evidence-quality task: Change one condition at a time and preserve the same reaction definition.

Evidence revision: If the simulation contradicts the prediction, audit the disturbance setup before changing the underlying model.

Uncertainty: Simulations may idealize activities, gas behavior, and heat transfer.

Perturbation-lab extension

Compare two disturbances and identify which one changes Q only and which one changes K itself. Explain the evidence chain for each.

Three-state data extension

For each simulated disturbance, record three states: original equilibrium, immediate post-disturbance, and restored equilibrium. Calculate or estimate Q in the first two states. The original equilibrium should have Q=K; the disturbed state should show why net reaction begins; the final state should again satisfy Q=K under the new conditions.

For temperature changes, note that K itself changes, so the final benchmark is different.

Simulation-control extension

Run a no-disturbance control long enough to confirm the simulated equilibrium is stable before applying a perturbation. Then repeat the same disturbance from different starting equilibria if possible to test whether the Q/K reasoning generalizes rather than fitting one prepared example.

Record whether the displayed values are concentrations, partial pressures, or particle counts so the equilibrium expression matches the data type.

Final simulation check

Verify that each simulated run changes only the intended variable and that the same equilibrium expression is used throughout.

Inert-gas and catalyst distinction

At constant volume, adding an inert gas raises total pressure but does not change the reacting species' partial pressures, so Q remains unchanged in the ideal model. At constant pressure, volume may change and the reacting partial pressures can shift. A catalyst changes neither Q nor K; it only changes the rate at which equilibrium is approached. These cases show why total-pressure slogans are weaker than an explicit Q/K analysis.
