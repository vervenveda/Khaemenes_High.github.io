Inquiry Question & Competing Models

Turn a kinetics phenomenon into a testable question with competing explanations.

Weekly EvidenceChemistry CourseScience Hall

Safety boundary

Use supplied datasets and approved simulations. Any physical demonstration must be teacher-supervised and explicitly classroom-safe; no improvised reactive mixtures.

Explicit chemistry instruction

A strong inquiry question identifies the measured response, the variable being changed, and the conditions that must remain controlled.

Competing models should make different predictions that can be tested with the same dataset or simulation.

Write predictions before seeing the result to reduce hindsight bias.

Vocabulary: hypothesis; competing model; independent variable; dependent variable; prediction.

Worked example

Model A predicts rate doubles when concentration doubles; Model B predicts rate quadruples. A controlled concentration series can distinguish them.

Guided question

Write two competing predictions for how rate might depend on concentration.

Independent work

  1. Define one kinetics question.
  2. Write two competing models.
  3. List controls and predicted outcomes.

Misconception check

A hypothesis should predict an observable result, not merely restate the question.

Formative check

What makes competing models scientifically useful?

Reveal response

They make distinguishable predictions that evidence can compare.

Mentor evidence conference

Ask Archaemenes to audit controls, competing predictions, residuals, uncertainty, and whether the conclusion exceeds the evidence.

Teacher guidance

Foundation: Use question-variable frames.

Core: Design a model-discrimination plan.

Extended: Evaluate whether predictions are sufficiently distinct.

Week 22 chemistry depth checkpoint

Phenomenon: Strong inquiry begins with competing models that make different testable predictions.

Retrieval: Use Week 21 mechanism-evidence logic to formulate an inquiry question that can actually discriminate explanations.

Quantitative/model transfer: Translate each candidate model into at least one measurable prediction about rate, concentration dependence, temperature effect, or catalyst response.

Evidence-quality task: Avoid questions so broad that every outcome can be explained after the fact.

Evidence revision: If two models predict the same observable outcome, redesign the test around a more discriminating variable.

Model limit: A single experiment may reduce uncertainty without uniquely identifying one mechanism.

Competing-model extension

Write two rival explanations for the same kinetic phenomenon and specify one observation that would support each and one observation that would count against it.

Discriminating-prediction extension

A useful competing model must make a prediction that could fail. For example, Model A may predict first-order dependence on a reactant while Model B predicts zero-order dependence. A concentration series can then distinguish the models more effectively than a single trial.

Write the expected pattern before seeing data so the interpretation is not retrofitted after the result is known.

Prediction-quality note

A competing model should make a measurable prediction that could be contradicted; otherwise it cannot be discriminated experimentally.

Final prediction note

Pre-register the expected pattern for each model before examining the data so the final interpretation is not shaped retroactively.

Model-contrast note

State the exact observable pattern that would favor one model over another so the inquiry has a clear decision rule.

Pre-registered prediction extension

Write the predicted numerical or graphical pattern for each competing model before examining the dataset. A prediction should specify not only direction but enough structure to be falsifiable—for example, proportional, quadratic, zero-order, or threshold-like response. Pre-registering the decision rule reduces hindsight bias and prevents a model from being retrofitted to any outcome after the fact.
