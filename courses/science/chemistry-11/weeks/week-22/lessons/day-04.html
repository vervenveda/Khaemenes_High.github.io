Kinetics Inquiry Investigation

Execute a simulation/supplied-data inquiry and revise the model from evidence.

Weekly EvidenceChemistry CourseScience Hall

Safety boundary

Use supplied datasets and approved simulations. Any physical demonstration must be teacher-supervised and explicitly classroom-safe; no improvised reactive mixtures.

Explicit chemistry instruction

Use the approved dataset or simulation to test the inquiry question.

Preserve raw conditions and rate measurements before graphing or fitting.

Compare the competing predictions, document uncertainty, and revise the model only as far as the evidence supports.

Vocabulary: inquiry; evidence; model comparison; uncertainty; revision.

Worked example

Observed rate ratios 1:2:4 across concentration ratios 1:2:4 support a proportional model better than a quadratic model over that tested range.

Guided question

Which evidence would falsify your initial preferred model?

Independent work

  1. Preserve raw trial data.
  2. Graph the relationship.
  3. Compare both predictions.
  4. Write a revision supported by residuals and uncertainty.

Investigation / Data Lab

Use supplied/simulated data. Preserve raw trials, model predictions, graphs, residuals, uncertainty, revision, and next-test plan.

Misconception check

An inquiry is not successful only when the original hypothesis is confirmed.

Formative check

What makes a model revision scientifically strong?

Reveal response

It responds to evidence and states the tested range and remaining uncertainty.

Mentor evidence conference

Ask Archaemenes to audit controls, competing predictions, residuals, uncertainty, and whether the conclusion exceeds the evidence.

Teacher guidance

Foundation: Use supplied data if simulation access is limited.

Core: Complete full compare-and-revise cycle.

Extended: Quantify model uncertainty and propose a discriminating next test.
