Kinetics Inquiry Investigation

Execute a simulation/supplied-data inquiry and revise the model from evidence.

Weekly EvidenceChemistry CourseScience Hall

Safety boundary

Use supplied datasets and approved simulations. Any physical demonstration must be teacher-supervised and explicitly classroom-safe; no improvised reactive mixtures.

Explicit chemistry instruction

Use the approved dataset or simulation to test the inquiry question.

Preserve raw conditions and rate measurements before graphing or fitting.

Compare the competing predictions, document uncertainty, and revise the model only as far as the evidence supports.

Vocabulary: inquiry; evidence; model comparison; uncertainty; revision.

Worked example

Observed rate ratios 1:2:4 across concentration ratios 1:2:4 support a proportional model better than a quadratic model over that tested range.

Guided question

Which evidence would falsify your initial preferred model?

Independent work

  1. Preserve raw trial data.
  2. Graph the relationship.
  3. Compare both predictions.
  4. Write a revision supported by residuals and uncertainty.

Investigation / Data Lab

Use supplied/simulated data. Preserve raw trials, model predictions, graphs, residuals, uncertainty, revision, and next-test plan.

Misconception check

An inquiry is not successful only when the original hypothesis is confirmed.

Formative check

What makes a model revision scientifically strong?

Reveal response

It responds to evidence and states the tested range and remaining uncertainty.

Mentor evidence conference

Ask Archaemenes to audit controls, competing predictions, residuals, uncertainty, and whether the conclusion exceeds the evidence.

Teacher guidance

Foundation: Use supplied data if simulation access is limited.

Core: Complete full compare-and-revise cycle.

Extended: Quantify model uncertainty and propose a discriminating next test.

Week 22 chemistry depth checkpoint

Phenomenon: A kinetics inquiry should connect a controlled intervention, reproducible rate measurement, and a model-based prediction.

Retrieval: Combine Days 1–3 competing models, experimental controls, and model fitting.

Quantitative transfer: Collect or analyze replicate rate data, calculate a summary statistic, and compare results with each model's prediction.

Evidence-quality task: Preserve raw data, replicate spread, control outcomes, and any deviations from the intended procedure.

Evidence revision: If neither model fits, report that result and propose a revised model rather than forcing a winner.

Uncertainty: Experimental noise and model uncertainty should be reported separately when possible.

Inquiry-analysis extension

Use the data to state which model is better supported, which evidence drives that conclusion, and what result would have changed your decision.

Inquiry-evidence extension

Report replicate means together with spread rather than only a single averaged number. If two model predictions differ by less than the experimental variation, the data may be insufficient to discriminate them even when the means are numerically different.

Document any deviation from the planned procedure and decide whether it warrants excluding, retaining, or repeating a trial. Exclusion should be justified by a procedural reason, not simply because a point weakens the preferred model.

Inquiry-traceability note

Keep raw trials, excluded points, procedural deviations, and model decisions traceable so the conclusion can be audited independently.

Final inquiry note

Report when the data are insufficient to distinguish models; uncertainty is a valid scientific outcome when evidence overlaps.
