Assessment boundary

This week contains public formative review, evidence audit, and correction support only. Protected midterm questions, answer keys, grading logic, and authentication details remain outside the learner-facing repository.

Explicit chemistry instruction

The midterm spans atomic structure, bonding, molecular geometry, materials, intermolecular forces, gases, solutions, analytical methods, reactions, and stoichiometry.

A readiness map should connect each model to its evidence, equations, assumptions, and common errors rather than becoming an equation dump.

Use prior learner evidence to identify genuine weak areas. Do not create artificial 'mastery' from unchecked review.

Vocabulary: readiness map; model family; evidence; assumption; weakness.

Worked example

A gas-law problem requires identifying controlled variables before choosing an equation; a stoichiometry problem requires a balanced equation and unit pathway before arithmetic.

Guided question

Create a map with at least six model families and one representative evidence type for each.

Independent work

  1. Build a semester concept map.
  2. List two common errors per model family.
  3. Choose three authentic weak areas for targeted correction.

Misconception check

Broad review is not the same as mastery; evidence must support the claim.

Formative check

Reveal response

Models, evidence, assumptions, and common errors.

Week 18 midterm readiness checkpoint

Purpose: Map mastery across Weeks 01–17 without exposing protected summative items.

Retrieval: Build a concept map spanning measurement, atomic models, isotopes, bonding, gases, solutions, analytical chemistry, reactions, stoichiometry, and redox.

Evidence-quality task: Mark each topic as secure, developing, or needs correction using actual work evidence rather than confidence alone.

Quantitative transfer: Select one representative calculation from each major quantitative strand and solve it without notes before checking.

Evidence revision: Convert every error into a written correction rule or worked replacement example.

Boundary: This page supports readiness and correction only; official supervised midterm authority remains separate.

Readiness-map extension

Choose the three weakest strands and create a targeted review sequence that addresses prerequisite gaps before harder applications.

Readiness evidence extension

For every major strand, attach one concrete piece of evidence: a correctly solved quantitative problem, a revised model, a laboratory/data artifact, or a CER. A self-rating without evidence is only a confidence measure, not a mastery record.

Use prerequisite logic when planning review. For example, weak stoichiometry may trace back to molar-mass or balanced-equation gaps; weak solution stoichiometry may trace back to molarity or mole-ratio errors. Repair the earliest weak link first.

Readiness-validation note

Any strand marked secure should be supported by at least one no-notes retrieval task and one evidence artifact. Confidence alone is not enough.
