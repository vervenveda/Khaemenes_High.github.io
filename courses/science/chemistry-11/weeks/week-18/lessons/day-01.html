Midterm Readiness Map

Organize Weeks 01–17 into connected model families for efficient review.

Weekly EvidenceChemistry CourseScience Hall

Assessment boundary

This week contains public formative review, evidence audit, and correction support only. Protected midterm questions, answer keys, grading logic, and authentication details remain outside the learner-facing repository.

Explicit chemistry instruction

The midterm spans atomic structure, bonding, molecular geometry, materials, intermolecular forces, gases, solutions, analytical methods, reactions, and stoichiometry.

A readiness map should connect each model to its evidence, equations, assumptions, and common errors rather than becoming an equation dump.

Use prior learner evidence to identify genuine weak areas. Do not create artificial 'mastery' from unchecked review.

Vocabulary: readiness map; model family; evidence; assumption; weakness.

Worked example

A gas-law problem requires identifying controlled variables before choosing an equation; a stoichiometry problem requires a balanced equation and unit pathway before arithmetic.

Guided question

Create a map with at least six model families and one representative evidence type for each.

Independent work

  1. Build a semester concept map.
  2. List two common errors per model family.
  3. Choose three authentic weak areas for targeted correction.

Misconception check

Broad review is not the same as mastery; evidence must support the claim.

Formative check

What should a readiness map connect besides formulas?

Reveal response

Models, evidence, assumptions, and common errors.

Mentor evidence conference

Archaemenes may challenge reasoning and help plan corrections but cannot reveal protected answers or grant official mastery.

Teacher guidance

Foundation: Use a provided organizer.

Core: Build an evidence-linked map.

Extended: Identify cross-unit dependencies and misconceptions.
