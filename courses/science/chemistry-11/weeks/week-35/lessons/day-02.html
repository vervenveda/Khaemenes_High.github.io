Chemistry Model Selection

Choose the chemical models needed to predict candidate performance.

Weekly EvidenceChemistry CourseScience Hall

Safety boundary

Capstone work must use data, simulation, paper models, or teacher-approved low-risk materials only. Do not synthesize hazardous substances or improvise chemical processes.

Explicit capstone instruction

Different capstones may require stoichiometry, bonding, thermochemistry, equilibrium, acid/base, electrochemistry, materials, or lifecycle reasoning.

The model should match the target property and produce a testable prediction.

State assumptions and uncertainty before comparing candidates.

Vocabulary: model selection; prediction; assumption; mechanism; validation.

Worked example

If comparing battery chemistries, voltage and redox models address energy-per-charge while lifecycle data address material impacts.

Guided question

Which chemistry models best fit a reusable-container material comparison?

Independent work

  1. Select two or more chemistry models.
  2. Write one quantitative prediction.
  3. State assumptions.
  4. Define how evidence will test the model.

Misconception check

Using more chemistry topics is not better unless each one answers a real design question.

Formative check

What makes a model useful in the capstone?

Reveal response

It produces an evidence-linked prediction relevant to the criteria.

Mentor evidence conference

Ask Archaemenes to challenge criteria, chemistry models, evidence quality, tradeoffs, and uncertainty.

Teacher guidance

Foundation: Use a model-choice matrix.

Core: Connect models to criteria.

Extended: Compare alternative models and uncertainty.

Week 35 chemistry depth checkpoint

Phenomenon: Different chemistry models answer different parts of a sustainability problem.

Retrieval: Draw from stoichiometry, thermochemistry, kinetics, equilibrium, acid-base, electrochemistry, and materials/nuclear units.

Quantitative/model transfer: Match each project criterion to the chemistry model that can generate relevant evidence.

Evidence-quality task: Explain why a selected model is appropriate and identify at least one model that would be misleading for the same question.

Evidence revision: Replace “use every model” with a justified minimal set of models tied to the decision.

Model limit: No single chemistry model captures lifecycle, cost, safety, performance, and environmental impact simultaneously.

Model-selection transfer extension

Build a model-to-evidence map showing which chemistry framework supports each major capstone claim and what uncertainty remains.

Model-evidence fit extension

For each selected model, identify the input data it requires, the output it produces, and the assumptions that limit interpretation. For example, stoichiometry can estimate material demand, thermochemistry can compare energy changes, and equilibrium can constrain achievable composition, but none alone represents full lifecycle impact.

Use the smallest set of models that collectively supports the decision criteria.
