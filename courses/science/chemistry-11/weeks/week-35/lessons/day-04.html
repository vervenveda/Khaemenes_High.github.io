Capstone Evidence Investigation

Test or analyze the leading candidate using safe data, simulation, or approved low-risk materials.

Weekly EvidenceChemistry CourseScience Hall

Safety boundary

Capstone work must use data, simulation, paper models, or teacher-approved low-risk materials only. Do not synthesize hazardous substances or improvise chemical processes.

Explicit capstone instruction

Collect or use supplied evidence that directly tests the selected performance claim.

Preserve raw data before normalization, scoring, or lifecycle aggregation.

Compare measured or simulated performance with the prediction and record discrepancies.

Vocabulary: prototype evidence; validation; raw data; residual; revision.

Worked example

A material is predicted to retain 90% performance after a simulated cycle but measures 82%; the −8 percentage-point residual should trigger model/design review.

Guided question

Which measurement best tests your highest-priority criterion?

Independent work

  1. Preserve raw test/data records.
  2. Calculate at least one performance metric.
  3. Compare result with prediction.
  4. Make one evidence-based revision.

Design Investigation

Use safe data/simulation or approved low-risk materials only. Preserve raw evidence, metrics, prediction comparison, uncertainty, and one revision.

A capstone is not complete merely because a preferred candidate was chosen; the choice must be tested against evidence.

Week 35 chemistry depth checkpoint

Phenomenon: Capstone evidence should be traceable from raw data or credible sources through calculations to claims.

Retrieval: Apply the course-wide evidence chain: observation/source → processing → model → claim → uncertainty.

Quantitative transfer: Recalculate at least one major metric from raw values and test one alternative assumption.

Evidence-quality task: Track source conditions, units, date/version where relevant, and whether values are measured, estimated, or modeled.

Evidence revision: Replace unsupported averages or cherry-picked examples with a defensible data range or documented selection rule.

Uncertainty: State which uncertainty most threatens the recommendation and why.

Evidence-investigation extension

Audit one major project claim from source to conclusion and identify the weakest link in the evidence chain.

Source-quality extension

Rank sources by directness and transparency. Primary measurements or well-documented technical datasets generally provide stronger evidence for a quantitative claim than unsourced summaries. Check whether values were measured under conditions comparable to the project scenario.

If sources disagree, preserve the range and explain the likely cause rather than averaging incompatible values automatically.

Evidence-range extension

Where several credible sources report different values, preserve the range and test the project conclusion at both ends. If the recommendation survives the full range, confidence increases; if it flips, that input becomes a priority for better measurement.

This is stronger than replacing disagreement with one average that may hide meaningful variability.
