Evidence boundary

Use supplied spectra, reference tables, and approved simulations only.

Explicit science instruction

Spectroscopic identification is strongest when several measured lines agree with a reference pattern. One visually similar color is weak evidence.

Choose a numerical tolerance before comparing lines and apply it consistently. Document unmatched lines rather than hiding them.

Calibration and spectral resolution limit certainty, so conclusions should report both the match and the tolerance used.

Vocabulary: reference spectrum; calibration; spectral resolution; tolerance; pattern match.

Worked example with reasoning

Unknown lines are 411, 435, 487, and 655 nm. A reference lists 410, 434, 486, and 656 nm. Every difference is 1 nm or less, so the unknown strongly matches that reference under a ±2 nm rule.

Guided question

Compare an unknown line set with two fictional references and justify a tolerance before choosing the stronger match.

Independent work

  1. Create a reference/unknown difference table.
  2. Apply one stated tolerance consistently.
  3. Report the best-supported match and any unmatched feature.
  4. Propose one calibration check that would improve confidence.

Investigation / Data Lab

Preserve the raw line positions, difference calculations, tolerance rule, final match, uncertainty, and one revision.

Misconception check

Matching one line is not enough for strong identification; multiple independent matches provide stronger evidence.

Formative understanding check

Why is a multi-line pattern stronger evidence than one matching wavelength?

Reveal response

Multiple matches constrain the source more strongly and reduce the chance of coincidental agreement.

Mentor evidence conference

Ask Archaemenes to challenge your tolerance choice and whether it was applied consistently.

Teacher guidance

Foundation: Match lines using a supplied tolerance.

Core: Build a difference table and justify an identification.

Extended: Analyze how a systematic calibration offset would change the conclusion.

Return to Thursday Evidence

Week 4 chemistry depth checkpoint

Phenomenon: Element identification becomes more reliable when several measured spectral lines agree with one reference pattern within a justified tolerance.

Retrieval: Apply Day 3 wavelength reasoning while preserving raw measured lines before any pattern-matching decision.

Quantitative transfer: Compute residuals between unknown and reference lines, summarize the largest absolute residual, and test whether the identification survives a tighter tolerance.

Evidence-quality task: Distinguish random line-position scatter from a systematic calibration offset that shifts all measured wavelengths in one direction.

Evidence revision: If unmatched lines remain, consider contamination, mixed sources, calibration, or an incorrect reference rather than deleting inconvenient observations.

Uncertainty: Report the match together with tolerance and resolution; avoid absolute identification claims that exceed the evidence.

Spectral-identification transfer extension

Compare two candidate references to one unknown spectrum. Use residuals and a predeclared tolerance to choose the better-supported model, then identify one additional calibration check that could change the conclusion.

Residual-pattern extension

Do not evaluate a reference match only by counting successful lines. Inspect the residual pattern. Residuals clustered around zero with mixed signs suggest random measurement scatter, whereas residuals of similar magnitude and direction suggest systematic calibration bias. A single large residual may represent contamination, overlap, transcription error, or an additional source. Preserve that anomaly and test competing explanations rather than deleting it from the evidence set.
