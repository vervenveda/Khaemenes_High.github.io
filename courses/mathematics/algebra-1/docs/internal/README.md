# Algebra I Internal Development Archive

This directory preserves construction-era and migration artifacts that are useful for forensic history, maintenance, or future integration work but are not part of the finished learner-facing course surface.

Files under `legacy/` were relocated from the Algebra I course root during Audit #3. They were preserved byte-for-byte rather than deleted.

The learner-facing course root should contain production course resources, not upload instructions, migration notes, temporary QA reports, or construction manifests.

Academic runtime files, assessments, unit resources, records, learner interfaces, teacher/family resources, and the cross-course readiness contract remain outside this archive.
