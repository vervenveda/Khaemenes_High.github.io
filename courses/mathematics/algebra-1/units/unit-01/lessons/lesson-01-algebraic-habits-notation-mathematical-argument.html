Algebraic Habits, Notation & Mathematical Argument

How do notation, number systems, properties, units, and precision make mathematical claims trustworthy?

Lesson objectives

  • Distinguish a mathematical claim from its justification.
  • Use definitions and properties to justify algebraic steps.
  • Verify a proposed solution independently.
  • Construct or identify a counterexample to disprove a universal claim.

Read and reason

A claim needs a reason

A mathematical claim says what is true; an argument explains why. “x=6” is a candidate answer, while substituting 6 into the original equation supplies evidence. In algebra, a chain of equal expressions should be supported by definitions or properties. Name the operation that preserves equality rather than saying that a term moves and changes sign. Subtracting 5 from both sides explains the change; moving a symbol does not.

Equality and equivalence have a scope

An equation can be true for only certain inputs. Equivalent expressions have the same value for every input in their shared domain. The distributive property proves 3(x+2)=3x+6 for every real x. Testing x=1 confirms only that case. A few matching values can catch an error or support a conjecture, but do not prove an identity for all real inputs. A definition such as “an even integer is divisible by 2” tells us what a term means.

Verification and counterexamples

Solving derives a candidate; verification returns to the original statement and tests it independently. To disprove an “always” claim, one allowed input that fails is sufficient. It must belong to the stated domain: a fractional counterexample is valid for a claim about all real numbers, but not for a claim restricted to integers. When explaining your reasoning, state the claim, the rule or evidence, and the conclusion, including any restrictions.

Worked examples

  1. Solve and verify 4x−7=13.
    1. Add 7 to both sides: 4x=20. This preserves equality.
    2. Divide both sides by 4, which is nonzero: x=5.
    3. Check in the original: 4(5)−7=20−7=13.
  2. Disprove: x²≥x for every real x.
    1. Choose an input in the real-number domain, x=1/2.
    2. Compute x²=1/4 and x=1/2.
    3. Since 1/4<1/2, the claimed inequality fails. One counterexample disproves the universal claim.

Independent reasoning task

Decide whether “every integer is positive” is true. Give an allowed counterexample, then rewrite the claim so it is true. Explain the distinction between evidence for one case and an argument about every case.
