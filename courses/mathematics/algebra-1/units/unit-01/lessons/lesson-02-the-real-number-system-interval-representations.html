The Real Number System & Interval Representations

How do notation, number systems, properties, units, and precision make mathematical claims trustworthy?

Unit 01 HomeAlgebra I HomeReadiness Diagnostic

Lesson objectives

  • Classify numbers in the smallest appropriate real-number set.
  • Distinguish rational from irrational numbers using definitions.
  • Translate inequalities to interval notation and back.
  • Distinguish exact values from decimal approximations.

Read and reason

Classify by definitions

We use natural numbers 1,2,3,… and whole numbers 0,1,2,3,… in this course. Integers include their negatives. A rational number is a ratio p/q of integers with q≠0, so every integer is rational: −7=−7/1. Terminating and repeating decimals are rational. An irrational real number cannot be written as such a ratio; its decimal expansion neither terminates nor repeats. State the smallest set when asked, while recognizing all larger sets that contain it.

A radical does not guarantee irrationality

The number √49 is exactly 7, while √50=5√2 is irrational. Simplify or use definitions before classifying. A finite decimal approximation to √2 is rational as written, but the exact value √2 is irrational. Use = for exact equality and ≈ for an approximation. Do not treat a calculator display as the entire decimal expansion of an irrational number.

Intervals describe sets of inputs

For a real variable, square brackets include endpoints and parentheses exclude them. Thus −2≤x<5 is [−2,5). Infinity is not a real endpoint and always uses a parenthesis. The interval (−∞,4] represents all real x≤4, not only integers. A context can impose a separate restriction, such as whole-number counts; say so rather than assuming the interval by itself imposes it.

Worked examples

  1. Classify −3, 0.125, √36 and √7.
    1. −3 is an integer and also equals −3/1.
    2. 0.125=125/1000=1/8, so it is rational but not an integer.
    3. √36=6, a natural number under our convention.
    4. 7 is not a perfect-square integer, so √7 is irrational.
  2. Translate −4<x≤2 into interval notation.
    1. The inequality excludes −4, so the left endpoint uses a parenthesis.
    2. It includes 2, so the right endpoint uses a bracket.
    3. Check: −4 is excluded, 0 is included and 2 is included. Values above 2 are excluded.

Independent reasoning task

Create a number belonging to each of these smallest sets: whole but not natural, integer but not whole, rational but not integer, irrational. Justify each classification and explain which larger sets also contain it.
