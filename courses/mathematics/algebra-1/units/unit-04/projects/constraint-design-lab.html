Unit 04 · Mission Board

Constraint Design Lab

Build a real decision system using inequalities, compound conditions, or absolute-value tolerances, then justify the feasible region.

Unit Home

Mission choices

  • Design amusement-ride height requirements.
  • Create a manufacturing tolerance rule.
  • Model a budget with minimum and maximum constraints.
  • Define safe temperature or storage ranges.
  • Create an eligibility rule using AND/OR conditions.
  • Propose your own feasible-region problem.

Required evidence

  • Define variables and units.
  • Write each constraint symbolically.
  • Represent it on a number line and in interval notation.
  • Explain open versus closed boundaries.
  • Use AND/OR correctly when combining rules.
  • Include an absolute-value tolerance when appropriate.
  • Test one allowed and one rejected value.
  • Explain what the final feasible set means.
