# Algebra I Resource Studio — review staging

The standalone `index.html` is intentionally **unlinked** from active lessons and official assessments during beta testing.

## Resource coverage

- Reading: proof/evidence, intervals and number classification, dimensional analysis, measurement precision.
- Worksheets: two independent, printable four-question sets, with answer guides excluded from print output.
- Learning tool: bounded interval number line (-8 to 8); visible inequality text and SVG description.
- Game: four explanation-rich reasoning questions with one check per answer and optional reset.

## Limits and safeguards

- Does not read/write localStorage, network data or the Academy evidence system.
- Has no authoritative 80% mastery gate or certified exam score; cannot unlock lessons.
- No third-party dependencies or downloads.
- Works offline as a single file after download, subject to browser SVG/printing support.
- The tool deliberately only supports finite integer endpoints from -8 through 8. Infinite intervals and noninteger endpoints require a future, separately reviewed feature.
- The teacher key stays hidden from printed student copies regardless of on-screen visibility.
- The worksheet is enrichment; it is not an alternative path to course credit.

## Quality gates before publishing links

1. Browser check: worksheet selection, focus order, all buttons, and teacher-key toggle.
2. Print checks: both question sets produce questions + working spaces, not answers; test blank and after revealing teacher key.
3. Interval tests: (-3,2], [-8,8], equal endpoints (rejected), swapped endpoints (rejected).
4. Game tests: unanswered check, wrong/correct selections, check-after-answer, complete round and restart.
5. Accessibility: keyboard-only and screen-reader inspection, zoom 200%, text diagram equivalence.
6. Review every mathematical worked answer and retain STOS and 80% progression unchanged.
7. Integrate only after beta testing and compare against the already deployed lesson resource map.
