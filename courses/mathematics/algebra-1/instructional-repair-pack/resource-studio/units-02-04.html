Unit 02 — Expression structure

An expression represents a value without asserting an equality. Terms are joined by addition or subtraction; a coefficient multiplies a variable or term. In 3(2x−5)+4x, distribution gives 6x−15+4x, then combining like terms gives 10x−15.

Why? Distributing 3 means multiplying both 2x and −5. Combining 6x and 4x uses the distributive property in reverse. Testing x=2 gives 5 in both expressions, but testing one input alone does not prove equivalence.

Common mistake: 3(2x−5)=6x−5 ignores the −5 factor. Re-expand to check.

Unit 03 — Equation balance

Each equality step must preserve the solution set. To solve 3x+5=20, subtract 5 from each side: 3x=15. Divide both sides by the nonzero number 3: x=5. Substitute in the original: 3(5)+5=20.

Compare: 2(x+1)=2x+2 is true for every real x (identity); 2(x+1)=2x+3 has no solution (contradiction). Solving should reveal that difference rather than invent an x-value.

Unit 04 — Inequalities and order

Multiplying or dividing an inequality by a negative number reverses the inequality because multiplication by a negative reverses order. For −2x < 6, divide both sides by −2: x > −3.

Test x=0: 0<6 is true. Test x=−4: 8<6 is false. Draw an open circle at −3 and shade right. In compound inequalities, AND represents intersection; OR represents union.
