# algebra functions systems challenge

A standalone, free Algebra I formative practice game covering **Units 05–07**. Contains **16** questions, explanations for each answer, a one-check-per-question flow, a Next control, and Restart. Works as a single HTML file without dependencies.

- Entry point: [index.html](./index.html)
- Original review source: [units-05-07-challenge.html](../../../algebra-1/instructional-repair-pack/resource-studio/units-05-07-challenge.html)
- Use: optional practice only, never official assessment or mastery evidence.
- Privacy: no storage, learner IDs, network requests, or tracking.
- Controls: select one answer; Check; read corrective feedback; Next; Restart clears only this practice run.
- Accessibility: label-based choices and live feedback; keyboard and mobile QA still recommended.
- Validation: check incorrect selections, unanswered Check, Next before Check, full round, end state, restart and content accuracy. Preserve all existing mathematics games and learner records.

**No automatic integration:** lesson links, game registry, service worker, and graded activities remain unchanged during beta testing.
