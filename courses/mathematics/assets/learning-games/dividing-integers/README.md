## Canonical Shared-Game Migration · Quotient Check v3

This directory is the canonical Mathematics copy for division structure.

Supported course modes:
- `?course=prealgebra&unit=02&lesson=07&mode=integer-division` — signed integer quotients, inverse checks, zero logic, and signed rates
- `?course=algebra1&unit=03&lesson=01&mode=inverse-operations` — division as an inverse operation, equation isolation, and solution verification
- `?course=algebra2&unit=04&lesson=u04-l01&mode=rational-restrictions` — rational-expression simplification with original denominator restrictions preserved

Geometry is intentionally not mapped to this game. Its strongest division applications are ratios, similarity, scale, and trigonometric ratios, which belong to the proportional-reasoning game family and should not be duplicated here.
