Division uses the same sign logic as multiplication.

For nonzero integers, matching signs produce a positive quotient and different signs produce a negative quotient.

Same → positive. Different → negative.
−42 ÷ 7 = −6
Check by reversing the division.
(−6)(7) = −42
quotient × divisor = dividend ✓

Every quotient should survive an inverse check.

Multiplication verifies the quotient. This catches many sign errors immediately.

quotient × divisor = dividend
Suppose 8 ÷ 0 = q.
Then the inverse check would require q × 0 = 8.
But every q × 0 = 0.
No quotient can work → 8 ÷ 0 is undefined.

Division by zero fails the inverse test.

There is no number that can be multiplied by zero to recover a nonzero dividend.

0 ÷ nonzero = 0, but nonzero ÷ 0 is undefined.

Division can find a signed rate.

A negative total change split across positive equal intervals gives a negative change per interval.
