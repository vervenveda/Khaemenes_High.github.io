# Equation Balance Lab · Khaemenes Academy

Original sovereign mathematics game, 100% vanilla HTML/CSS/JavaScript. No CDN, remote assets, third-party code, tracking, or network calls. Works as a local file and on GitHub Pages.

## Installation
Extract `equation-balance-lab/` into:
`courses/mathematics/assets/learning-games/equation-balance-lab/`

Launch `index.html` directly for independent testing. **Do not replace existing lesson or game files.** After QA, connect the canonical URL through the Academy shared-game launcher and game registry to suitable Algebra I equation-solving lessons. Integration and grading are deliberately not automatic.

## Levels
1. One-step equations (including additive and multiplicative forms)
2. Two-step equations
3. Variables on both sides

Features: infinitely generated integer-solution equations, recent-question avoidance, explanation and substitution check, local progress, JSON export, optional synthesized sound, accessible form controls, responsive parchment interface, reduced-motion support.

## Important learning policy
The game tracks **answer-attempt accuracy**, not formal course mastery. An incorrect answer does not reset a challenge or session. Teacher and course engines retain authority over assessment and the 80% course mastery rule.

## Test checklist
- Solve and check examples in all three levels, including negative and zero solutions.
- Test wrong answers, correction, new challenge, level switching and session reset.
- Test keyboard-only navigation, narrow mobile screens, sound toggle and offline use.
- Confirm no duplicate game folders and correct shared launcher integration before publishing.
