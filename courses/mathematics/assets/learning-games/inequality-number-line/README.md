# Inequality Number Line · Khaemenes Academy

Original sovereign single-file mathematics game. No external dependencies, tracking, or video assets.

## Installation
Extract the folder into `courses/mathematics/assets/learning-games/inequality-number-line/` in the High School repository. Open `index.html` directly or on GitHub Pages.

## Suggested lessons (do not auto-wire without audit)
- Algebra I Unit 04 Lesson 02: One-Step & Multi-Step Linear Inequalities.
- Additional lessons on graphing inequalities, subject to lesson-by-lesson fit.

## Learning design
Levels 1–3 cover basic graphing, positive-coefficient solving, and negative-coefficient solving. Each challenge has an exact integer endpoint, strict/inclusive circle, and left/right ray. All operations are generated with a known valid solution.

## Release notes
Practice accuracy is not an official course mastery grade. Progress is saved locally and can be exported. Students may retry after mistakes. Keyboard-operable form controls and an accessible textual description accompany the SVG number line.
