Benchmarks can end a comparison quickly.

Before converting or finding an LCD, ask whether a familiar value such as 0, 1/2, or 1 settles the question.

Common denominators create like units.

Once denominators match, numerators count the same-sized pieces and can be compared directly.

Same unit → compare the counts.
5/7 ? 7/10
5×10 = 50
7×7 = 49
50 > 49therefore 5/7 > 7/10
