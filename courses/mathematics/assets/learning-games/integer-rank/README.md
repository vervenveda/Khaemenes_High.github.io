The lesson’s central idea is that number-line position determines order: values increase to the right, and among negative integers the value closer to zero is greater. It also explicitly warns students not to confuse absolute value with signed order.

I built the Animated Instruction Studio around four ideas:

Farther Right = Greater — visually compares −8 and −3.
Negative Number Trap — shows why −15 < −6 even though 15 > 6.
Order a Set — animates 4, −6, 0, −1, 7 into −6, −1, 0, 4, 7.
Magnitude ≠ Order — contrasts |−12| > |−5| with the signed comparison −12 < −5.

The game missions include inequality symbols, greatest/least values, least-to-greatest and greatest-to-least ordering, number-line logic, temperatures, elevations, finance, absolute-value traps, counterexamples, and expressions such as:

−|7|, −2, 0, |−3|

which students must first evaluate and then correctly order.
