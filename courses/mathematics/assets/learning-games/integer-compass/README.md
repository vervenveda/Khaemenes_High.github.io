The new game includes:

Animated Zero / Reference Point number line — students watch a marker move negative, positive, and back to zero while zero remains the reference.
Sign + Magnitude animation — visually separates −12 into the negative sign = direction and `12 = magnitude**.
Context translator — temperature, money, elevators, elevation, sports, and net change animate into signed integers.
Changing Reference Point — the same physical location can be +8 relative to sea level but −3 relative to a different zero. This directly supports the lesson's Extended pathway.
Mixed Integer Compass missions — context-to-integer, zero interpretation, reference-point reasoning, sign vs. magnitude, integer identification, phrase translation, and error detection.
Foundation / Core / Extended pathways, 12/16/20 mission rounds, missed-question review, streak scoring, local best score, and an 80% mastery target.

One thing I deliberately avoided was letting the game drift ahead into integer operations. Unit 2 places opposites/absolute value in Lesson 2, comparison in Lesson 3, addition in Lesson 4, and subtraction/multiplication/division after that. This game stays focused on the conceptual foundation Lesson 1 is supposed to establish.

For example, a student may see:

“A diver is 30 feet below sea level, but a student writes +30 ft.”

The game does not merely say “wrong.” It distinguishes:

Magnitude: 30 is correct.
Direction/sign: should be negative.
Correct representation: −30 ft.

Or:

“Net change = 0 customers.”

The student has to distinguish no net change from the incorrect interpretation that the business had zero customers.

The more advanced missions also address a subtle but important idea from the lesson:

A signed number alone does not tell you the unit or story.

So −12 might mean 12 feet below a reference, a decrease of 12, or movement 12 units in the negative direction—but without context we cannot automatically claim it means a $12 debt.

That should give Unit 2 a strong opening learning loop:

context → identify zero → determine direction → assign sign → interpret magnitude → check reasonableness → place meaning on the number line.
