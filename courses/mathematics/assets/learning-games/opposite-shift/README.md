The lesson is built around the structural rule a − b = a + (−b), with number-line movement, subtracting negatives, signed differences, contextual change, and the important Extended distinction between signed change and absolute distance.

The new Animated Instruction Studio contains four parts:

Add the Opposite — animates 7 − (−3) → 7 + (+3) → 10.
Subtracting a Negative — shows −4 − (−5) = −4 + 5 and physically moves the marker five spaces to the right.
Final Minus Initial — models a temperature change from −6°C to +4°C, producing 4 − (−6) = +10°C.
Difference vs Distance — contrasts −5 − 3 = −8 with |−5 − 3| = 8, so students see that a signed difference preserves direction while distance does not.

That last distinction directly supports the lesson’s Extended pathway.

The game missions now cover rewrite-only questions, subtraction computation, subtracting negatives, number-line direction, sign prediction, temperature, elevation, elevators, finance, error analysis, equations such as x − (−8) = 3, absolute-value expressions such as −|5| − (−9), signed-difference vs. distance reasoning, and multi-step subtraction.

I also deliberately made the game reinforce Lesson 4 rather than introduce an unrelated trick: once subtraction is rewritten, the learner goes right back to the integer-addition reasoning they already learned.

For example:

−15 − (−20)

becomes

−15 + 20

and then the existing different-sign magnitude reasoning produces:

+5
