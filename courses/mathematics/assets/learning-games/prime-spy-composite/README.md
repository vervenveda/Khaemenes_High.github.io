Students investigate each number and classify it as Prime, Composite, or Neither. The important difference is that they are given actual investigative tools rather than simply guessing.

It includes:

Prime / Composite / Neither classification
Correct handling of 0 and 1
Interactive divisibility scanner for 2, 3, 5, 7, and 11
Quotient evidence when a divisor works
Factor-pair explanations for composite numbers
Square-root stopping-rule instruction for proving primality
Prime reasoning rather than memorization alone
Randomized number bank extending beyond 100
12-, 18-, and 24-case rounds
Progressive reasoning hints
Immediate explanations
Score and streak system
Missed-case review
Local best score
80% mastery gate
Responsive and printable design
