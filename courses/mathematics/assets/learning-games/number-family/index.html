One number can belong to several families.

Natural numbers sit inside whole numbers, which sit inside integers, which sit inside rational numbers. Rational and irrational numbers together fill the real number system.

  • 8 is natural, whole, integer, rational, and real.
  • 0 begins at whole, then continues outward.
  • −8 begins at integer, then continues to rational and real.
  • √2 is irrational and real.
When asked for the most specific set, choose the smallest set that contains the value.

Repeating → Rational

Rational numbers wear disguises.

A number is rational if it can be written as a ratio of integers a/b, with b ≠ 0.

  • Terminating decimals are rational.
  • Repeating decimals are rational.
  • Every integer is rational because n = n/1.
Terminating or repeating decimal → rational.

Do not classify a radical by appearance alone.

First ask whether the number under the radical is a perfect square.

  • √49 = 7, so its most specific family is Natural.
  • 11 is not a perfect square, so √11 is Irrational.
  • The same idea works for √9, √16, √25, and other perfect squares.
Simplify first. Then classify the value you actually have.

Every real number has a place on the line.

Use nearby perfect squares or a useful decimal approximation to compare irrational and rational values.

  • √2 ≈ 1.414, so 1.4 < √2 < 1.5.
  • √9 = 3, so √9 > 2.9.
  • √10 is a little greater than 3.1 because 3.1² = 9.61.
Understand the value first, then locate and compare it.

Lesson 1 Field Guide

Most specific means smallest. 25 belongs to many sets, but Natural is the smallest set that contains it.
Natural begins at 1. This course convention places 0 in Whole, Integer, Rational, and Real—but not Natural.
Rational test Can it be written a/b? Terminating and repeating decimals pass this test.
Radical test Simplify perfect-square roots before classifying. √49 is 7, not irrational.
Real-number split Every real number is rational or irrational. No real number is both.
