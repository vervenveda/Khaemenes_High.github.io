The game itself is also different now

Instead of every question doing the same thing, the round mixes three mission types.

Most Specific Family

Example:

√49

Student chooses:

Natural

Then the game expands its entire membership chain:

Natural → Whole → Integer → Rational → Real

This matches the lesson's repeated distinction between most specific classification and all sets containing the value.

Full Membership

Example:

−6

Student must identify:

Integer + Rational + Real

So we retain the valuable feature from our original game.

Number-Line Comparison

Examples include:

√9 ? 2.9

√2 ? 1.5

√10 ? 3.1

π ? 3.14

Students select <, =, or > and receive the same style of reasoning used in the lesson's worked examples.
