The Animated Instruction Studio now teaches four ideas: same vs. different sign patterns, magnitude first / sign second, multiplication as repeated signed change, and the Extended rule that an even number of negative factors gives a positive product while an odd number gives a negative product.

The game missions include sign prediction, product computation, zero and ±1 structure, absolute-value expressions, error analysis, repeated temperature/elevation/money changes, solving equations such as (−5)x = 30, and multi-factor parity questions.

For example, Extended students can reason about:

(−2)(−3)(−4)(−5)

without multiplying anything: four negative factors is an even count, so the product must be positive.

The game includes the same Foundation / Core / Extended pathways, 12/16/20 mission rounds, missed-item review, local best score, and 80% mastery target.
