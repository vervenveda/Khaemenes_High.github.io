This companion follows the actual lesson closely: students compare using benchmarks, common denominators, decimal forms, cross products, and number-line position, while learning to choose whichever strategy is most efficient for the numbers. It also emphasizes the important signed-number rule that among negative values, greater absolute value means farther left and therefore smaller.

The Animated Instruction Studio contains four synchronized demonstrations:

Benchmark Lens — 49/100 vs. 1/2 = 50/100
Common Units — 5/8 = 15/24 compared with 7/12 = 14/24
Cross-Product Bridge — 5/7 vs. 7/10 using 50 > 49
Negative Order — visually places −5/6, −0.8, and −3/4 on a number line

The mission bank covers all of the lesson’s major skills and contexts, including mixed fraction/decimal comparisons, signed ordering, common denominators, cross products, temperature, running-distance changes, equivalent representations, and choosing the best comparison strategy rather than merely a valid one.

It preserves our established structure: Foundation / Core / Extended, 12/16/20 mission rounds, score and streak tracking, immediate explanations and hints, missed-item replay, local best mastery score, print support, keyboard Enter / H, responsive design, and the 80% mastery target.
