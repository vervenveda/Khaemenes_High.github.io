The lesson centers on opposites, absolute value as distance, zero’s special role, and the distinction between sign and magnitude. It also explicitly extends into distance between integer positions.

I designed the game around one visual metaphor: zero is a mirror and a measuring point.

The Animated Instruction Studio includes:

Mirror Opposites — −4 and +4 illuminate on opposite sides of zero while both show a distance of 4.
Absolute Value = Distance — animates |−12| as a number-line distance rather than the shortcut “make it positive.”
Zero Is Special — shows that the opposite of 0 is 0, |0| = 0, and zero is the only integer equal to its own opposite.
Distance Between Positions — introduces |7 − (−4)| = 11 and then reverses the subtraction to demonstrate why |a−b| = |b−a|.

That last feature comes directly from the lesson’s Core/Extended pathway, which expands absolute value from distance from zero into distance between positions.

The game missions then mix the actual Lesson 2 skills instead of drilling only absolute-value calculations. Students work with opposites, equal absolute values, farther-from-zero comparisons, contexts such as temperatures and balances, notation traps such as −|8|, possible values from equations like |x| = 9, and Extended distance reasoning.

A particularly useful misconception check is:

−|8|

The game explicitly teaches:

|8| = 8

then

−|8| = −8

so students see that a negative sign outside absolute-value bars is different from a negative number inside the bars.

The same Foundation / Core / Extended pathways and 80% mastery gate are included, matching the lesson’s pathway structure and mastery threshold.
