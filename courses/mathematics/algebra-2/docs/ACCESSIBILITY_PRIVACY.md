# Accessibility, Privacy, and Offline Design

- Open-age, placement-based language
- Foundation, Core, and Extended pathways
- Keyboard-accessible links and controls
- Visible focus indicators
- Responsive single-column layouts
- Reduced-motion support
- Print styles for lessons, assessments, reports, and records
- Canonical learner-scoped local record for names, scores, notes, attempts, retrieval evidence, and provenance
- Persistent writes are read-back verified when browser storage is available; memory-only/read-only states are shown explicitly
- Explicit exports rather than automatic transmission
- Runtime service-worker caching after first access
- No analytics or third-party record collection in the course package

Local files and public GitHub Pages cannot provide secure multi-user authentication. A verified learner binding improves local evidence attribution but is not secure multi-user authentication or Account Cloud synchronization. Families and schools should preserve exports and manage them appropriately.
