# Khaemenes Mathematics Resource Gap Classification — 2026-10-20

## Purpose

After two conservative canonical-game reuse waves, every remaining lesson without a game companion is classified as either:

- **Tool-sufficient** — calculator, CAD, modelling project, lab, portfolio, or evidence workflow is the better learning companion.
- **New game needed** — a focused interactive game would add distinct instructional value.

A tool-sufficient lesson is **not considered deficient** merely because it has no game. Games remain formative support and never grant 80% mastery.

## Recommended build order

1. **Pre-Algebra algebra-language cluster** — variables/terms, translating expressions, equivalence, distributive property, combining like terms.
2. **Algebra I structure cluster** — algebra vocabulary/polynomial classification/piecewise functions/polynomial operations.
3. **Geometry visual reasoning cluster** — quadrilateral properties, polygon angle/design reasoning, area/scale/probability.
4. Reuse those new games upward or downward only when the mathematics truly aligns.
5. Do **not** build new games for the lessons classified tool-sufficient unless a later learner audit shows a genuine instructional need.
