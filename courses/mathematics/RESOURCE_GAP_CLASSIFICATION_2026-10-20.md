# Khaemenes Mathematics Resource Gap Classification — 2026-10-20

## Purpose

After canonical-game reuse and the first new shared-game cluster, every lesson without a game companion is classified as either:

- **Tool-sufficient** — calculator, CAD, modelling project, lab, portfolio, or evidence workflow is the better learning companion.
- **New game needed** — a focused interactive game would add distinct instructional value.

A tool-sufficient lesson is **not deficient** merely because it has no game. Games remain formative support and never grant 80% mastery.

## Algebra-language cluster completed

Three new canonical shared games were created:

1. **Algebra Language Lab** — vocabulary, variables, terms, coefficients, constants, degree, monomial/polynomial structure.
2. **Expression Translator Studio** — words ↔ algebraic expressions, grouping language and contextual translation.
3. **Equivalence Forge** — properties, equivalent expressions, distribution, factoring, combining like terms, and polynomial addition/subtraction.

Together they added **9 direct placements**: five Pre-Algebra lessons and four Algebra I lessons. Each game uses randomized formative rounds, local best-score storage, accessible feedback, and explicitly does not award official mastery.
