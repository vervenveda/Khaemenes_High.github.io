# PA-13.2 Compact Engine Consolidation

Units 02–13 intentionally share one byte-identical compact `lesson-engine.js` contract after PA-13.2.

The canonical source snapshot is `records/compact-engine-reference.js`. Production copies remain inside each unit so lessons retain local/offline resilience rather than depending on a runtime network import.

The shared contract preserves:

- evidence-backed 80% mastery gating;
- first/latest/best attempt history;
- legacy completion → review migration when score evidence is insufficient;
- voluntary lower-retake mastery preservation;
- pathway, vocabulary, reflection, print, and review controls;
- string or structured application rendering;
- vocabulary fallback with optional local vocabulary loading;
- trust-aware `khaemenes.lesson.learning-record` JSON export.

The production copies are intentionally byte-identical even though individual lesson content remains data-driven through each unit's `LESSON_DATA`, `UNIT_MAP_FALLBACK`, and vocabulary data.
