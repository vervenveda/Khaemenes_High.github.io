# PA-13.2 Lesson Export Schema

Every lesson export must declare:

- `schema_version`
- `record_type = khaemenes.lesson.learning-record`
- `exported_at`
- a `trust` object
- `course`, `unit`, and `lesson` identity
- `pathway`
- a `mastery` object containing threshold, state, first/latest/best score, attempt count, and mastered timestamp
- `reviewed`
- learner-created evidence separately from mastery evidence
- source progress key and browser environment

## Trust boundary

Lesson exports produced by the public browser course are classified as `unscoped_browser_unit_evidence` because current unit progress keys are not bound to a learner identity. The underlying score is produced by canonical course-engine logic, but the browser-local export is not independently authenticated and must not silently become an institutional or learner-scoped record.

## Mastery state

- `not_assessed`: no score evidence
- `developing`: score evidence exists but best score remains below the threshold
- `mastered`: best score meets or exceeds the canonical mastery threshold

A voluntary later score below the threshold does not erase a prior `mastered` state when the best-score evidence remains valid.
