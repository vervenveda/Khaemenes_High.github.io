# Pre-Algebra Substantial Portal v21 Release

## Release purpose

This release strengthens the Pre-Algebra course portal without replacing the detailed diagnostic, Units 01–13, assessments, certificate, or the student's existing local records.

## New course-home capabilities

- scholarly paper-and-mathematics visual system
- dashboard for multiple local learners
- safe migration from the prior Grade 9 mathematics portal storage key
- 36-week scope with exact unit routes
- 180 substantial Monday–Friday classwork sessions
- week-specific essential questions, rules, applications, misconceptions, vocabulary, and evidence
- 112 generated skill families
- definitive-answer problem generation
- 80% mastery target and retained best score
- attempt tracking
- classwork, mastery, and portfolio scoring
- transparent 40/20/30/10 course-grade calculation
- formal assessment result import
- gradebook CSV
- 36-week scope CSV
- printable weekly packet
- downloadable HTML weekly packet
- portfolio JSON and HTML
- complete backup import and export
- progress report HTML and CSV
- generator self-audit
- future scientific-calculator integration reserved but disabled
