# Pre-Algebra Unit 1

## Number Systems, Factors & Estimation

The first complete instructional unit in Khaemenes Global Pre-Algebra.

- Duration: 2 weeks
- Recommended sessions: 10
- Lessons: 6
- Practice pathways: Foundation, Core, Extended
- Mastery threshold: 80%
- Project: Number Systems Investigation
- Progress: browser-local and exportable

## Lessons

1. Number Families & the Real Number System
2. Factors, Multiples & Number Structure
3. Prime Numbers, Divisibility & Factorization
4. Greatest Common Factor & Least Common Multiple
5. Order of Operations & Numerical Expressions
6. Estimation, Compatible Numbers & Reasonableness

## Design principles

Concept before procedure; multiple representations; support by skill; multilingual vocabulary bridges; explanatory feedback; estimation before acceptance; local-first records; printable alternatives; no account required.

## Static-site assessment caution

Because this is a public static repository, answer data cannot be securely hidden in the browser. The mastery check is suitable for self-assessment and formative learning. Schools needing secure high-stakes testing should use protected assessment delivery and alternate forms.
