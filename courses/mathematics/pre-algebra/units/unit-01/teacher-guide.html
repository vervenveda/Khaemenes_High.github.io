Teacher Guide

A two-week guide for number systems, factor structure, GCF/LCM, order of operations, estimation, and mathematical communication.

Core misconceptions

  • Believing a number belongs to only one number set.
  • Calling 1 prime or assuming an undefined natural-number convention.
  • Confusing factors with multiples.
  • Using GCF for repeating cycles or LCM for largest equal groups.
  • Thinking multiplication always precedes division.
  • Treating an estimate as careless guessing.
  • Trusting a calculator without checking magnitude.

Instructional moves

  • Ask learners to compare methods before choosing the fastest.
  • Use “most specific classification” when one set is expected.
  • Require units and labels in context.
  • Invite counterexamples such as “Is every odd number prime?”
  • Preserve unchanged expression parts on each line.
  • Estimate before exact calculation.
  • Use multilingual vocabulary as a bridge, not a substitute for modelling.

Discussion prompts

  • What structure do you notice?
  • Which answer can be rejected without exact calculation?
  • How do you know the groups are greatest?
  • What counterexample changes the claim?

Differentiation

Foundation

Use counters, number lines, arrays, factor-pair tables, oral rehearsal, reduced item sets, and optional hints.

Core

Require multiple representations, context, explanation, error analysis, and independent practice.

Extended

Use bounds, primality arguments, counterexamples, the GCF×LCM identity, and proof-oriented explanations.

Assessment use

The mastery threshold is 80%, but one total score should not replace domain evidence, project work, practice explanations, and learner reasoning.

  • Below 50%: return to Foundation models and direct instruction.
  • 50–79%: target the lowest domains and reassess.
  • 80–89%: continue with brief review of missed concepts.
  • 90–100%: offer Extended tasks and peer explanation.

The public static answer key is not secure. Use protected alternate forms for high-stakes grading.

Accessibility and inclusion

  • Read symbols aloud using complete mathematical language.
  • Offer visual, verbal, symbolic, and physical representations.
  • Do not rely on color alone.
  • Allow keyboard use, print copies, processing time, and oral explanation.
  • Separate language difficulty from mathematical difficulty.
  • Use contexts from varied regions without stereotyping.
