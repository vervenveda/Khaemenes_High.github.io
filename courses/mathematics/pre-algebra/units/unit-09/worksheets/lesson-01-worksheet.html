1. Which means “x is at most 12”?

(A) x<12   (B) x≤12   (C) x>12   (D) x≥12

2. Does x=4 satisfy 2x+5≥13?

(A) Yes   (B) No; left side is 9   (C) No; 13 is not included   (D) Cannot tell

3. A room holds no more than 80 people. If p is attendance:

(A) p<80   (B) p≤80   (C) p>80   (D) p≥80

4. Translate x<−3.

(A) x is at least −3   (B) x is no more than −3 including −3   (C) x is greater than −3   (D) x is less than −3

5. Does x=2 satisfy 4x+1≥10?

(A) only if equality is excluded   (B) cannot tell   (C) no   (D) yes

6. A ride requires height h of at least 48 inches.

(A) h>48   (B) h≤48   (C) h<48   (D) h≥48

7. An inequality solution set often contains:

(A) no numbers ever   (B) only integers   (C) many values   (D) exactly one value

8. A value where inclusion/exclusion changes is a:

(A) factor   (B) quotient   (C) boundary   (D) coefficient

9. A student tests x=4 in x+3<7 and says true because 7≤7. Correct?

(A) no; 7<7 is false   (B) yes   (C) yes because 4 is positive   (D) cannot test boundaries

10. Why distinguish < from ≤?

(A) one is multiplication   (B) ≤ excludes equality   (C) the boundary membership changes   (D) they always mean the same thing
