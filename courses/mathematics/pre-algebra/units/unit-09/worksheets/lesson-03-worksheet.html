Lesson 03 · Inequality & Constraints Studio

Five ungraded investigations. Translate each scenario, distinguish strict versus inclusive boundaries, show work, and test both an allowed value and a disallowed value when possible.

A · Bus tickets

Each ticket costs $4 and a student has at most $30. Write and solve an inequality for the number n of tickets; state the actual whole-number choices.

B · Water reserve

A reservoir has 145 L, and 38 L must remain after an event. If x liters are used, write and solve the constraint.

C · Reverse the addition

Solve x−17>−8, graph the answer, and verify a solution and a non-solution.

D · Watch the meaning

A teacher says 3 more than the number of entries must be at least 22. Set up and solve an inequality; explain the smallest whole number allowed.

E · Repair a wrong solution

A learner solves y+12≤−5 by adding 12 and claims y≤7. Correct the inverse step and test the boundary.

Reflection / Error Analysis

Choose one inequality from this lesson. Explain its boundary, solve or interpret it, describe the graph, identify one likely error, and verify a solution and a non-solution.
