Constraint Design Investigation

Create and test an inequality model for a public, fictional, measured, or designed situation; graph the feasible set and communicate boundaries, units, domain restrictions, assumptions, and verification.

Open Project Workspace

Project sequence

Build and verify an evidence-aware constraint model.

Select a safe context or design

Examples: budget, event capacity, packaging, transportation, environmental threshold, safe temperature, material limits, garden dimensions, or production planning. Use public, fictional, or measured data.

Define variables and constraints

State variables, units, fixed quantities, rates, upper and lower bounds, endpoint rules, domain restrictions, and assumptions.

Write and solve inequalities

Create at least one multi-step inequality and one compound inequality. Show equivalent transformations and explain every reversal.

Represent the feasible set

Use a number-line graph, table, or interval description. Apply whole-number, nonnegative, or continuous restrictions as appropriate.

Test and communicate

Check boundary values, one feasible and one infeasible case, and explain which option or design is practical and why.

Rubric

DimensionProficient evidence
DefinitionsVariables, units, limits, boundary inclusion, domain, and assumptions are explicit.
Inequality accuracySymbols, transformations, reversal rules, and arithmetic are correct.
RepresentationsGraphs, intervals, tables, and words describe the same feasible set.
Contextual feasibilityDiscrete, continuous, nonnegative, and bounded conditions are applied correctly.
VerificationBoundary, feasible, and infeasible test cases support the conclusion.
CommunicationThe final recommendation states limits and avoids overstating the model.
