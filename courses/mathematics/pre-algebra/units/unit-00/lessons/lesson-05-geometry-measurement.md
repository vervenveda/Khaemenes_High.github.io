# Unit 0 · Week 5 / Lesson 5
## Geometry & Measurement Bridge

**Readiness Strand:** Geometry & Measurement  
**Essential Strand:** Supporting  
**Question:** Can the learner use units, formulas, and scale relationships accurately in measurable situations?

## Targets
By the end of this week, the learner should be able to:
- distinguish perimeter from area;
- calculate area of rectangles and triangles;
- select and use appropriate measurement units;
- convert common metric units;
- interpret simple scale drawings;
- check whether a geometric answer has a reasonable magnitude and unit.

## Weekly Cadence

### Session 1 — Diagnostic Connection
Use fresh measurement and geometry items. Require the learner to state the unit expected before calculating.

### Session 2 — Teach / Reteach
Reconnect meaning to formulas:
- perimeter measures boundary length;
- area measures two-dimensional coverage;
- triangle area is half the area of a related rectangle/parallelogram;
- unit conversion changes numerical representation, not the physical quantity;
- scale drawings preserve proportional relationships.

### Session 3 — Guided Practice
Work through diagrams, missing measurements, metric conversions, and scale problems. Include error analysis where units expose an incorrect answer.

### Session 4 — Independent Practice
Complete a new mixed set involving perimeter, area, unit conversion, and scale.

### Session 5 — Application & Mastery Evidence
Plan a fictional room, garden, poster, or map using dimensions and scale. Explain which quantities require linear units and which require square units. Finish with a 10-item strand check.

## Secure-Strand Compact Path
If already secure:
- one perimeter/area comparison;
- one triangle-area explanation;
- one unit conversion;
- one scale application;
- mastery evidence.

## Reasoning Correction Rule
Corrections must identify:
1. the quantity being measured;
2. the formula or relationship that applies;
3. the correct unit;
4. corrected work;
5. one reasonableness check.

## Mastery Signal
Target: **80%+** on new mastery evidence with required corrections completed.
