Deeper concept study guide

How to think through this week.

These notes make the lesson more substantial without changing the mastery engine.

Expression discipline

  • Replace the variable with the given value using parentheses.
  • Evaluate grouping and exponents before lower-level operations.
  • Do not combine unlike terms as though every symbol were the same kind of quantity.

Equation balance

  • Read the equals sign as 'has the same value as.'
  • Undo the operation attached to the variable.
  • Do the same operation to both sides to preserve equality.

Inequality awareness

  • Read inequalities from left to right.
  • Keep the solution meaning connected to the situation.
  • Save formal inequality-flip rules for multiplication/division by negatives when introduced.

Verification habit

  • Put the proposed solution back into the original problem.
  • Check both sides of the equation.
  • Reject answers that work only after an accidental sign or order mistake.

Worked examples

Model the thinking before the score.

Substitution

Evaluate 3x + 5 when x = −2.

  1. Substitute −2 for x: 3(−2)+5.
  2. Multiply first: 3(−2)=−6.
  3. Add: −6+5=−1.

Result: −1

One-step equation

Solve y − 9 = 14.

  1. Undo subtracting 9 by adding 9.
  2. Add 9 to both sides.
  3. Check: 23−9=14.

Result: y = 23

Two-step equation

Solve 4n + 3 = 19.

  1. Subtract 3 from both sides: 4n=16.
  2. Divide both sides by 4.
  3. Check: 4(4)+3=19.

Result: n = 4

Misconception clinic

Common errors to catch early.

  • Replacing a variable without parentheses — Parentheses protect the sign of substituted values, especially negatives.
  • Doing an operation to only one side — An equation stays balanced only when the same valid operation is applied to both sides.
  • Solving but not checking — Checking catches arithmetic slips and wrong inverse-operation choices.
  • Confusing expression with equation — An expression can be evaluated or simplified; an equation can be solved.
