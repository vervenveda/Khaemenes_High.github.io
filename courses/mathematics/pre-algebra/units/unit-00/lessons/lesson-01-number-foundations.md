# Unit 0 · Week 1 / Lesson 1
## Number Foundations Reset

**Readiness Strand:** Number Foundations  
**Essential Strand:** Yes  
**Question:** Can the learner reason accurately with whole numbers, signed numbers, factors, order of operations, and basic powers?

## Targets
By the end of this week, the learner should be able to:
- apply order of operations accurately;
- identify factors, multiples, prime and composite numbers;
- add, subtract, multiply, and divide integers with meaning;
- interpret absolute value as distance from zero;
- evaluate small whole-number exponents;
- explain why an answer is reasonable rather than relying only on a procedure.

## Weekly Cadence

### Session 1 — Diagnostic Connection
Review the learner's Number Foundations strand report. Do not simply reveal old diagnostic answers. Ask the learner to solve a fresh five-item confirmation set and explain at least two answers.

### Session 2 — Teach / Reteach
Focus on conceptual trouble spots:
- operation priority and left-to-right ties;
- factor vs. multiple;
- why 1 is neither prime nor composite;
- signed-number direction and change;
- absolute value as distance;
- exponent meaning as repeated multiplication.

### Session 3 — Guided Practice
Use worked examples with error analysis. The learner identifies where a fictional student's reasoning changed from valid to invalid.

### Session 4 — Independent Practice
Complete a new mixed set containing numerical expressions, integer contexts, factor/prime classification, and powers.

### Session 5 — Application & Mastery Evidence
Solve a short multi-part planning problem that combines signed change, factor structure, and operation order. Finish with a 10-item strand check.

## Secure-Strand Compact Path
If the readiness gateway showed this strand at or above 80%, replace repetitive review with:
- a five-item confirmation challenge;
- two unfamiliar application problems;
- one written explanation of an error;
- mastery evidence.

## Reasoning Correction Rule
A correction must include:
1. the original error or misconception;
2. the correct mathematical principle;
3. a worked correction;
4. one new example showing the principle.

## Mastery Signal
Target: **80%+** on new mastery evidence with reasoning corrections completed for missed prerequisite ideas.
