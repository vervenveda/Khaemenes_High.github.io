Session 2 · Teach / Reteach

Six Foundations That Hold the Course Together

Read for meaning. Each concept prevents a common error that can spread into later algebra.

Operation Priority

Grouping → exponents → multiplication/division left to right → addition/subtraction left to right.

Factor vs. Multiple

A factor divides a number evenly. A multiple is produced by multiplying the number by an integer. 6 is a factor of 24; 24 is a multiple of 6.

Prime Structure

A prime has exactly two positive factors. A composite has more than two. 1 is neither because it has only one positive factor.

Signed Numbers

Signs describe position and direction. Subtracting a number can be understood as adding its opposite. −7 − (−4) = −3.

Absolute Value

Absolute value is distance from zero, so |−9| = 9.

Exponents

An exponent counts repeated multiplication of the base: 3⁴ = 3 × 3 × 3 × 3 = 81.

Reasonableness check: Before accepting an answer, ask whether the sign, size, units, and operation fit the original problem.

Session 3 · Guided Error Laboratory

Find the Exact Moment the Reasoning Breaks

Identify the invalid step and explain the mathematical principle that repairs it.

Error A · Operation order

18 − 3 × 4 = 15 × 4 = 60

Error B · Prime classification

1 is prime because it can be divided by 1 and itself.

Error C · Integers

−6 + 11 = −17 because the signs are different.

Error D · Exponents

2⁵ = 10 because 2 × 5 = 10.

A: Multiply first: 3 × 4 = 12; then 18 − 12 = 6.

B: Prime numbers have exactly two distinct positive factors. The number 1 has only one.

C: Eleven positive units cancel six negative units, leaving +5.

D: 2⁵ means five factors of 2, so the value is 32.

Given: 84 notebooks, 126 pencils, a storage change of −18 boxes followed by +27 boxes, and the packaging expression 96 − 4 × 15. Identical kits must use equal whole-number quantities with no leftovers.

1. 42 kits; GCF(84,126)=42, giving 2 notebooks and 3 pencils per kit.

2. +9 boxes.

3. 36, because multiplication is completed before subtraction.

4. A distance or magnitude of 12 units from zero.
