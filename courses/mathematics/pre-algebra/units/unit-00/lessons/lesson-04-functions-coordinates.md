# Unit 0 · Week 4 / Lesson 4
## Functions & Coordinates Bridge

**Readiness Strand:** Functions & Coordinates  
**Essential Strand:** Supporting  
**Question:** Can the learner connect ordered pairs, tables, rules, and changing quantities?

## Targets
By the end of this week, the learner should be able to:
- plot and interpret ordered pairs in all four quadrants;
- identify input and output quantities in a relationship;
- use a rule to generate a table of values;
- recognize a simple linear pattern from a table;
- interpret rate of change as change in output per change in input;
- move among words, tables, coordinates, and simple equations.

## Weekly Cadence

### Session 1 — Diagnostic Connection
Use fresh coordinate, table, and rule items. Ask what each coordinate means rather than accepting plot placement alone.

### Session 2 — Teach / Reteach
Reconnect representations:
- x-coordinate before y-coordinate;
- four-quadrant sign patterns;
- input → rule → output;
- table rows as matched pairs;
- constant additive change in y for equal changes in x;
- rate as a comparison of changes.

### Session 3 — Guided Practice
Build tables from rules and rules from simple tables. Plot selected points and describe the relationship in words.

### Session 4 — Independent Practice
Complete a new set using ordered pairs, tables, simple equations, and contextual input/output relationships.

### Session 5 — Application & Mastery Evidence
Analyze a constant-speed or savings relationship using a table, graph description, and rule. Finish with a 10-item strand check.

## Secure-Strand Compact Path
If already secure:
- complete one coordinate confirmation;
- infer one rule from a table;
- explain one rate-of-change problem;
- translate one context into a table and rule;
- complete mastery evidence.

## Reasoning Correction Rule
Corrections must identify whether the issue involved:
- coordinate order;
- sign/quadrant reasoning;
- input/output interpretation;
- rule application;
- rate-of-change interpretation.

Then solve one new parallel item.

## Mastery Signal
Target: **80%+** on new mastery evidence with required corrections complete.
