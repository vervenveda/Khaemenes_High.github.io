Foundations & Readiness · Lesson 05

Coordinates, Patterns & Functions

Connect rules, tables, ordered pairs, graphs, and introductory rate of change.

Math Word: Function

A function assigns each allowed input exactly one output.

input → rule → output

Guided refresh

  • An ordered pair is written (x,y).
  • The x-coordinate moves horizontally; the y-coordinate moves vertically.
  • A table, graph, equation, and verbal rule can describe the same relationship.
  • Rate of change compares change in output to change in input.

Example: y=2x+1 gives (0,1), (1,3), (2,5). The output increases by 2 whenever x increases by 1.

Independent readiness checks

1. In which quadrant is (−4,3)?
2. Complete the table for y=3x−2 when x=0,1,2.
3. Write a rule for the pattern 5,8,11,14,… using term number n.
4. A table changes x by +1 while y changes by +4. What is the rate of change?
5. Does {(1,2),(2,4),(1,5)} represent a function? Explain.
6. A taxi charges $3 plus $2 per mile. Write the rule and find the cost for 7 miles.

Application

Create a small table for a real situation with a constant rate. State the independent variable, dependent variable, and rate of change.

Week 5 evidence: connect at least three representations of the same relationship and interpret rate of change.
