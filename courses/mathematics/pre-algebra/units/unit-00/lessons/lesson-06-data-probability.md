# Unit 0 · Week 6 / Lesson 6
## Data & Probability Bridge

**Readiness Strand:** Data & Probability  
**Essential Strand:** Supporting  
**Question:** Can the learner summarize data, reason about chance, and judge whether a sample supports a conclusion?

## Targets
By the end of this week, the learner should be able to:
- calculate and interpret mean, median, and mode;
- identify how an outlier can affect a mean;
- read simple tables and data displays;
- compute simple theoretical probability;
- distinguish favorable outcomes from total possible outcomes;
- identify obviously biased or unrepresentative samples;
- state a conclusion that does not exceed the data.

## Weekly Cadence

### Session 1 — Diagnostic Connection
Use a fresh set involving center, probability, and sampling. Ask the learner to explain what the calculated value means in context.

### Session 2 — Teach / Reteach
Reconnect procedures to meaning:
- mean as equal-share balance;
- median as the middle ordered value;
- mode as the most frequent value;
- outliers and sensitivity of the mean;
- probability as favorable outcomes over total equally likely outcomes;
- sample quality and why convenience can create bias.

### Session 3 — Guided Practice
Compare small datasets, calculate several summaries, interpret simple probability situations, and critique sample-selection methods.

### Session 4 — Independent Practice
Complete a new mixed set involving mean/median/mode, outliers, simple probability, and representative sampling.

### Session 5 — Application & Unit 0 Readiness Preparation
Analyze a supplied school-survey dataset. Choose an appropriate summary, calculate one probability, identify one sampling limitation, and write a bounded conclusion. Then complete a 10-item strand check and prepare for the Unit 0 Exit Assessment.

## Secure-Strand Compact Path
If already secure:
- compare mean and median in an outlier dataset;
- solve one probability problem;
- critique one biased-sample scenario;
- write one evidence-limited conclusion;
- complete mastery evidence.

## Reasoning Correction Rule
Corrections must state:
1. what the statistic/probability/sample claim means;
2. what error occurred;
3. corrected reasoning;
4. one new example.

## Mastery Signal
Target: **80%+** on new mastery evidence with required corrections completed.
