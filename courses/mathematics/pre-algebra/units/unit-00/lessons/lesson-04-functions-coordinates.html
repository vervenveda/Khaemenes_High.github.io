Learn

Relationships can be represented in several ways.

Coordinates

The x-coordinate describes horizontal position; the y-coordinate describes vertical position.

Rules

A function rule transforms an input into an output in a predictable way.

Sequences

Repeated change can be described by a rule and used to predict later terms.

Rate of change

Compare change in output with change in input to describe how quickly a relationship changes.
