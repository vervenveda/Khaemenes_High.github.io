Learn

Relationships can be represented in several ways.

Read the concept cards before beginning the practice. The goal is not only to get an answer; the goal is to explain why the answer is reasonable.

Coordinates

The x-coordinate describes horizontal position; the y-coordinate describes vertical position.

Rules

A function rule transforms an input into an output in a predictable way.

Sequences

Repeated change can be described by a rule and used to predict later terms.

Rate of change

Compare change in output with change in input to describe how quickly a relationship changes.

Deeper concept study guide

How to think through this week.

These notes make the lesson more substantial without changing the mastery engine.

Coordinate reading

  • Read ordered pairs as (x, y), never (y, x).
  • Move horizontally first, then vertically.
  • Use signs to choose right/left and up/down.

Function table reasoning

  • A rule assigns each input to an output.
  • Check every row before declaring the rule.
  • Use the rule to predict values beyond the table.

Sequence reasoning

  • Find whether the change is constant.
  • Use repeated addition for arithmetic patterns.
  • Connect the repeated change to a simple rule when possible.

Rate reasoning

  • Compare change in output to change in input.
  • Use units to keep the meaning clear.
  • Check whether the rate is positive, negative, or zero.

Worked examples

Model the thinking before the score.

Coordinate movement

Start at (−2, 3), move 5 right and 4 down.

  1. Right adds 5 to x: −2+5=3.
  2. Down subtracts 4 from y: 3−4=−1.
  3. Write the new ordered pair.

Result: (3, −1)

Input/output rule

Rule: y = 2x + 1. Find y when x = 4.

  1. Substitute 4 for x.
  2. Multiply first: 2(4)=8.
  3. Add 1.

Result: y = 9

Rate of change

A table goes from (1, 5) to (3, 11).

  1. Input changed by 2.
  2. Output changed by 6.
  3. Rate is output change ÷ input change.

Result: 3 per 1 input

Misconception clinic

Common errors to catch early.

  • Reversing coordinates — The first coordinate is horizontal x; the second is vertical y.
  • Calling any pattern a function rule too quickly — A rule must work for every input-output pair given.
  • Ignoring units in rate problems — A rate is not just a number; it describes change per input unit.
  • Thinking negative coordinates are errors — Negative coordinates are valid positions left of or below the origin.
