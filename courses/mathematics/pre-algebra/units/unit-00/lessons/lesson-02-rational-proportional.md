# Unit 0 · Week 2 / Lesson 2
## Rational & Proportional Reasoning Reset

**Readiness Strand:** Rational & Proportional Reasoning  
**Essential Strand:** Yes  
**Question:** Can the learner move flexibly among fractions, decimals, percent, ratios, and rates?

## Targets
By the end of this week, the learner should be able to:
- compare and generate equivalent fractions;
- add, subtract, multiply, and divide common fractions and decimals;
- convert among fractions, decimals, and percentages;
- interpret ratios and unit rates;
- solve proportional situations by scaling or equivalent ratios;
- explain whether a proportional answer is reasonable.

## Weekly Cadence

### Session 1 — Diagnostic Connection
Use a fresh six-item set sampling fraction equivalence, decimal operations, percent, ratio, and unit rate. The learner explains one correct and one uncertain answer.

### Session 2 — Teach / Reteach
Reconnect representations:
- fraction ↔ division ↔ decimal ↔ percent;
- common denominator as equivalent-unit reasoning;
- ratio as multiplicative comparison;
- unit rate as per-one comparison;
- percent as per hundred.

### Session 3 — Guided Practice
Work through recipe, price, distance, and percent contexts. Emphasize choosing a representation rather than memorizing one procedure for every problem.

### Session 4 — Independent Practice
Complete a new mixed set requiring conversions, operations, ratios, rates, and percent. Include at least two items where estimation can reject an unreasonable answer.

### Session 5 — Application & Mastery Evidence
Complete a real-world comparison task using price-per-unit, percent change, and scaling. Finish with a 10-item strand check.

## Secure-Strand Compact Path
If this strand was already secure, use:
- a representation-conversion sprint;
- one unit-rate comparison;
- one multi-step percent application;
- one written explanation of why additive reasoning fails in a proportional situation;
- mastery evidence.

## Reasoning Correction Rule
Corrections must identify whether the error came from:
- representation;
- operation;
- scale factor;
- percent interpretation;
- unit reasoning.

The learner then solves a new parallel example correctly.

## Mastery Signal
Target: **80%+** on new mastery evidence with required reasoning corrections completed.
