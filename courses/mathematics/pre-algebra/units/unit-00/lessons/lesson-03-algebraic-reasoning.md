# Unit 0 · Week 3 / Lesson 3
## Algebraic Reasoning Reset

**Readiness Strand:** Algebraic Reasoning  
**Essential Strand:** Yes  
**Question:** Can the learner use symbols to represent relationships and preserve equality while solving?

## Targets
By the end of this week, the learner should be able to:
- identify terms, coefficients, constants, and like terms;
- evaluate expressions by substitution;
- combine like terms correctly;
- solve one-step and simple multi-step equations using inverse operations;
- check a solution by substitution;
- solve and interpret simple inequalities;
- explain why performing equivalent operations preserves a relationship.

## Weekly Cadence

### Session 1 — Diagnostic Connection
Use fresh items involving simplification, substitution, equations, and inequalities. Ask the learner to explain what the equals sign means before solving.

### Session 2 — Teach / Reteach
Rebuild algebra from structure:
- variable as a quantity, not a mysterious letter;
- expression vs. equation;
- equal sign as a relationship;
- inverse operations;
- like terms;
- inequality as a set of possible values.

### Session 3 — Guided Practice
Use balance models, substitution checks, and error analysis. Include a fictional solution that performs an operation on only one side and ask why the equality breaks.

### Session 4 — Independent Practice
Complete a new mixed set of expressions, substitutions, equations, inequalities, and contextual translations.

### Session 5 — Application & Mastery Evidence
Model a simple budget, distance, or scoring situation with an equation or inequality, solve it, and interpret the answer in context. Finish with a 10-item strand check.

## Secure-Strand Compact Path
A learner already secure in this strand receives:
- a short symbolic reasoning confirmation;
- one equation from a context;
- one inequality from a constraint;
- one error-analysis explanation;
- mastery evidence.

## Reasoning Correction Rule
Corrections must state:
1. what mathematical relationship was misunderstood;
2. the valid operation or structure;
3. the corrected work;
4. a check showing the result works.

## Mastery Signal
Target: **80%+** on new mastery evidence with reasoning corrections complete.
