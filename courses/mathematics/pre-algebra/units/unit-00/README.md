# UNIT 0 — Foundations & Readiness
## STATUS: LOCKED — CONDITIONAL SIX-WEEK REFRESHER

**Course:** Khaemenes Global Pre-Algebra  
**Route:** Readiness Gateway → Unit 0 when support is indicated → 80% mastery + reasoning corrections → Official Unit 1

## Purpose

Unit 0 is a **conditional six-week refresher**, not part of the standard 36-week official Pre-Algebra curriculum. Learners who demonstrate readiness enter Official Unit 1 immediately. Learners who need prerequisite reinforcement receive this six-week support unit first, creating a **42-week supported pathway**.

A readiness diagnostic guides support; it does not label or punish a learner.

## Duration

- **6 weeks**
- **6 substantial refresher lessons**
- each lesson is designed as one week of focused work
- recommended weekly cadence: diagnose/confirm → reteach → guided practice → independent practice → application → mastery evidence
- strong strands may use confirmation/challenge work instead of redundant drill

## Six Readiness Strands

| Week / Lesson | Strand | Essential for direct entry? | Main focus |
|---|---|---|---|
| 1 | Number Foundations | Yes | order of operations, factors/primes, integers, absolute value, exponents |
| 2 | Rational & Proportional Reasoning | Yes | fractions, decimals, percent, ratios, rates |
| 3 | Algebraic Reasoning | Yes | expressions, substitution, equations, inequalities |
| 4 | Functions & Coordinates | Supporting | coordinate plane, input/output, rules, rate of change |
| 5 | Geometry & Measurement | Supporting | area, perimeter, scale, units, measurement reasoning |
| 6 | Data & Probability | Supporting | center, probability, data summaries, representative samples |

## Weekly Lesson Pattern

Each refresher lesson follows the Academy readiness contract:

1. **Diagnostic connection** — review the learner's strand evidence without exposing prior answers as instruction.
2. **Teach / reteach** — concise conceptual instruction focused on prerequisite meaning.
3. **Guided practice** — worked examples with reasoning prompts.
4. **Independent practice** — new items, not copies of the readiness gateway.
5. **Application** — contextual transfer and explanation.
6. **Mastery evidence** — short strand check with reasoning correction when needed.

## Adaptive Use

Unit 0 is targeted rather than punitive.

- A weak strand receives full reteaching and practice.
- A secure strand receives a shorter confirmation path, richer applications, and challenge problems.
- No learner is required to repeat an already-secure skill set through unnecessary drill.
- The six-week supported route remains available as the full calendar path when prerequisite reinforcement is needed.

## Exit Mastery

Unit 0 ends with a separate **Foundations & Readiness Exit Assessment**.

Requirements to enter Official Unit 1:
- **80% or higher overall**;
- all required reasoning corrections completed;
- essential strands demonstrate sufficient readiness evidence;
- no premature answer disclosure before submission.

If the first exit attempt is below mastery:

**targeted correction → new parallel-form retake → 80% mastery → Official Unit 1**

Unit 0 never loops a learner indefinitely through the same questions.

## NAIB Record Behavior

Unit 0 produces and updates **Readiness** and **Refresh** evidence. It does not erase or rewrite earlier records.

NAIB keeps separate:
- **Course Mastery** — what the learner demonstrated during a completed course;
- **Retention** — what remains fluent later;
- **Refresh** — what currently needs reinforcement;
- **Readiness** — whether the learner can successfully enter the next course.

A later readiness or refresh result must never erase or downgrade a prior course-completion record.

## Student-Facing Language

Preferred:
- "You are strengthening a few foundations before Pre-Algebra begins."
- "This route gives you extra runway before Official Unit 1."
- "Your strongest strands will move faster; your refresh priorities receive more practice."

Avoid:
- "failed placement"
- "behind"
- "low student"
- labels that turn a temporary skill gap into an identity
