Signed Data Investigation

Choose a real system with values above and below a reference point, collect meaningful signed data, calculate changes and distances, and explain what the signs reveal.

Open Project Workspace

Project sequence

Investigate a system that changes.

Select a context and reference point

Examples: temperatures, elevations, tidal levels, account balances, game scoring, environmental measurements, building floors, or coordinate movement. Define what zero means.

Collect signed data

Use at least twelve values across time or position. Record units, sources or measurement method, and why positive or negative signs are appropriate.

Analyze value, magnitude, and distance

Order the values, identify opposites where present, compare absolute values, and calculate at least three distances or signed changes.

Model operations

Use addition, subtraction, multiplication, or division to answer at least four meaningful questions. Include one multi-step calculation and one coordinate representation.

Communicate a conclusion

Create a report, poster, data story, map, or short presentation. Explain the reference point, sign conventions, findings, limitations, and one surprising result.
