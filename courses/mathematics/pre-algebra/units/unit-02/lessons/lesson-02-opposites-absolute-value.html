      Concept study guide

      Read this before the quick rules.

      This lesson has two ideas students often mix up: the opposite of a number and the absolute value of a number. Use this guide to separate mirror position from distance.

      1 · Locate zero first

      Zero is the mirror line for opposites and the starting point for absolute value. Before answering, ask: where is zero in this situation?

      2 · Opposite means other side

      The opposite of a number is the same distance from zero but on the other side. Opposite changes direction while preserving magnitude.

      3 · Absolute value means distance

      Absolute value ignores direction and reports distance from zero. Distance is never negative, so the value inside the bars may be negative while the result is not.

      4 · Read notation carefully

      |−8| = 8, but −|8| = −8. The bars are evaluated first, then any sign outside the bars is applied.
