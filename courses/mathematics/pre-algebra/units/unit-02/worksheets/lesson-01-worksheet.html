1. Which value is an integer?

(A) 3/4    (B) −8    (C) 2.5    (D) √2

Answer: __________

2. Which value is not an integer?

(A) −12    (B) 0    (C) 19    (D) 4.6

Answer: __________

3. A temperature of 6 degrees below zero is represented by which integer?

(A) −6    (B) 0    (C) +6    (D) 60

Answer: __________

4. A deposit of $45 is best represented as which account change?

(A) −45    (B) 0    (C) +45    (D) −4.5

Answer: __________

5. A withdrawal of $28 is represented by which signed change?

(A) +28    (B) 0    (C) −28    (D) 28/100

Answer: __________

6. A hiker is 320 feet above sea level. Which integer represents the elevation?

(A) +320    (B) −320    (C) 0    (D) 32

Answer: __________

7. A submarine is 75 meters below sea level. Which integer represents its position?

(A) +75    (B) 0    (C) 750    (D) −75

Answer: __________

8. Which situation can reasonably be represented by 0?

(A) 12 feet below sea level    (B) No change in an account balance    (C) +8 points gained    (D) 5°C below freezing

Answer: __________

9. Which statement about zero is correct?

(A) Zero is neither positive nor negative.    (B) Zero is positive.    (C) Zero is negative.    (D) Zero is not an integer.

Answer: __________

10. A football team loses 7 yards on a play. Which integer represents the change in field position?

(A) +7    (B) 0    (C) −7    (D) 70

Answer: __________
