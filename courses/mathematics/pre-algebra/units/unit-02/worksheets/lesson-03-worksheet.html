1. Which statement is true?

2. Choose the correct symbol: −12 __ −5.

3. Choose the correct symbol: 7 __ −2.

(A) >    (B) <    (C) =    (D) −

Answer: __________

4. Choose the correct symbol: 0 __ −9.

5. Which integer is greatest?

(A) −11    (B) −7    (C) −2    (D) −5

Answer: __________

6. Which integer is least?

(A) −4    (B) +3    (C) 0    (D) −1

(A) −3, −8, 0, 5    (B) 5, 0, −3, −8    (C) 0, −8, −3, 5    (D) −8, −3, 0, 5

Answer: __________

8. Order −1, 6, −9, 2 from greatest to least.

(A) −9, −1, 2, 6    (B) 6, 2, −1, −9    (C) 6, −1, 2, −9    (D) 2, 6, −1, −9

Answer: __________

9. Which value belongs first when −4, 3, −10, 0 are ordered least to greatest?

(A) −10    (B) 3    (C) 0    (D) −4

Answer: __________

10. On a number line, integer A is to the right of integer B. What must be true?

(A) A < B    (B) A = B    (C) A > B    (D) A and B are opposites

Answer: __________
