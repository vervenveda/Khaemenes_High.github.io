1. In 2,2,3,3,3,5, the frequency of 3 is:

(A) 2   (B) 3   (C) 5   (D) 6

2. Which display preserves every individual numerical observation?

(A) pie chart   (B) two-way table   (C) map   (D) dot plot

3. Which five values define a standard box plot?

(A) mean, mode, range, MAD, total   (B) minimum, Q1, median, Q3, maximum   (C) minimum, mean, median, mode, maximum   (D) count, percent, mean, range, IQR

4. A dot plot is especially useful for:

(A) categorical-only data always   (B) showing individual values in a small numerical data set   (C) hiding all values   (D) proving causation

5. Adjacent histogram bars typically:

(A) must have large gaps   (B) represent categories only   (C) show exact individual labels   (D) touch

6. The box in a box plot spans:

(A) minimum to maximum   (B) mean to median   (C) 0 to 100   (D) Q1 to Q3

7. A long right tail suggests a distribution is:

(A) left-skewed   (B) perfectly symmetric   (C) categorical   (D) right-skewed

8. Data 2,2,3,5,5,5 has frequency of 5 equal to:

(A) 5   (B) 2   (C) 1   (D) 3

9. A graph omits axis labels and units. Main problem:

(A) all values become categorical   (B) the display becomes difficult or impossible to interpret responsibly   (C) the data change   (D) the median doubles

10. For comparing compact distribution summaries across groups, prefer:

(A) paragraph only   (B) single data point   (C) unscaled icon chart   (D) box plots
