1. In C=25+8h, 25 represents:

(A) hourly rate   (B) fixed starting cost   (C) number of hours   (D) residual

2. Predicting at x=20 from data ending at x=10 is:

(A) interpolation   (B) extrapolation   (C) an intercept   (D) a domain value already observed

3. A strong model report should include:

(A) only the equation   (B) domain, units, assumptions, error, and limitations   (C) only the largest prediction   (D) no source information

4. Using C=4+2.5m, cost at 8 miles:

(A) $20   (B) $26.50   (C) $32   (D) $24

5. Prediction inside the observed data range is:

(A) extrapolation   (B) residual   (C) domain   (D) interpolation

6. Residual is commonly calculated as:

(A) x−y always   (B) observed − predicted   (C) predicted + observed   (D) slope − intercept

7. Residuals close to zero generally indicate:

(A) all data are identical   (B) predictions close to observed values   (C) no function exists   (D) slope is zero

8. Why avoid careless extrapolation?

(A) all slopes reverse   (B) units disappear   (C) the relationship may change outside observed conditions   (D) equations stop existing

9. A model predicts 6.4 people. Best response:

(A) always round down   (B) discard the model automatically   (C) interpret using the context and appropriate discrete constraint   (D) always report 6.4 people

10. A strong model check includes:

(A) slope only   (B) prediction only   (C) units, plotted/data agreement, residuals, domain, and reasonableness   (D) equation only
