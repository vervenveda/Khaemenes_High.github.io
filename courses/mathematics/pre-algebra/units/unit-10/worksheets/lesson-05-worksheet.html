1. For (1,4),(3,10),(5,16), the rate is:

(A) 2   (B) 3   (C) 4   (D) 6

2. A negative rate means the output generally:

(A) increases   (B) decreases   (C) stays zero   (D) has no units

3. A horizontal graph has rate:

(A) −1   (B) 0   (C) 1   (D) undefined

4. If y rises 12 while x rises 4, rate is:

(A) 8   (B) 1/3   (C) 3   (D) 48

5. If distance is miles and time hours, rate units are:

(A) miles per hour   (B) hours per mile only   (C) miles   (D) hours

6. A horizontal line has rate/slope:

(A) infinite   (B) 0   (C) undefined   (D) 1

7. A savings account grows $15 each week. Rate:

(A) 1 week/$15 only   (B) $0/week   (C) $15/week   (D) $15 total

8. A negative rate means:

(A) input decreases only   (B) there is no relationship   (C) output decreases as input increases   (D) output is always negative

9. Using (2,3),(5,12), student calculates (12−3)/(2−5)=−3. Error:

(A) 12−3 is wrong   (B) subtraction order must be consistent in numerator and denominator   (C) negative slopes are impossible   (D) points cannot be used

10. For nonlinear data, rate between two points is called:

(A) domain   (B) average rate of change   (C) always constant slope   (D) intercept
