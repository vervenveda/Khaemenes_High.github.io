Linear Relationship Data Story Investigation

Create a transparent data story using a public, fictional, or personally measured non-sensitive data set; connect coordinates, table, graph, equation, rate, prediction, residuals, and model limitations.

Open Project Workspace

Project sequence

Build and test an evidence-aware linear relationship.

Select a safe question and data set

Examples: travel time, garden growth, production, temperature, energy use, art dimensions, event costs, or environmental measurements. Use public, fictional, or non-sensitive measured data.

Define variables, units, domain, and source

State the independent and dependent variables, units, observed input range, scale, assumptions, and where the data came from.

Create four connected representations

Build a table, coordinate graph or scatter plot, verbal description, and equation or line of fit. Explain slope and intercept.

Test the model

Calculate at least three residuals, identify one interpolation and one extrapolation, and compare observed and predicted values.

Communicate a responsible conclusion

Explain the trend, useful prediction range, uncertainty, limitations, and one decision the model can or cannot support.

Rubric

DimensionProficient evidence
Definitions and sourceVariables, units, domain, scale, source, and privacy choices are explicit.
RepresentationsTable, graph, words, coordinates, and equation describe the same relationship.
Rate and structureSlope, intercept, and function meaning are calculated and interpreted correctly.
Model testingResiduals, interpolation, extrapolation, and fit are examined.
ReasoningClaims distinguish observed evidence from model-based prediction.
CommunicationThe conclusion states assumptions, uncertainty, and limitations without overstating the model.
