Teacher Guide

A three-week sequence for developing equation balance, inverse operations, formula rearrangement, and responsible modelling.

Suggested pacing

Week 1: Lessons 1–3. Week 2: Lessons 4–6. Week 3: Lessons 7–8, project, review, and mastery check.

High-leverage routines

  • Read the equals sign as “has the same value as.”
  • Require the same valid operation on both sides.
  • Simplify structure before isolating the variable.
  • Check every solution in the original equation.
  • Require variable definitions, units, and constraints in models.

Common misconceptions

  • The equals sign means “the answer comes next.”
  • A term is moved across the equals sign without explaining an inverse operation.
  • Distribution reaches only one term.
  • Division by a variable is performed without a nonzero restriction.
  • An algebraic solution is accepted even when it violates context.

Differentiation

Foundation learners use balances, algebra tiles, operation arrows, and substitution checks. Core learners solve signed rational equations and rearrange formulas. Extended learners analyze parameters, identities, contradictions, domains, and alternate solution paths.

Assessment use

The public mastery check is formative. Review written transformations, equality justifications, verification, units, and interpretation alongside scores. Use protected alternate forms for high-stakes assessment.
