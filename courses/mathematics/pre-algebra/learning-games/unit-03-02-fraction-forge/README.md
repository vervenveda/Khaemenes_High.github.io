The companion is synchronized to the lesson’s four central goals: generating equivalent fractions, simplifying with common factors/GCF, estimating with benchmark fractions, and understanding equivalence as multiplication by a form of 1.

The Animated Instruction Studio includes Multiply by 1, Simplify with GCF, Benchmark Sense, and Illegal Moves. Students see, for example:

1/2 × 4/4 = 4/8

and

42/56 → divide both by 14 → 3/4

while also seeing why something like subtracting the same number from numerator and denominator does not preserve fraction value.

The game retains Foundation / Core / Extended pathways, 12/16/20 missions, hints, explanations, missed-item replay, local best score, keyboard controls, printable reference, and the 80% mastery target.

I also corrected one curriculum QA issue in the supplied Lesson 2 practice. The scale item marks “6/16 inch for 12 feet” as equivalent to “3/8 inch for 6 feet,” but that changes the scale. Since 6/16 = 3/8, the equivalent representation using the existing choices is “6/16 inch for 6 feet.” The game uses the mathematically correct version.
