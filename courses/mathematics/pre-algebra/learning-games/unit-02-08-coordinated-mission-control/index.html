Operation choice comes before computation.

The arithmetic only makes sense after the situation has been translated correctly.

Context → operation → sign → calculation → check.

Descends 4 m/min for 3 min → 3(−4)=−12

Multi-step problems chain different ideas.

Repeated change may require multiplication first, then addition to combine that change with an initial position.

Translate every stage before combining them.

Then right 5 → −12+5=−7
