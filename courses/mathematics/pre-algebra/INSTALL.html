Pre-Algebra · Archaemenes + Style Upgrade v1

This is deliberately a drop-in layer so the existing 148 KB Pre-Algebra engine does not need to be rebuilt.

1. Upload the asset

Put:

assets/prealgebra-archaemenes-upgrade.js

inside:

courses/mathematics/pre-algebra/assets/

2. Add one line to the current Pre-Algebra index.html

Immediately before the final </body>, add:

<script src="assets/prealgebra-archaemenes-upgrade.js"></script>
Nothing else in index.html needs to be replaced. The existing APP object, 36-week curriculum, localStorage records, quizzes, exams, tools, reports and assessment logic remain intact.

What the upgrade adds

It adds the Archaemenes course mentor, passes current Week/Unit/Lesson context to his High School page, changes the course presentation into the centered forest/gold Khaemenes academic style, adds the canonical Beta Program button, and hardens the existing details/dropdown menus so they collapse on outside click or Escape.

Trust boundary

The mentor layer does not read answer keys or modify scores, mastery, exams, learner records or progression.
