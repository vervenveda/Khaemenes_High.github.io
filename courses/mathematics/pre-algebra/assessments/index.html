Evidence standards

Records should be accurate, transparent, and proportionate.

Definitive scoring

Each scored multiple-choice item is intended to have one correct answer, with equivalent duplicate choices and subjective “best” wording excluded.

Documented administration

Record testing conditions, accommodations, corrections, retests, and which attempt is retained as the official course result.

Private record control

Browser data remains local unless exported. Store printed and exported records in the family’s chosen secure portfolio location.
