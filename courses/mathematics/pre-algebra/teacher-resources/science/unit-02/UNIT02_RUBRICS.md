# Unit 02 Rubrics

## Cell Model Performance Task — 24 points
| Criterion | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Classification | Missing | Broad category | Precise type | Precise type supported by evidence |
| Structures | Missing | Several inaccurate | Major structures accurate | Distinguishes universal, common, optional |
| Structure–function | Missing | Labels only | Most functions accurate | Interactions and trade-offs explained |
| Membrane and transport | Missing | Vague | Correct transport connection | Gradient, selectivity, process connected |
| Scale | Missing | Implied | Not-to-scale statement | Quantitative or comparative scale |
| Model design | Missing | Difficult to interpret | Organized | Design choices justified |
| Limitations | Missing | One generic | Three relevant | Linked to possible misinterpretation |
| Communication | Missing | Unclear | Clear | Precise, accessible, transparent |

Suggested mastery: 19/24, with no zero in accuracy or limitations.

- Reasoning: 0–2
- Limitations and communication: 0–2
