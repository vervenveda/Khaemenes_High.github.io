# Unit 06 Real-Evidence Source Notes

## CIAAW

Use the 2024 standard atomic-weight table as the current critical recommendation. Several elements have intervals because isotope composition varies in normal materials.

## NIST Isotope Data

The chlorine, magnesium, and silicon records in this unit are transcribed from NIST's Atomic Weights and Isotopic Compositions database. Representative compositions may not match every natural material.

## NIST Spectra and Configurations

The Atomic Spectra Database provides measured spectral lines and energy levels. The electronic-configuration reference supplies ground-state configurations. Shell totals in this course are a simplified instructional transformation for elements 1–20.

## IUPAC

Use IUPAC for element names, symbols, and periodic-table terminology.

## Evidence Distinction

A database value is a recorded or recommended datum with provenance. A shell diagram, periodic trend, or atomic model is an explanatory representation. Students must not treat them as identical evidence types.
