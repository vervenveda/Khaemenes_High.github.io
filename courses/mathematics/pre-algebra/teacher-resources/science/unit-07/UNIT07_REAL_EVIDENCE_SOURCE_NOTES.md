# Unit 07 Real-Evidence Source Notes

## IUPAC

Use the current Gold Book for bonding terminology. IUPAC cautions that practical bonding descriptions often involve degrees of ionic character rather than perfectly pure categories.

## NIST Chemistry WebBook

Use NIST for thermochemical and physical-property records. Values depend on phase, temperature, pressure, reference state, and selected compilation.

## PubChem

Use PubChem for substance identifiers, formulae, structures, compiled properties, and safety summaries. Follow the original cited source when a precise value is load-bearing.

## American Chemical Society Rate Investigation

The optional effervescent-tablet activity is based on ACS guidance. Students enter their own measured times; the application contains no fictional default results.

## Data Integrity

Always identify:
- exact formula and phase
- temperature and pressure when relevant
- whether the value is measured, calculated, estimated, or compiled
- source and access date
- uncertainty, range, or method limitation
- whether an educational model is being used instead of a measurement
