# High School Mathematics — Learning Depth, Material Quality & Quantity Audit
**Date:** 2026-11-17  
**Courses:** Pre-Algebra · Algebra I · Geometry · Algebra II  
**Scope:** source-level curriculum, lesson, practice, project, assessment, differentiation, retention, and teacher-support audit.

## Audit standard

This audit does **not** equate file count with rigor. The review considers:
- conceptual understanding;
- procedural fluency and flexibility;
- mathematical reasoning / proof;
- multiple representations;
- application and modelling;
- worked examples → guided practice → independent transfer;
- misconception/error analysis;
- retrieval and cumulative retention;
- pathway differentiation;
- assessment abundance and retake validity;
- project / constructed-response evidence;
- teacher/evaluator support;
- pacing and cognitive load.

The target is a coherent progression from understanding → practice → reasoning → transfer → retention, rather than maximum content volume.

---

# Executive finding

There is **no broad curriculum-quality collapse in any of the four courses**.

The courses are unusually ambitious and, in three cases, already have more learning material than they need for a conventional one-year course.

The main findings are:

1. **Algebra I is the strongest all-around course.**
2. **Pre-Algebra has exceptional quantity and strong conceptual/application depth; its primary risk is overload rather than shortage.**
3. **Geometry is exceptionally strong in visual reasoning, proof, construction, practice, and assessment; its next improvements should make diagrams/projects more lesson-specific rather than simply adding material.**
4. **Algebra II has excellent scope and modelling ambitions, but its assessment pool, practice differentiation, visual representation layer, worked-example depth, retention cycle, and lesson-scoring reliability lag behind the other three.**
5. The next mathematics-content build should therefore be **Algebra II depth first**, not a four-course content expansion.

# Research-aligned learning architecture

Across the repository, the strongest recurring features are:
- explicit objectives;
- worked examples;
- guided and independent practice;
- mathematical verification;
- error analysis;
- reflection;
- modelling;
- multiple pathways;
- 80% mastery gates;
- correction/retake structures;
- projects and portfolio evidence.

These align well with major evidence-based mathematics-learning principles: conceptual/procedural balance, reasoning, modelling, representation, worked-example/problem alternation, retrieval, and explanatory questioning.

The main research-alignment issue is **not absence of these practices**. It is that they are not equally strong in every course.

# PRE-ALGEBRA

## Quantity

Formal course:
- 97 official lessons across Units 01–13.
- 6 additional Unit 0 refresher lessons.
- 39 Foundation / Core / Extended unit-practice pages.
- 149 worksheet HTML surfaces.
- 13 applied investigations / projects.
- teacher guide + family guide + teacher answer key for every formal unit.
- 36 week-specific quizzes × 10 questions = 360 aligned weekly quiz prompts.
- 56-question cumulative midterm.
- 80-question cumulative final.
- modelling capstone / portfolio.

Representative unit practice:
- Foundation commonly uses a smaller guided set.
- Core and Extended increase quantity and/or reasoning demand.
- Example Unit 08: Foundation 15 questions; Core 18; Extended 18.

## Lesson depth

Representative formal lessons routinely contain:
- 4 explicit objectives;
- vocabulary;
- warm-up retrieval;
- 6 concept/reasoning blocks;
- multiple worked examples;
- Foundation / Core / Extended guidance;
- application;
- 20 scored questions;
- error analysis / verification;
- reflection.

Examples inspected:
- Unit 08 literal equations includes structure, restrictions, units, formula rearrangement, verification, error analysis, and contextual interpretation.
- Unit 12 sampling/bias lesson distinguishes random sampling, random assignment, association, causation, confounding, uncertainty, and evidence limits.
- Unit 13 modelling requires verification, validation, residual reasoning, revision, reproducibility, sensitivity, and human judgment.

This is substantially deeper than a worksheet-only Pre-Algebra course.

## Projects

Each formal unit has an investigation. The projects require evidence rather than decorative “real-world” context.

Examples:
- financial decision investigation requires terms, calculations, comparison, changed assumptions, limitations, and recommendation;
- final capstone requires framing, planning, multiple representations, verification, sensitivity, uncertainty, fairness/accessibility, defense, revision, and reflection.

## Strength rating

- Conceptual depth: **Excellent**
- Procedural opportunity: **Excellent**
- Reasoning / error analysis: **Excellent**
- Application / modelling: **Excellent**
- Differentiation: **Excellent**
- Assessment quantity: **Excellent**
- Teacher support: **Excellent**
- Visual representation: **Strong**
- Retention: **Strong to Excellent**
- Pacing / cognitive-load control: **Needs monitoring**

## Gaps

### PA-1 · Resource abundance needs a clearer minimum route
The course contains so many lessons, practices, worksheets, projects, games, and supporting materials that a learner can mistake “available” work for “required” work.

**Recommendation:** mark each resource as:
- Required;
- Recommended;
- Optional Extension;
- Recovery / Reteach.

### PA-2 · Unit 0 is appropriately compact, but its teaching layer is thinner than its testing layer
Unit 0 Weeks 5–6, for example, provide short concept summaries followed by 20-question lesson practice + 10-question weekly quiz.

That is reasonable for a refresher **if prior knowledge is only rusty**. For a learner who truly lacks the concept, it can become assessment-heavy.

**Recommendation:** add a “Need the full lesson?” route from every Unit 0 week to a richer worked-example / visual mini-lesson.

### PA-3 · Weekly quizzes are strongly week-specific, but delayed cumulative retrieval should be more explicit
The current depth patch deliberately aligns each 10-question quiz to that week. That is good alignment, but long-term retention benefits from also revisiting older knowledge after delay.

**Recommendation:** preserve 8 week-specific items and add 2 non-gating cumulative retrieval items, or create a separate low-stakes retention check every 3–4 weeks.

### PA-4 · Do not add another broad content strand
The course already covers number, rational arithmetic, ratios, finance, powers, algebra, equations, inequalities, linear functions, geometry, statistics/probability, evidence, and modelling.

The next improvements should refine retrieval, pathway clarity, and representations—not add topics.

# ALGEBRA I

## Quantity

- 87 formal lessons.
- 39 unit-practice pages.
- 435-question base bank before additional abundant / upgrade banks.
- Base bank by unit ranges from 25–40 questions.
- difficulty tagging is systematic.
- 36 week-specific mastery checks × 10 questions = 360 weekly prompts.
- 13 substantial unit mastery checks.
- 60 selected-response + 6 human-reviewed constructed-response midterm.
- 100 selected-response + 10 human-reviewed constructed-response final.
- at least one applied project per unit.
- additional labs, remediation / repair packs, synthesis challenges, family guides, teacher guides, answer keys, and a capstone/oral defense.

## Lesson depth

The course is renderer/data-driven, so small lesson HTML files are **not** evidence of shallow lessons.

Representative unit data contain:
- 4 objectives;
- concept explanations;
- a mystery/problem launch;
- a deliberate misconception / wrong solution;
- 3 substantive reading sections;
- 2 fully worked examples with reasoning and steps;
- guided practice;
- transfer task;
- explicit transfer criteria;
- lesson check;
- model defense / reflection.

Unit 06 additionally uses abundant aligned banks and a synthesis challenge requiring:
- selected-response reasoning;
- error analysis;
- transfer/modelling;
- mathematical defense;
- written evaluator evidence.

## Differentiation

Algebra I differentiation is real, not cosmetic.

Representative Unit 06:
- Foundation: 16 balanced items; difficulty ceiling 1.
- Core: 24 items; difficulty ceiling 2.
- Extended: 32 items; includes Level-3 reasoning.

The general shared renderer also uses:
- Foundation ≈ 15;
- Core ≈ 20;
- Extended ≈ 25;
with difficulty ceilings 1 / 2 / 3.

## Projects / capstone

The Unit 13 portfolio/oral defense is particularly strong:
- multi-week planning runway;
- formal Week 36 evidence;
- at least 3 complementary representations;
- integration of multiple Algebra I domains;
- independent verification;
- revision based on evidence;
- sensitivity analysis;
- uncertainty/fairness;
- bounded conclusion;
- oral defense;
- reflection.

## Strength rating

- Conceptual depth: **Excellent**
- Procedural fluency: **Excellent**
- Reasoning / mathematical argument: **Excellent**
- Application / modelling: **Excellent**
- Differentiation: **Excellent**
- Assessment abundance: **Excellent**
- Cumulative evidence: **Excellent**
- Teacher / remediation support: **Excellent**
- Retention architecture: **Excellent**
- Overall balance: **Best of the four**

## Gaps

There is no major curricular-content hole.

### A1-1 · Protect the learner from resource overload
Algebra I now contains base banks, abundant banks, weekly checks, unit checks, labs, projects, synthesis challenges, remediation, and formal exams.

**Recommendation:** define one canonical learner route and keep everything else visibly supplemental.

### A1-2 · Add a non-gating long-delay retention signal
Weekly mastery is strongly aligned to the current week. The cumulative exams provide retention evidence later, but there is room for a small delayed-retrieval layer between them.

**Recommendation:** add short “Retain” checks every 3–4 weeks drawing from material learned at least 2 weeks earlier.

### A1-3 · Preserve depth rather than expanding scope
Do not add more major Algebra I topics. Future work should improve coherence, multiple representations, and learner navigation.

# GEOMETRY

## Quantity

- 90 formal lessons.
- 39 pathway practice pages.
- 13 applied investigations.
- 36 weekly mastery gates × 10 questions = 360 unique weekly prompts.
- 13 formal 20-question unit mastery checks.
- unit mastery is generated from week-aligned depth banks and balances five dimensions:
  - procedural fluency;
  - multi-step application;
  - representation / interpretation;
  - error analysis;
  - transfer reasoning.
- 60 selected-response + 6 constructed-response midterm.
- 100 selected-response + 10 constructed-response final.
- 90 individual lesson teacher-key pages plus broader teacher/family support.

## Lesson depth

Geometry is the strongest visual course.

Representative lessons contain:
- diagrams / SVGs;
- formulas;
- worked reasoning;
- misconception checks;
- printable problem grids;
- proof / construction / explanation;
- units;
- reflection and application.

The pathway practices materially alter the intellectual demand:
- Foundation may provide a labelled model and require one justified step.
- Core requires complete reasoning.
- Extended asks for generalization or independent verification.

## Proof and reasoning

The course correctly treats geometry as more than formula substitution:
- constructions;
- congruence and proof;
- coordinate proof;
- transformations;
- similarity;
- trigonometry;
- circles;
- loci;
- geometric probability;
- solids;
- CAD / scale drawing;
- capstone defense.

## Assessment validity

The apparent base-bank shortage in later units is **not** a defect in the formal unit mastery checks.

The unit mastery loader replaces the base bank with a 20-question set drawn from the weekly mastery depth banks and fails closed if:
- 20 items are unavailable;
- every instructional week is not represented;
- each of five depth dimensions does not contribute four questions.

That is a strong design.

## Strength rating

- Conceptual depth: **Excellent**
- Visual / spatial representation: **Exceptional**
- Proof / reasoning: **Exceptional**
- Procedural fluency: **Excellent**
- Differentiation: **Excellent**
- Assessment depth: **Exceptional**
- Teacher support: **Exceptional**
- Application / modelling: **Excellent**

## Gaps

### GEO-1 · Some lesson worksheets are broader than the named lesson
Example: a CPCTC / multi-step proof lesson also presents triangle-angle, triangle-inequality, and congruence questions.

Spiral review is valuable, but the student needs to know which items are:
- lesson-specific mastery;
- prerequisite retrieval;
- cumulative retrieval.

**Recommendation:** label problem boxes by purpose.

### GEO-2 · Repeated generic diagrams should become problem-specific where practical
Several worksheets reuse the same category diagram across multiple questions. A visual representation helps most when the diagram actually expresses the mathematical information in that problem.

**Recommendation:** upgrade high-value proof / circle / trig / loci worksheets to problem-specific diagrams.

### GEO-3 · Projects share a strong but highly reusable template
The common investigation framework is good, but some projects could show more unit identity.

Examples:
- Unit 03: formal proof dossier;
- Unit 08: chord/tangent construction investigation;
- Unit 09: locus / conic design;
- Unit 12: CAD constraint and tolerance brief.

The goal is not a longer rubric—it is more unit-specific evidence.

# ALGEBRA II

## Quantity

- 92 formal lessons.
- 39 practice pages.
- 13 applied investigations.
- 196 prompts in the shared question-bank file:
  - 156 unit-tagged course questions;
  - 40 diagnostic items.
- exactly **12 unit-bank items per formal unit**.
- unit mastery selects **10 of those 12**.
- 60-question midterm covering Units 01–06.
- 100-question final covering Units 01–13.
- teacher and family guide for every unit.
- strong 13-project modelling spine.

## Scope

The course covers:
1. advanced functions / inverses;
2. polynomials + complex numbers;
3. polynomial equations / division;
4. rational functions;
5. radical functions;
6. exponentials;
7. logarithms;
8. nonlinear systems + matrices;
9. sequences / series / binomial theorem;
10. trigonometric functions;
11. identities / equations / oblique triangles;
12. probability / distributions / inference;
13. advanced modelling.

This is an ambitious Algebra II + Advanced Functions course. The scope is **not** the problem.

## Lesson strengths

Representative lessons use a consistent learning flow:
1. prerequisite recall;
2. governing relationship;
3. worked examples;
4. explain why;
5. guided attempt;
6. independent practice;
7. misconception repair;
8. contextual transfer;
9. feedback readiness;
10. reflection.

That is pedagogically sound.

The applied projects are also strong:
- question and context;
- variables / assumptions;
- multiple representations;
- calculation;
- validation / revision;
- sensitivity / uncertainty / fairness;
- communication;
- defense / reflection;
- analytic rubric.

## Major gaps

### A2-1 · The question bank is too small for the stated mastery / retake model — **Highest priority**

Each unit has only 12 unit-bank questions while a formal mastery check draws 10.

Therefore, if the engine draws only from that bank:
- any two 10-question unit forms from a 12-item pool must share **at least 8 questions**;
- a “new” unit mastery form can be at least 80% the same material.

The midterm is also constrained:
- Units 01–06 provide 72 unit-bank questions;
- the Midterm selects 60;
- any two 60-item forms from a 72-item pool must overlap by at least 48 questions.

The Final:
- 156 unit-tagged course questions;
- selects 100;
- any two 100-item forms must overlap by at least 44 questions.

**Recommendation:** build at least:
- 30–40 high-quality questions per unit;
- difficulty and reasoning-dimension metadata;
- alternate forms that avoid recent items;
- dedicated cumulative pools for Midterm / Final.

### A2-2 · Foundation / Core / Extended practice is currently label-only in item selection — **Highest priority**

The three practice pages each call the same assessment engine.

Current selection logic:
- filters by unit;
- shuffles;
- chooses the requested count.

It does **not** currently filter or weight by:
- Foundation / Core / Extended;
- difficulty;
- reasoning dimension.

The selected pathway is stored with the result, but it does not materially alter the set.

By contrast:
- Pre-Algebra has different pathway banks / demands;
- Algebra I explicitly changes difficulty ceiling and quantity;
- Geometry changes reasoning/scaffolding demands.

**Recommendation:** add question metadata and a canonical pathway blueprint:
- Foundation = access + prerequisite + scaffolded procedural/conceptual;
- Core = complete unit target;
- Extended = non-routine, parameter, proof/justification, model critique.

### A2-3 · Advanced topics need more worked-example depth

Representative Algebra II lessons contain **two worked examples**.

For topics such as:
- rational equations;
- complex roots;
- logarithmic equations;
- matrices;
- trigonometric graphs;
- identities;
- sinusoidal regression;
- statistical inference;

two concise examples are not enough to expose:
- boundary cases;
- alternate strategies;
- invalid methods;
- parameter changes;
- transfer.

**Recommendation:** target 3–5 intentionally different worked examples for conceptually difficult lessons:
1. canonical;
2. boundary/restriction;
3. misconception;
4. representation change;
5. non-routine application where appropriate.

Then fade support as expertise increases.

### A2-4 · Multiple representations are underbuilt inside the lessons

Four representative lessons sampled from Units 01, 04, 10, and 12 contained:
- no embedded SVG;
- no figure;
- no canvas;
- no image;
- no table.

The shared lesson-tools engine also does not create graph/visual elements.

That is a meaningful gap for a course dominated by functions, rational behavior, trigonometry, transformations, probability distributions, and model comparison.

**Recommendation:** add local/offline-first:
- function graphs;
- unit-circle diagrams;
- transformation overlays;
- asymptote/domain visuals;
- complex-plane diagrams;
- matrix / system representations;
- distribution plots;
- residual plots;
- tables tied directly to symbolic forms.

### A2-5 · No equivalent 36-week retrieval/mastery layer

Geometry and Algebra I explicitly expose 36 weekly mastery checks.  
Pre-Algebra has 36 aligned weekly quizzes.

Algebra II currently has:
- lesson evidence;
- pathway practice;
- unit mastery;
- Midterm;
- Final;
- projects.

It lacks the same weekly delayed-retrieval rhythm.

**Recommendation:** add a low-stakes 36-week retrieval layer before making it a progression gate. It should mix:
- current lesson retrieval;
- prior-unit retrieval;
- representation;
- error analysis;
- transfer.

### A2-6 · Lesson mastery scoring lacks a standardized scoring contract

Algebra II lesson progression currently asks an evaluator to enter a 0–100 score after reviewing lesson evidence.

The lesson engine stores that score and unlocks progression at 80%.

The teacher guides appropriately say to use multiple evidence sources, but they do not provide a common 0–100 lesson-scoring rubric.

That creates evaluator reliability risk.

**Recommendation:** replace “enter a score” with a common analytic lesson-evidence rubric, for example:
- conceptual understanding 25;
- procedure / accuracy 25;
- reasoning / justification 20;
- verification / representation 15;
- transfer / communication 15.

Or calculate the score from explicit criteria and require evaluator attestation.

### A2-7 · Breadth is beginning to outrun consolidation

92 lessons plus matrices, full trigonometry, statistics/inference, and modelling in 36 weeks is ambitious.

Do **not** add more topics.

The right repair is:
- more retrieval;
- more visual representation;
- richer worked examples;
- better differentiation;
- larger banks;
- clearer mastery evidence.

1. Make diagrams more problem-specific.
2. Label lesson-specific vs spiral-retrieval problems.
3. Make projects more unit-specific.

## Tier 3 — Pre-Algebra
1. Clarify required vs optional resource routes.
2. Strengthen Unit 0 teaching routes for learners who need instruction rather than review.

## Tier 4 — Algebra I
1. Preserve the current depth.
2. Clarify canonical vs optional route.
3. Add small delayed-retention signals only where they add value.
4. Avoid adding new topic breadth.

# Recommended next implementation program

The safest next curriculum build is:

**Algebra II Unit 01 pilot → validate the upgraded lesson/practice/mastery pattern → propagate Units 02–13 → add weekly retrieval → then make small targeted refinements to Geometry and Pre-Algebra.**

For the Algebra II Unit 01 pilot:
- retain the existing 6 lessons;
- add richer visual / representation layers;
- expand the unit bank from 12 to at least 36 questions;
- tag every item by lesson, difficulty, representation, reasoning dimension, misconception, and pathway suitability;
- implement real Foundation / Core / Extended selection;
- create one weekly retrieval set per instructional week;
- add a common lesson-evidence rubric;
- test retake novelty;
- preserve current 80% mastery policy.

If Unit 01 passes, the architecture can become the canonical Algebra II content-depth engine.

# Audit boundary

This was a source-level forensic curriculum audit. It evaluates the material actually present in the repository and its runtime selection rules.

It does not yet include:
- observed student completion time;
- live learner interviews;
- classroom discourse;
- real-world error-rate data;
- longitudinal retention results.

Those would be the next empirical layer after the source curriculum is internally balanced.
