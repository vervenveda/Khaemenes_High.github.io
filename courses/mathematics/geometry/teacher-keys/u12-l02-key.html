Precision Lines, Angles & Dimensions

Math Word of the Day · Tolerance

tolerance is the permitted variation around a target dimension. For 25.0 mm ±0.2 mm, acceptable values run from 24.8 mm through 25.2 mm.

Instructional anchor

Keep construction precision and measurement/reporting precision distinct. Exact CAD entry can encode a target, while real measurement may still have finite resolution and error.

1
Answer: 24.8 mm ≤ value ≤ 25.2 mm.
2
Answer: Absolute error = 0.3 mm. Relative error = 0.3/120.0=0.0025, so percent relative error = 0.25%.
3
Answer: 0.2°. Absolute angular error = |59.8−60.0|.
4
Answer: The display claims precision the measuring tool cannot support. A tool reading only to the nearest tenth does not justify four decimal places.
5
Answer: No. Acceptable interval is 895–905 mm; 906 mm exceeds the upper tolerance by 1 mm.
6
Expected reasoning: Exact coordinates/angle entry control the geometry itself; dimensions communicate and document intended measurements for readers and verification. A dimension label should describe accurate geometry, not replace it.

Misconception watch

  • Treating tolerance as the same thing as actual error.
  • Reporting relative error without comparing it to the target magnitude.
  • Assuming more displayed decimals mean greater real accuracy.
  • Using annotation text as a substitute for accurate CAD construction.

Mastery: 80% plus corrections and a correct explanation of tolerance.
