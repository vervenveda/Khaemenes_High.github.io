Distance from a Point to a Line · Teacher Key

Shortest-distance geometry and coordinate point-to-line calculations.

Teacher KeyExact form firstMastery target 80%

Instructional focus

  • Shortest point-to-line distance is perpendicular.
  • Horizontal/vertical cases should be understood geometrically before formula use.
  • For Ax+By+C=0, use d=|Ax₀+By₀+C|/√(A²+B²).
  • Center-to-line distance equal to a circle radius provides a tangency test.
