Unit 01 · Lesson 01 · Foundations, Constructions & Geometric Reasoning

Points, Lines, Planes & Defined Terms

Build precise geometric language by identifying and naming points, lines, planes, segments, rays, opposite rays, collinear points, and coplanar points.

Foundation · Core · ExtendedMastery target 80%20 problemsPrintable

Learning intention

I can identify, name, and distinguish the basic objects of Euclidean geometry and use notation that communicates exactly which object I mean.

Success evidence

  • Distinguish undefined terms—point, line, and plane—from defined terms built from them.
  • Name lines, segments, rays, and angles using valid notation.
  • Recognize collinear, noncollinear, coplanar, and noncoplanar relationships.
  • Explain why a drawing is a model and not automatically proof of an unstated relationship.

Visual model

A, B, C lie on line m, so they are collinear. All four points A, B, C, and D lie in plane P, so they are coplanar. The ray beginning at B and passing through E is ray BE.

Worked reasoning

Question: If points R, S, and T lie on the same line and S is between R and T, name two rays that are opposite rays.

  1. Opposite rays must share the same endpoint.
  2. They extend in opposite directions on one line.
  3. Using S as the common endpoint, ray SR points toward R and ray ST points toward T.

Conclusion: ray SR and ray ST are opposite rays.

Misconception check: Segment AB and line AB use the same two points in their names, but they are different objects. A segment has two endpoints; a line extends without end in both directions.

Vocabulary

Learning pathways

Foundation: Use the visual model and speak each object name before writing notation.

Core: Complete all 20 problems and justify Problems 8, 12–16, and 20.

Extended: Create a diagram containing five points that demonstrates both collinear and noncollinear sets, then write three true statements about it.

Mastery recovery

If fewer than 16 of 20 responses are secure, review naming/notation first, then relationships among points, lines, and planes before reassessment.
