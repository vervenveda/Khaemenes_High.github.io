Unit 01 · Lesson 05 · Foundations, Constructions & Geometric Reasoning

Conditional Statements, Converses & Counterexamples

Translate geometric statements into logical form, distinguish related conditionals, and use counterexamples to test universal claims.

Foundation · Core · ExtendedMastery target 80%20 problemsPrintable

Learning intention

I can identify hypotheses and conclusions, write converse, inverse, and contrapositive statements, determine truth values, and disprove false universal claims with valid counterexamples.

Success evidence

  • Translate “if p, then q” accurately as p → q.
  • Distinguish converse, inverse, and contrapositive.
  • Recognize that a conditional and its contrapositive are logically equivalent.
  • Give a counterexample that satisfies the hypothesis but violates the conclusion.

Logic map

conditional: p → qconverse: q → pinverse: ¬p → ¬qcontrapositive: ¬q → ¬p

Equivalent pairs: conditional ↔ contrapositive; converse ↔ inverse. Equivalent statements always share a truth value.

Worked reasoning

Claim: If a quadrilateral is a square, then it is a rectangle.

  1. Hypothesis: the quadrilateral is a square.
  2. Conclusion: the quadrilateral is a rectangle.
  3. Converse: If a quadrilateral is a rectangle, then it is a square. False.
  4. A 3-by-5 rectangle is a counterexample to the converse.
  5. Contrapositive: If a quadrilateral is not a rectangle, then it is not a square.

Misconception check: A counterexample must meet the hypothesis and fail the conclusion. An object outside the hypothesis cannot disprove the conditional.
