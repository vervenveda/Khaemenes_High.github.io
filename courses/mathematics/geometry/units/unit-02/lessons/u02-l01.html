Unit 02 · Lesson 01 · Transformations, Symmetry & Congruence

Translations on the Coordinate Plane

Model translations with vectors and coordinate rules, recover unknown translation information, and verify the geometric properties a translation preserves.

Foundation · Core · ExtendedMastery target 80%20 problemsPrintable

Learning intention

I can translate points and figures, write and recover translation rules, compose translations, and justify why a translation preserves size and shape.

Success evidence

  • Use vector and coordinate-rule notation accurately.
  • Apply one translation consistently to every vertex of a figure.
  • Recover a translation vector from a preimage and image.
  • Verify preserved distance, angle measure, parallelism, and orientation.

Translation model

A translation moves every point the same horizontal and vertical amount. For vector ⟨a,b⟩:

T⟨a,b⟩(x,y)=(x+a,y+b)vector = ⟨x′−x, y′−y⟩inverse = T⟨−a,−b⟩

Translations are rigid motions: corresponding lengths and angle measures are preserved. Parallel lines remain parallel, collinear points remain collinear, and orientation is preserved.

Worked reasoning

Example: Triangle A(−3,1), B(1,1), C(−1,4) is translated by ⟨5,−2⟩.

  1. Apply the same rule to every vertex: (x,y) → (x+5,y−2).
  2. A′=(2,−1), B′=(6,−1), C′=(4,2).
  3. Check AB=4 and A′B′=4, so this corresponding side length is preserved.
  4. The vector from A to A′ is ⟨5,−2⟩, matching the rule.

Misconception check: A translation does not swap coordinates, change signs automatically, or use different vectors for different vertices.
