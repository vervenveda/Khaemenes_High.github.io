CAD Workspace, Units, Grid & Snap

Set up a digital drafting environment so every later measurement, scale decision, and geometric construction starts from a reliable workspace.

Learning intention

Configure units, sheet size, grid spacing, snap spacing, and project recovery intentionally before drawing.

Success evidence

  • Choose units that match the design context.
  • Explain the difference between a visible grid and a snap increment.
  • Select a sheet size or working boundary appropriate to the intended output.
  • Predict coordinates created by a given snap spacing.
  • Save or preserve project state before beginning significant construction.

Workspace model

grid = visual referencesnap = allowed cursor incrementcoordinate = (x,y)

A grid can be coarser or finer than snap. The two settings serve different purposes: the grid helps you see spatial structure; snap constrains where points can land.

Worked setup decision

Scenario: Draft a small classroom plan 12 m by 9 m.

  1. Choose meters as the working unit.
  2. Choose a sheet or workspace large enough to contain the 12×9 design plus margins.
  3. Use a visible grid such as 1 m for quick spatial orientation.
  4. Use a finer snap such as 0.25 m if openings or furniture require quarter-meter placement.
  5. Save an initial project state before drawing major objects.

Setup principle: Precision begins before the first line is drawn.
