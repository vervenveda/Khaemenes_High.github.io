Unit 03 · Lesson 01 · Triangle Congruence & Proof

Triangle Classification & Angle Relationships

Build the triangle facts that later congruence proofs depend on: classification, angle sums, exterior angles, and triangle inequality.

Open-AgePrintableFoundation · Core · ExtendedMastery target 80%

Learning intention

Classify triangles from reliable evidence and use angle and side constraints to decide what a triangle must look like—or whether it can exist at all.

Success evidence

  • Classify by sides: scalene, isosceles, equilateral.
  • Classify by angles: acute, right, obtuse.
  • Use m∠A + m∠B + m∠C = 180°.
  • Use an exterior angle as the sum of its two remote interior angles.
  • Use |a-b| < c < a+b to test possible side lengths.

Visual model

m∠A+m∠B+m∠C=180°m∠ACD=m∠A+m∠B|a-b|<c<a+b

The exterior angle is supplementary to its adjacent interior angle and equals the sum of the two remote interior angles.

Worked reasoning

Example: An isosceles triangle has vertex angle 38°. Find each base angle.

  1. The two base angles are congruent. Let each be x.
  2. Use the triangle angle sum: 38 + x + x = 180.
  3. 2x = 142, so x = 71.
  4. Check: 38 + 71 + 71 = 180.

Precision check: A drawing can suggest a classification, but markings, measurements, coordinates, or stated facts are the evidence.
