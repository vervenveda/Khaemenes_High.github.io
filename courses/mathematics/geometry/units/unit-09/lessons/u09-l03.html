Distance from a Point to a Line

Measure the shortest distance from a point to a line and connect perpendicular geometry to a coordinate formula.

Open-AgePrintableGeometry + coordinatesMastery target 80%

Learning intention

Understand why point-to-line distance is always measured along a perpendicular segment and calculate that distance in geometric and coordinate settings.

Success evidence

  • Identify the perpendicular segment as the shortest path to a line.
  • Find simple distances to horizontal and vertical lines directly.
  • Use d=|Ax₀+By₀+C|/√(A²+B²) when a line is written Ax+By+C=0.
  • Interpret the distance in a geometric or applied context.

Shortest-distance model

distance = length of perpendicularAx+By+C=0d=|Ax₀+By₀+C|/√(A²+B²)

The formula is a coordinate shortcut for the same geometric idea: perpendicular distance. The absolute value keeps distance nonnegative.

Worked reasoning

Example: Find the distance from P(4,1) to the line 3x−4y+8=0.

  1. A=3, B=−4, C=8 and (x₀,y₀)=(4,1).
  2. Numerator: |3(4)−4(1)+8|=|16|=16.
  3. Denominator: √(3²+(−4)²)=√25=5.
  4. Distance = 16/5 = 3.2 units.

Misconception check: The distance is not found by choosing an arbitrary point on the line. Only the perpendicular segment gives the shortest distance.

Vocabulary

perpendicular distance — shortest distance from a point to a line.
foot of the perpendicular — point where the perpendicular meets the line.
standard linear form — Ax+By+C=0.
absolute value — magnitude without sign.

Reasoning pathway

Horizontal/vertical line? Read the coordinate difference directly. General line? Rewrite in Ax+By+C=0 form and apply the formula carefully.
