Locus as a Set of Points Meeting a Condition

Describe a locus as the complete set of points satisfying one geometric condition, and distinguish a boundary from a region.

Open-AgePrintableFoundation · Core · ExtendedMastery target 80%

Learning intention

Translate verbal geometric conditions into complete point sets using distance, equality, and boundary language.

Success evidence

  • Define a locus as all points satisfying a stated condition.
  • Recognize common loci such as a circle, parallel lines, and perpendicular bisectors from distance conditions.
  • Distinguish an exact boundary from an inside/outside region.
  • Test sample points without mistaking samples for the entire locus.

Visual model

A locus describes a condition first and a shape second. The condition determines every point that belongs—and every point that does not.

fixed distance from a point → circlefixed distance from a line → two parallel linesequal distance from A and B → perpendicular bisector

Worked reasoning

Example: Describe the locus of points exactly 4 cm from point O.

  1. The condition uses one fixed point and one fixed distance.
  2. Every qualifying point must be 4 cm from O.
  3. All such points form a circle centered at O with radius 4 cm.
  4. The interior is not included because points inside are less than 4 cm from O.

Misconception check: Drawing three or four points that work does not describe the locus. The locus is the entire set of all points satisfying the condition.

Vocabulary

locus — complete set of points satisfying a condition.
boundary — edge separating regions.
equidistant — the same distance from two or more objects.
region — a set containing area, not merely its edge.

Learning pathways

Foundation: Match verbal conditions to familiar locus shapes.

Core: Distinguish equality conditions from less-than/greater-than regions.

Extended: Write your own locus condition and justify every included boundary.
