Sine, Cosine & Tangent Ratios

Choose a trigonometric ratio from the known and unknown sides relative to a reference angle.

SOH-CAH-TOACalculator-readyMastery target 80%

Learning intention

Identify opposite, adjacent, and hypotenuse relative to a chosen acute angle, then select sine, cosine, or tangent to solve an unknown side.

Success evidence

  • Relabel opposite and adjacent when the reference angle changes.
  • Choose a ratio containing both the known and unknown sides.
  • Write the ratio equation before using a calculator.
  • Round only at the end and include units.

Visual model

sinθ=opp/hypcosθ=adj/hyptanθ=opp/adj

Worked reasoning

Example: From a 38° angle, the adjacent side is 14 m. Find the opposite side.

  1. Known: adjacent. Unknown: opposite.
  2. Choose tangent because tanθ=opposite/adjacent.
  3. tan38°=x/14, so x=14tan38°.
  4. x≈10.9 m.

Misconception check: SOH-CAH-TOA is not three formulas to try randomly; the side information determines the ratio.
