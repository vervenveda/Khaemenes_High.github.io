Inverse Trigonometry & Angle Measure

Recover an acute angle from a known side ratio and use calculator settings and rounding responsibly.

sin⁻¹ · cos⁻¹ · tan⁻¹Degree modeMastery target 80%

Learning intention

Write the side ratio first, then use the matching inverse trigonometric function to determine an angle in degrees.

Success evidence

  • Select the correct inverse function from the two known sides.
  • Confirm the calculator is in degree mode.
  • Interpret inverse notation as a function, not a reciprocal.
  • Round only after computing the angle.

Visual model

θ=sin⁻¹(opp/hyp)θ=cos⁻¹(adj/hyp)θ=tan⁻¹(opp/adj)

Worked reasoning

Example: Opposite=7 and adjacent=12. Find θ.

  1. Use tangent because the known sides are opposite and adjacent.
  2. tanθ=7/12.
  3. θ=tan⁻¹(7/12).
  4. In degree mode, θ≈30.3°.

Misconception check: tan⁻¹ does not mean 1/tan. Here it means the inverse function that returns an angle.
