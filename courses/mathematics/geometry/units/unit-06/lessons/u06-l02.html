Special Right Triangles: 45-45-90

Use the exact side ratio 1:1:√2 and recognize the isosceles-right-triangle structure.

Exact valuesPrintableMastery target 80%

Learning intention

Derive and use the 45-45-90 relationship: if each leg is x, the hypotenuse is x√2; if the hypotenuse is h, each leg is h√2/2.

Success evidence

  • Recognize equal acute angles imply equal legs.
  • Keep exact radical form unless a decimal is requested.
  • Move between a leg and hypotenuse in either direction.
  • Rationalize or simplify radicals appropriately.

Visual model

x:x:x√2h=x√2x=h√2/2

Worked reasoning

Example: Hypotenuse = 14. Find a leg.

  1. Use h=x√2.
  2. 14=x√2, so x=14/√2.
  3. Rationalize: x=7√2.
  4. Check: (7√2)²+(7√2)²=196=14².

Misconception check: √2 belongs on the hypotenuse when the leg is the base unit; do not multiply the hypotenuse by √2 again.
