Bearings, Vectors & Multi-Step Navigation

Translate quadrant bearings into components and combine travel legs to determine resultant displacement and direction.

NavigationVectorsMastery target 80%

Learning intention

Interpret bearings such as N 35° E, resolve a displacement into north/south and east/west components, add components across multiple legs, and recover a final distance and bearing.

Success evidence

  • Read quadrant-bearing notation from the named reference direction.
  • Assign component signs consistently.
  • Add vector components before finding a resultant.
  • Use Pythagorean theorem and inverse trig to state final magnitude and direction.

Visual model

N 35° E: start at north, turn eastR=√(x²+y²)θ=tan⁻¹(|x|/|y|)

Worked reasoning

Example: Travel 6 km east, then 8 km north.

  1. Add components: east=6, north=8.
  2. Resultant distance: √(6²+8²)=10 km.
  3. From north, θ=tan⁻¹(6/8)≈36.9°.
  4. Final bearing is N 36.9° E.

Misconception check: A bearing of N 35° E is measured from north toward east; it is not the same reference angle as E 35° N.
