# Khaemenes High — Grade 9 Global Studies Honors

A complete 36-week integrated social studies course for the public path:

`courses/social-studies/grade-09/`

## Included
- 36 distinct weeks
- 180 Monday–Friday lessons
- 108 principal assignments
- 36 weekly quizzes with 360 objective questions
- 45-question midterm plus short responses and essay
- 55-question final plus short responses and essay
- Original offline weekly readings
- Primary-source, map, data, economics, civics, and media-literacy work
- Nonpartisan civic capstone
- Student portal, teacher portal, reports, CSV/JSON export, printing, read-aloud, and local retakes
- 36 printable student packets and 36 teacher guides
- Searchable glossary and printable learning tools

## Launch
Open `index.html`.

## Student data
Records use browser `localStorage`. Export backups regularly. Data is not synchronized across devices.

## Teacher portal
Open `teacher/index.html`. Initial local passcode: `KHAE09`. Change it after first use.

Because GitHub Pages is a static host, this passcode is only a convenience layer. It is not secure server authentication, and the site must not contain sensitive student information.

## Required upload location
Upload the included `courses/social-studies/` directory into the repository root so the final path is:

`courses/social-studies/grade-09/index.html`
