# Assessment Classification Policy

## Public self-check

Public learner repositories may contain formative practice, unit mastery checks, diagnostics, and cumulative self-check forms when all scoring material is necessarily delivered to the browser.

These results are:

- editable by the learner/device owner;
- unsigned;
- non-authoritative until reviewed;
- unsuitable as confidential testing evidence by themselves.

## Supervised secure

A supervised secure assessment must satisfy all of the following:

- questions are newly authored and previously unpublished;
- correct answers and scoring rubrics remain only inside the protected Noema + Administration assessment authority;
- learner-delivered assessment packages contain no answer material;
- response packages contain responses, not scoring keys;
- grading occurs inside the private authority;
- reviewed results are eligible for signed record issuance.

## Permanence rule

If a secure assessment item or its answer is ever committed to a public repository, published to a public site, placed in a public issue, or otherwise publicly distributed, that item is permanently downgraded to public/self-check status and must be replaced in future secure versions.

## Pre-Algebra status

- Existing public midterm: self-check / non-confidential.
- Existing public final: self-check / non-confidential.
- Existing public unit mastery checks: self-check learning evidence.
- Midterm v2: confidential supervised assessment, authored here.
- Final v2: confidential supervised assessment, authored here.
