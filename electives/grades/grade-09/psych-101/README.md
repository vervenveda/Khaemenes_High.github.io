# Psychology 101 — Grade 9
## Foundations of Human Behavior

Initial GitHub-ready curriculum repository scaffold.

### Current curriculum status
- Week 1 — Psychology as a Science: **LOCKED**
- Week 2 — Brain, Nervous System & Consciousness: **LOCKED**
- Week 3 — Sensation, Perception & Attention: **LOCKED**
- Weeks 4–13 — scaffolded and awaiting week-by-week forensic audit

### Course identity
- Grade: 9
- Duration: 13 weeks
- Target structure: 65 daily lessons
- Format: independent study / homeschool / classroom
- Technology target: vanilla HTML + CSS + JavaScript
- Internet required: no
- External runtime dependencies: none
- Core academic rule: psychological science does not diagnose people from simple observations

### Sovereign design
The finished course is intended to operate without login, account creation, advertising,
external APIs, remote tracking, or required internet access. Student progress will be
stored locally with explicit export/import backup controls.

### Implementation status
This ZIP intentionally freezes the **curriculum architecture first**. Weeks 4–13 are not
being represented as finished. As each week passes the academic audit, its folder can be
filled and its status changed from `IN DEVELOPMENT` to `LOCKED`.
