# Week 05 · Day 01
## Encoding, Attention & Working Memory

**Essential Question:** Why does information have to be processed before it can be remembered well?

### Learning Objectives
- Distinguish exposure, attention, and encoding.
- Explain working memory as a limited mental workspace.
- Compare shallow processing with meaningful elaboration.
- Explain chunking without treating memory capacity as one fixed magical number.
- Analyze how divided attention can interfere with learning.

### Vocabulary in Context
encoding · attention · working memory · rehearsal · elaboration · chunking · cognitive load · familiarity

### Core Concept
Exposure is not the same as learning. Working memory temporarily holds and manipulates information, and its effective capacity depends on the material, organization, prior knowledge, and task demands. Meaningful processing often creates more useful retrieval relationships than passive rereading.

### Worked Example
Compare asking “What font is this word?” with “What does this concept mean, and how is it related to something I already know?” The second prompt requires deeper semantic processing and creates more connections for later retrieval.

### Psychological Scientist's Desk
Evaluate: **“If I read something several times, I must know it.”**

Students distinguish the feeling of familiarity from independent retrieval and delayed performance.

### Data Lens
Interpret fictional recall results under quiet study, background speech, text-message interruption, and continuous task switching. Identify the dependent variable, strongest and weakest conditions, and one limitation on generalization.

### Guided Investigation
Compare two equivalent word sets learned through repeated rereading versus semantic grouping and self-generated examples. Predict first, then analyze fictional recall results.

### Independent Assignment
Redesign one study routine to reduce unnecessary cognitive load and increase meaningful encoding. Justify each change using today’s concepts.

### Research Notebook Checkpoint
What would participants need to notice, understand, or remember for the semester phenomenon to occur? Identify whether attention or encoding could be a variable, mediator, confound, or irrelevant factor.

### Academic Journal
