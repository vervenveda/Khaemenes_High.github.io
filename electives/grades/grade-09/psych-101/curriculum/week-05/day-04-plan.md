# Week 05 · Day 04
## Reconstructive Memory, Misinformation & Source Monitoring

**Essential Question:** Why can a person be completely sincere about a memory that is partly inaccurate?

### Learning Objectives
- Explain reconstructive memory.
- Describe how schemas and later information can influence recall.
- Define source monitoring and source confusion.
- Distinguish confidence from objective accuracy.
- Evaluate memory evidence without treating error as dishonesty.

### Vocabulary in Context
reconstructive memory · schema · misinformation effect · leading question · source monitoring · source confusion · confidence · accuracy

### Core Concept
Remembering rebuilds an event from stored details, prior knowledge, current cues, and later information. Reconstruction is a normal feature of human memory, not proof that memory is useless.

### Worked Example
A person remembers an office and later reports books that were never shown. The error may reflect an office schema rather than deliberate fabrication.

### Psychological Scientist's Desk
Evaluate three claims:
- “A confident eyewitness must be accurate.”
- “If a memory contains an error, the person is lying.”
- “Because memory can be wrong, memory evidence is worthless.”

All three are too strong.

### Data Lens
Analyze a fictional misinformation experiment in which neutral, moderate, and strongly leading wording produce different later reports. Identify the manipulated variable, measured outcome, condition pattern, ethical considerations, and a cautious conclusion.

### Guided Investigation
Compare neutral and leading follow-up questions after the same fictional event. Identify which details might be vulnerable to later-information effects and why.

### Ethics Boundary
Do not attempt to implant meaningful false memories in classmates, friends, or family. Classroom work uses fictional scenarios, provided datasets, or low-risk informed demonstrations only.

### Independent Assignment
Write a 350–500 word evidence analysis explaining why memory accuracy, confidence, and honesty are related but not identical concepts.

### Research Notebook Checkpoint
Could retrospective self-report create a measurement problem in the semester question? Compare a delayed memory report with a more direct or repeated measure.

### Academic Journal
Why is recognizing normal memory error important for fair interpretation of another person's report?
