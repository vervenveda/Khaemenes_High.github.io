2 · Essential Question

Essential Question

Does the brain remember facts, experiences, and skills in the same way?

3 · Learning Objectives

Learning Objectives

  • Distinguish working memory from long-term memory.
  • Compare episodic, semantic, and procedural memory.
  • Explain how schemas and categories organize information.
  • Distinguish recognition from recall.
  • Explain why retrieval cues can affect performance.
4 · Psychology Word of the Day

long-term memory

Use it in context: Explain how long-term memory connects to today’s evidence, measure, or explanation. Do not treat knowing the word as the same thing as understanding the construct.
5 · Vocabulary in Context

Vocabulary in Context

long-term memory · episodic memory · semantic memory · procedural memory · schema · category · retrieval cue · recognition · recall

6 · Core Reading

Substantial Core Reading

Memory categories are useful because different tasks emphasize different forms of knowledge, but they are not sealed boxes. A real event may involve episodic memory for what happened, semantic knowledge about the situation, and procedural skill used during the event.

7 · Worked Example

Worked Example / Synthesis

A musician recalling a concert may use episodic memory for the event, semantic knowledge about music, and procedural memory for performance. Working memory supports the current task of comparing or explaining those memories.

8 · Scientist's Desk

Psychological Scientist's Desk

Evaluate the metaphor: “Memory works like a computer hard drive.”

Students identify where the metaphor helps and where it becomes misleading because human memory is selective, cue-dependent, reconstructive, and altered by new learning and retrieval.

9 · Data Lens

Data Lens

Compare fictional performance on free recall, cued recall, and recognition. Students describe the pattern and explain why more retrieval support can raise performance without claiming that recognition is always easier in every task.

10 · Claims Laboratory

Claims Laboratory

Calibrate this claim: “One observation about Long-Term Memory Systems & Organization tells us everything important about a person.”

11 · Guided Investigation

Guided Investigation

Study a fictional 24-word list in random order versus semantic categories. Analyze how organization could create retrieval structure.

12 · Independent Assignment

Independent Assignment

Create a concept map showing working memory plus episodic, semantic, and procedural memory. Add one example in which at least three systems interact.

13 · Research Notebook

Research Notebook Checkpoint

If the semester question involves memory, specify which kind of memory or retrieval process is actually relevant rather than using the broad word “memory.”

14 · Academic Journal

Academic Journal Reflection

Why are memory categories scientifically useful even though real remembering can involve several systems at once?

Privacy boundary: The journal is academic, not therapeutic. Fictional, public, non-sensitive, or course-supplied examples are always acceptable.
