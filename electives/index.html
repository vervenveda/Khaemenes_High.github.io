Sovereign by Design

The finished student portal will remain independent and local-first.

No Required Account

No login, advertising, remote analytics, or external API dependency is required for the academic course.

Local Progress

Progress and journal data are planned for browser-local storage with explicit JSON export/import backup.

Scientific Boundaries

The course teaches explanation, evidence, limitations, and ethics. It does not train students to diagnose people from casual observation.

Implementation Discipline

Curriculum is locked first. Student-facing lesson HTML and assessment logic follow only after content audit.
