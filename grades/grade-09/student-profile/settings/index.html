Parent Access Policy

Parent or guardian access always remains active. A student profile setting must not remove parent access, hide grades from the parent, or block a parent recovery path.

When the protected account service is available, password changes should require parent notification and should preserve parent recovery. This static GitHub Pages profile does not store passwords, password hashes, recovery secrets, or authentication tokens.

Student Password Change Request

This records a local parent-review alert. It is not a real password change and does not store the password.

Parent Review

Use this to mark local alerts as reviewed after the parent has seen them. In a future protected system this should become a real notification receipt.
