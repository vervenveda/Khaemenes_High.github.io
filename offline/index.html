Important: two kinds of offline learning

Portable file: English 9–12 reading packs can be downloaded as a single HTML file and copied to phones, USB drives, and memory cards. Saved browser pages: the installer below stores learning pages inside this browser's cache. They are tied to this browser and device, can be deleted by the operating system or user, and should not be your only copy.

Save written answers, projects, grade reports and student records separately to a dependable device. Keep a second backup when possible. A browser cache is not a permanent record.

Offline checklist

  1. While online, choose your course, save its pages, and confirm that the completed count has no failures.
  2. Switch the device to airplane mode and open the course lessons to test them before depending on the cache.
  3. Save a second copy of portable readings and export reports or other student work.
  4. When you reconnect, repeat downloads to refresh changed content.

Offline availability of a course does not guarantee that every interactive game, remote video, sign-in flow, or external linked resource will function. Quizzes and grades should only be trusted after a separate offline functionality test.
